# Keeper: recovery_view 죽은 팔 제거 (D2-08)

`Keeper_turn_driver.run_named`의 `?recovery_view`에 Some을 넘기는 production 생산자가
없어 Some 가드가 전부 죽은 팔이었다. 감사 D2-08 처방대로 `?recovery_view` 인자,
`Runtime_agent.recovery_view`, `Runtime_recovery_projection`을 제거하고
`Keeper_recovery_transmission`은 `require_reader`만 남긴다. 유일했던 Some 생산자는
삭제된 테스트 픽스터뿐이었다.
