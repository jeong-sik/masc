# D2 tool-call errors: sanitized top five

`d2-top5-sanitized.jsonl` joins the 2026-09-28/29 host system logs to the exact `(file, line, seq, ts)` entries in `error-index.jsonl` for `tool_call_error`. It contains all 360 rows for the five most frequent tools: Read 174, WebFetch 54, Edit 46, masc_board_post_get 43, Execute 43. The full audit has 687 tool-call error rows; this file is the requested first classification slice, not a diagnosis of all 687.

Each row retains the Keeper and tool from the original log, argument **names and types** from the log's `input_shape`, the typed `masc.tool_disposition` only when present, and up to 400 characters of the error preview. Argument values are never copied. Credential-shaped strings, email addresses, URLs, host paths, long hex IDs, and long opaque strings are masked in the preview. The source preview itself can be truncated by the runtime, so empty or shortened messages are evidence limits, not missing errors. Typed disposition was present in 84/360 rows; the other 276 are `null`, not inferred from message text. The extractor parsed all 360 selected rows without a join failure; 27 previews had no extractable `error` or `message` field.

Use the exact source coordinates to investigate a particular case in the host ledger. Classify normal rejection, dependency failure, and tool-contract defect separately. This dataset does not include raw request values, private credentials, or provider payloads, and it does not prove that a rejection was incorrect.
