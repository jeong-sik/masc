---

## Core Variables

| Variable | Description | Default |
|---|---|---|
| `MASC_BASE_PATH` | Base directory hosting the `.masc/` state | `.` |
| `MASC_PORT` | HTTP and MCP server listening port | `8935` |
| `MASC_HOST` | Network interface binding | `127.0.0.1` |

## Provider API Keys

- `ANTHROPIC_API_KEY`: Anthropic Claude models
- `OPENAI_API_KEY`: OpenAI GPT/Codex models
- `ELEVENLABS_API_KEY`: TTS and Voice interaction
