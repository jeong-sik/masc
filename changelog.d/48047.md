### Fixed

- A failed browser command no longer reads as `workflow_rejection` whatever
  happened: an absent browser, a lane that is off and a browser that did not
  answer are `dependency_unavailable`, an argument or permission the caller
  lacks is `policy_rejection`, and a reply the tool cannot read is
  `runtime_failure`. A failure the browser itself answered stays
  `workflow_rejection`, because its cause is only in its message (#48047).
