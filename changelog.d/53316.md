### Changed

- A turn that serves an admitted chat request and a turn a Keeper wakes for
  itself send the same System and the same tools on Agent Core. The admitted
  request source rides the end context of the turn's first request instead of
  the System, and every run is offered `keeper_receipt_wait`, which refuses a
  call from a run with no chat execution. An official client still reads the
  source in its System. A provider no longer reads the whole history again
  when the two kinds of turns alternate (#53316).
