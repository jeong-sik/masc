### Added

- A `muse-serve` runtime protocol: a runtime.toml provider with
  `protocol = "muse-serve"` runs Keeper turns on Muse Code through
  `Keeper_muse_runtime`, and fusion panelists run one `muse serve` turn.
  Muse Code reads `max-prompt-bytes`, takes no output schema, and installs
  through `masc prerequisite-actions muse-code`. The seed declares
  `muse_code.muse-code-spark-1-3` without assigning it (#39272).
