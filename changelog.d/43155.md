### Changed

- `masc_wiki_lint` reports a new `revision_log_hole` finding when `log.md` skips an `r<N>` below the highest revision it records for a page; `missing` carries the skipped number. A page's lines run `r1`, `r2`, … with no skips, so the missing value is a line that reached the page and never reached the log — what an `append_log` that failed leaves. A write in flight only leaves the top of the column empty, so this needs no lock (#43155).
