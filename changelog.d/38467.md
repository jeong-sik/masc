### Added

- Each User message a native AGENT_CORE Keeper turn creates carries its
  speaker as metadata under `agent_core.input_speaker.v1`, stamped when the
  message is created: the host's autonomous wake (with who answered each
  quoted Ask), the owner, a registry-matched Keeper, or an external
  connector speaker. The Librarian's conversation headers render it as
  `speaker=...`; messages without it render `speaker=unknown`. The entry is
  never sent to a provider and does not change request bytes (#38467).

### Upgrade notes

- Messages stored before this change have no speaker and read as
  `unknown`. An approval gate pending across the upgrade whose turn carries
  an answered Ask may admit that answer a second time, because the stamped
  message has a different admission digest (#38467).
