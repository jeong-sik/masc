### Upgrade notes

- Before installing this build, delete `memory_recall`, `memory_recall_scope` and `memory_recall_keepers` from `[typesafeai]` in `runtime.toml`; delete the three together, because the previous build refuses a scope or keeper list left on its own. `[typesafeai]` refuses unknown keys, so while any of them remains `scripts/install-local-build.sh` refuses the file and installs nothing. A new binary started without that check refuses the file at boot and starts in model-setup-required mode with no runtime and no Keepers; deleting the keys then is not enough, and the server needs a model setup resume (`POST /api/v1/runtime/setup/resume`) or a restart. The previous build reads a file without the three keys as recall off, so they can be deleted before the upgrade (#55426).

### Removed

- The `[typesafeai]` keys `memory_recall`, `memory_recall_scope` and `memory_recall_keepers` are removed; nothing has read them since the recall pipeline was removed (#55426).
