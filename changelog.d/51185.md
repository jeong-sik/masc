### Internal

- `approval-auto-merge` now dispatches the main build right after it confirms a
  merge. Between 2026-11-10T21:07Z and 2026-11-11T01:51Z every one of the thirteen
  merges whose `merged_by` was `github-actions[bot]` left no `push` run for its
  merge commit, so `Main minimal build` did not start for them and the build had
  to be dispatched by hand. All four merges by a person account in the same window
  left one. This is a record of those samples, not a rule about every future merge
  (#51185).
