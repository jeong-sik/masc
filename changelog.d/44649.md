### Fixed

- A checkpoint save that had to write a recovery copy (the payload encoder refused some json) now reports the checkpoint it wrote. The turn-end step used to return the checkpoint it passed in, so the messages handed to the Librarian and the turn record's last-atom digest could differ from the file, and the Keeper's Librarian stopped on the mismatch. The checkpoint purge tool no longer moves the Librarian position when the save stored a recovery copy (#44649)
