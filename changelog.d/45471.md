### Added

- Add `Verifier_review_worker`, the E06 worker bridge that runs a retained verifier review attempt through the host-built tool-capable reviewer while keeping verdict extraction, `report_review_verdict`, and Task/Goal transitions on the host side. (#45471)

- Bind retained review execution to the actual host lookup authority and recorded destination, execute its frozen prompt and media, and allocate retry identities from the durable owner inventory (#45471).

- Task verifier execution now retains dispatch, exact structured judgment, safe terminal retry lineage and host commit progress with the original request owner. The judgment publication also retains its exact domain notes, and restart finds it before evidence or lookup preparation. Restart restores that original and judgment; possible dispatch or a lost reply never authorizes another automatic model call. Commit recovery confirms the same verification's exact domain notes or rejection handoff, and retries only from its original awaiting state.

- Preserve true pre-admission refusal as retryable admission of the same frozen original after configuration repair. A possible-dispatch unknown result now closes the actual inner runtime walk's next-candidate admission as well as the outer verifier slot loop; ordinary consumers keep their existing retry policy.

### Upgrade notes

- Task verifier originals use `verifier_review_original/v2` and freeze both the review goal and the separate `verification.system` instructions. Version 1 originals have no captured system instructions and are rejected; there is no compatibility reader or automatic replacement. Preserve and resolve any unfinished older original before upgrading. Task original ownership now uses the shared workspace `.masc/lane-addons` store. Goal proof review is not converted to this retained worker lifecycle by this change.
