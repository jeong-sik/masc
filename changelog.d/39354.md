### Changed

- A Muse Code Keeper under `native = "none"` or `"read"` runs with MASC's
  tools only. `muse serve` starts with `--disable-write --disable-shell`, the
  session selects `promptUnmatched`, and MASC answers each approval the host
  raises itself: a tool call named exactly like one of the session's MASC
  tools (`mcp__masc__<tool>`, from the list the MCP bridge serves) is allowed
  once, and every other call is rejected with a short reason. MASC never
  picks a choice that saves a rule in the operator's Muse Code files. `none`
  no longer fails as config, and the start prompt states the posture. A
  `microvm` or `remote_ssh` Keeper's session works in its own private
  directory, `<base>/.masc/official-clients/muse/workspaces/<keeper>`, instead
  of the host bookkeeping bundle. Every spawn sets `MUSE_NO_AUTO_UPDATE=1` so
  the launcher does not replace the binary in the background (#39354).
