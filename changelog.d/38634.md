### Upgrade notes

- Existing `<keeper>.vision` directories are pruned to the newest 500 files / 20 MB on the first image write after upgrade. Copy the directory first if you need older frames. Configure `MASC_VISION_MAX_ARTIFACTS_PER_KEEPER` and `MASC_VISION_MAX_BYTES_PER_KEEPER` environment variables to adjust or extend these limits (#38634).

### Added

- Add bounded retention and rotation to multimodal vision artifact stores (`default_max_entries = 500`, `default_max_bytes = 20 MB`), evicting older canonical files on writes while refreshing modification times on re-used frames to bound disk consumption without breaking active workflows (#38634).
