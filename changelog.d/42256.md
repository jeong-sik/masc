### Changed

- Tool schema wire JSON is now memoized on physical schema identity in an Ephemeron table instead of being rebuilt on every provider step. `Agent_turn.prepare_tools` re-serialized the whole unchanged tool surface each step; one tree is now built per schema and shared by `Tool.schema_to_json`, `Tool.wire_json_of_schema`, and `Tool.wire_bytes_of_schema`. The schema record is private and immutable, so physical identity determines the wire form, and weak cache keys release wire forms with their schemas. Output shape and key order are unchanged (#42256).
