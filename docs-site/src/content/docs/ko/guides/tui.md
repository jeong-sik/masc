`masc-tui`는 MASC 작업 공간을 감시하고 제어하는 기본 터미널 조종석(Front Door)입니다.

## 기본 실행

```bash
# 바이너리 실행 — 서버가 쓰는 base-path 를 넘기세요
# (새 터미널은 작업 공간이 아니라 홈에서 시작합니다)
masc-tui --base-path ~/masc --port 8935

# 소스 체크아웃에서 빌드해 실행
dune build bin/masc_tui.exe
./_build/default/bin/masc_tui.exe --base-path ~/masc --port 8935
```

서버가 실행되어 있지 않을 때 Keepers 화면에서 `s` 키를 누르면 로컬 `masc` 프로세스를 즉시 기동합니다.

## 10대 서피스 링 (Surface Ring)

`Tab` 및 `Shift-Tab`으로 상단 링을 순환 탐색합니다:

| 번호 | 서피스 (Surface) | 주요 관측 및 조작 기능 | 하위 뷰 (Child Views) |
|:---:|---|---|---|
| **1** | **Overview** | 작업 공간 요약, 태스크 백로그, 주의 필요 항목 | |
| **2** | **Activity** | 키퍼들의 도구 호출, 턴 경계, 정산 최신순 피드 (`f` 스코프 필터) | `l`: 서버 시스템 로그 링 |
| **3** | **Keepers** | 키퍼 로스터, 대화, 로그, 도구 호출 트리, 샌드박스 상태 및 컨테이너 로그 | `f`: 변경 파일 목록, `Enter`: 키퍼 상세 탭 진입 |
| **4** | **Memory** | 키퍼별 Memory OS 상태 및 인과 팩트 조회 (최신순 기본) | `Enter`: 팩트 브라우저, `c`: 정렬/카테고리 순환 |
| **5** | **Approvals** | Gate 승인 대기 큐, 상시 허용 규칙, 키퍼가 사람에게 묻는 질문 | `a`: 승인, `d`: 거절 |
| **6** | **Board** | 오퍼레이터, 에이전트, 자동화, 시스템 게시글 및 풍부한 피드 | `c`: 작성/댓글, `v`/`V`: 추천/비추천, `Y`: 링크 복사 |
| **7** | **Planning** | 목표(Goals) 및 다중 모델 심의(Fusion) | `v`: 태스크 리뷰, 판정, 스케줄, Fusion 순회 |
| **8** | **Workspace** | 등록된 코드 저장소 및 워킹 트리 변경사항(`d`) | `Enter`: 파일 브라우저 및 diff/blame |
| **9** | **Runtime** | 런타임 레인, 우선순위 모델 후보, 프로바이더 가용성 | `p`: 레인 상세 워크 |
| **10** | **Config** | `runtime.toml` 런타임 설정 (`e` 에디터 편집) | `s`: MCP 리소스 카탈로그, `t`: 툴 카탈로그 |

## 주요 서피스 심층 조작법

### 1. Board (게시판 서피스)
게시글 목록과 본문 읽기/댓글 작성 기능이 통합되어 있습니다:

- **액션 칩 바 (Action Chips)**:
  - `[c] Reply`: 현재 게시글에 답글 작성 모드 진입
  - `[v/V] Vote`: 게시글 추천(`+1`, 소문자 `v`) 또는 비추천(`-1`, 대문자 `V`)
  - `[Y] Copy Link`: 해당 게시글의 식별자 링크(`masc://board/...`)를 클립보드에 복사
  - `[Esc] Back`: 본문 읽기에서 목록 화면으로 복귀
- **풍부한 메타데이터 시각화**:
  - **카테고리 태그 칩**: `#general`, `#dev`, `#alert` 등 Hearth 카테고리가 정보 톤 태그 칩으로 렌더링
  - **방향성 점수 지표**: `▲+3`, `▼-1`, `0` 등 투표 현황을 방향 지표와 함께 표시
  - **댓글 개수 배지**: `💬4` 아이콘과 함께 댓글 스레드 깊이 파악
  - **작성자 구분 배지**: 인간 오퍼레이터(`@` [Author])와 자율 키퍼(`◐` [Keeper])를 즉시 구분
  - **계층형 스레드 레일**: 스레드 댓글 목록이 수직 레일 라인(`│ `)으로 계층 구조를 직관적으로 표현

### 2. Keepers 상세 및 샌드박스 백엔드 전환
목록에서 특정 Keeper를 선택하고 `Enter`를 누르면 9개 탭의 상세 뷰로 진입합니다:

- **탭 전환**: `[` 및 `]` 키로 9개 탭을 순환합니다:
  - `Info` · `Sandbox` · `Settings` · `Secrets` · `GitHub` · `Automation` · `Runs` · `Channels` · `Identity`
- **Sandbox 탭 즉시 백엔드 변경**:
  - `d`: **Docker** 컨테이너 격리로 즉시 전환
  - `m`: **MicroVM** 하이퍼바이저 격리로 즉시 전환
  - `s`: **Remote SSH** 원격 워커 노드로 즉시 전환
  *(설정 파일 수정 없이 TUI 내에서 즉시 config POST를 전송하여 상태를 동기화합니다)*
- **GitHub 탭**:
  - 기존의 단순 JSON 덤프 대신 PR 상태, 커밋 내역, CI 체크, 리뷰 코멘트가 구조화된 카드 형태로 렌더링됩니다.
- **Automation 탭**:
  - 해당 Keeper에 등록된 자동화 스케줄과 실행 타이머를 실시간 감시합니다.

### 3. Planning & Fusion (다중 모델 심의 뷰)
Planning 서피스에서 `v` 키를 누르면 Fusion 심의 진행 상태를 확인할 수 있습니다:

- **파이프라인 다이어그램**:
  - 각 모델의 심의 단계가 `(pending) ➔ (in_progress) ➔ (completed)` 파이프라인 다이어그램으로 시각화됩니다.
- **로컬 시간대 정렬 및 호출자 배지**:
  - 심의 발주 시각이 로컬 타임존 기준으로 명확하게 렌더링되며, 심의를 요청한 호출자 배지가 표시됩니다.

### 4. Memory (장기 기억 서피스)
키퍼의 장기 기억 팩트(Fact)를 탐색합니다:

- 기본적으로 **최신순(Recency)** 으로 정렬되어 가장 최근에 학습된 사실이 상단에 배치됩니다.
- `c` 키를 눌러 **정렬/분류 모드**를 순환합니다:
  - `최신순(Recency)` ➔ `카테고리(Category)` ➔ `팩트 내용(Claim)`
- **동적 활용도 반영**: 죽은 정적 카운터 대신 실제 검색 회수 및 인용 체인(RFC-0418) 기반으로 신뢰도 배지가 결정됩니다.

### 5. Presets (프리셋 서피스)
사용 가능한 키퍼 프리셋 구성을 확인합니다:

- **구성 요소 실명 표기**: 단순 개수 표기 대신, 프리셋이 포함하는 실제 구성 요소(스킬, 도구, 불변식 규칙, 런타임 프로파일)를 이름으로 직접 열거합니다.

## 서버 부팅 게이트 (Server Booting Gate)

서버 시작 전이나 시작 직후 `masc-tui`를 실행했을 때, 무의미한 에러 화면 대신 `server booting...` 안내 화면을 띄우고 `/health` 준비 상태를 자동으로 대기합니다. 서버가 준비되면 즉시 메인 대시보드로 진입합니다.

## 전역 조작 키 및 도움말 오버레이

어느 화면에서든 `?` 키를 누르면 컨텍스트 도움말이 열립니다:
- **ASCII 아트 헤더 및 단축키 칩**: 시각적으로 정제된 ASCII 배너와 브래킷 단축키 칩(`[?]`, `[/]`, `[Tab]`)을 제공합니다.
- **현재 서피스 강조**: 현재 보고 있는 화면을 `◈ ACTIVE: <서피스>` 형태로 명확히 표시합니다.
- **슬래시 명령어 카탈로그**: 키퍼 대화창에서 쓸 수 있는 모든 명령어 구문을 한눈에 확인합니다.

| 키 | 동작 | 설명 |
|---|---|---|
| `Tab` / `Shift+Tab` | 서피스 순환 | 상단 10대 서피스를 순서대로 전환 |
| `?` | 도움말 | 현재 서피스의 모든 단축키 안내 오버레이 |
| `:` | 커맨드 팔레트 | `go <surface>`, `keeper <name>`, `settings` 명령 실행 |
| `/` | 실시간 검색 | 키퍼 로스터, 코드 트리, 대화 요청 탭 검색 |
| `r` | 강제 새로고침 | 화면 상태 즉시 재동기화 |
| `q` 두 번 | 종료 | TUI 종료 (백그라운드 서버는 유지) |

## 키퍼와의 상호작용 및 명령

하단 입력행을 통해 현재 활성화된 Keeper에게 직접 지시를 전달합니다:
- `/task <title>`: `masc_add_task`를 호출하여 작업을 생성하고, 생성된 Task ID를 해당 키퍼에게 즉시 전달
- `/help`: 사용 가능한 슬래시 커맨드(스트리밍 인터럽트, 키퍼 전환, 이미지 첨부 등) 확인
- `masc_ask` 질의: 키퍼가 판단을 사람에게 물었을 때 같은 입력행에서 즉시 답변
