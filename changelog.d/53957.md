### Added

- `GET /api/v1/keepers/<name>/cache-outcome?turn_ref=...` answers why that turn's first provider request read or rewrote the prompt cache, behind the same `CanReadState` gate as the turn records; a runtime's default lifetime comes from the catalog declaration of the provider that answers it in the running configuration, and a runtime the configuration no longer holds is reported as inactive rather than undeclared (#53957).
