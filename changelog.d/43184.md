### Added

- The setup wizard's tools checklist can choose where web search goes, in two
  rows that start unmarked. The z.ai row is shown when `ZAI_API_KEY` is set
  where the wizard runs and runs `masc web-search-setup --provider zai`. The
  SearXNG row is shown when Docker answers: it takes a fresh look, runs the
  catalog action that fits the `masc-searxng` container, and writes
  `web_search.searxng_url` (`http://127.0.0.1:8888`) only once a JSON search is
  answered. A container that is paused, restarting or unusable gets a line
  naming the Docker command that looks at it, not a row. Quick setup lists
  both with their commands and runs nothing (#43184).
