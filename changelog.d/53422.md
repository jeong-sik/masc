### Performance

- The server keeps the decision row it appended when the row, with its newline, is at least one byte shorter than the reader's window (39,999 bytes). It kept only rows of at most half the window, so a row of 20,001 to 39,999 bytes emptied the kept row and the next Keeper row read the file. A row as long as the window is still not kept: the file read does not find it. (#53422)
