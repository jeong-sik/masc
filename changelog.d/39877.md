### Changed

- `/play invite` shows the invite link and a QR code on a card instead of a chat row, and copies the link only when `y` is pressed. The TUI keeps every card it issued by name until it exits or the invite is revoked: `/play link` reopens the newest and `/play link <name>` an earlier one, and `j`/`k` scroll a link longer than the card. A refused invite or revoke shows the server's message and what it says is missing, not only the error code (#39877).
