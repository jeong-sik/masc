### Changed

- RFC #53746 §3.4 (L5) states how the turn context lives today — sent once at the end of a turn's first request and absent from later requests' input on every Agent Core lane — and how L5 is built: the outside-text message keeps the `Outside_context` origin, sits right before the turn's caller message, and is kept whole in history; each request's projection leaves out the sections and lines an earlier outside-text message in the window already carries, so the same window sends the same bytes. It adds the price `w·ΔO + c·O·(1+m)` with measured requests per turn by lane. A new §3.6 records the operator's decision to put recall in L5 as one line per fact instead of a separate window-head layer, with the measurements behind it (recall sets of 84–251 facts and 149–304KB, of which a median 94–99% is still selected 16 turns later), and §8 adds the pre-L5 first-difference baseline (#54219).
