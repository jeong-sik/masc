### Removed

- Claude Opus 5 (`claude-opus-5`) is no longer in the model catalog, the Claude Code seed bindings (`claude-code-opus-low` through `claude-code-opus-max`) or the release evidence list, and the Claude Code account picker stops offering it. A `runtime.toml` that still binds `claude-opus-5` has that runtime disabled at boot; switch the binding to `claude-opus-5-5` or delete it. Opus 5 through OpenRouter (`anthropic/claude-opus-5`) is unchanged (#41880).
