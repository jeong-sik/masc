### Changed

- `GET /api/v1/runtime/metrics` keeps each decision log and cost day file's rows between reads and reads only what a file gained, instead of reading the whole last day on every request behind a cache; the cache, its `loading` placeholder and stale states are gone. The server announces `runtime_metrics` when a decision or cost row is written and when a kept row leaves the window, and the TUI Runtime surface reads on that push instead of every two seconds (#48122).
