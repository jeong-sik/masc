### Added

- **config**: `[transport] http_base_url` in `<base>/.masc/config/runtime.toml` names the public address of that workspace. Two servers started from one shell on two base paths each read their own, so an account server no longer takes the address a shell exported for the single-user server and stops with `redirect_uri_origin_mismatch`. `MASC_HTTP_BASE_URL` still wins over the file as a per-launch override. `masc auth bootstrap` and `masc auth invite` read the address the same way, so the invitation link carries the address the server compares its login clients with (#55537).

### Upgrade notes

- A `MASC_HTTP_BASE_URL` exported from a shell startup file reaches every server started from that shell and comes before the file. Move it into `http_base_url` of the `[transport]` table of each workspace's runtime.toml. The table already exists in a placed runtime.toml, and TOML refuses a second `[transport]` header (#55537).
