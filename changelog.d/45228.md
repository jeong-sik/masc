### Fresh state required

- Original Add-on request records are now `lane.addon.tool-request-owner.v3`. A record names its request body by digest, and the body is a file under `<base>/.masc/lane-addons/tool-request-bodies/`. Earlier records are not read, and the deploy store check refuses each one by file. With the server stopped, move every scope directory under `<base>/.masc/lane-addons/tool-request-owners/` out of `<base>/.masc/lane-addons/` (workspace-curator is `5e5665b70b1920c0c1dc7d16ab2b33c8d21773a7a0fab71bed62b03a8dd851e3/`, candle-appraisals is `730f334f72479a09ad59258948bf7ed64bbe4d707bc3c0d1e787baeebe5d7a37/`). Delete the `workspace-curator/` directory in the state volume of the workspace-curator installation, because a request its worker still lists after the original is gone stops the host's pass at that request (#45223). Keep the `candle-appraiser/` worker state: Candle retains each appraisal again under the same request ID and reads its retained answer from that state (#45228).

### Changed

- An original Add-on request body is written once, before the record that names it, and a record moves together with that body. Retain and progress compare the request by its digest. A Workspace Curator successor intent names its child by request ID and request digest instead of holding the whole child capture. A record whose body is missing, changed or not canonical JSON is an error, not absence (#45228).

### Performance

- A progress event on an original Add-on request reads and rewrites only its record, whose size does not depend on the request; the record still holds the commit's before and after domain states. Before, each event read, compared and rewrote the whole request. Discovery reads every body its records name under one listing of the bodies directory (#45228).
