### Added

- The dashboard's Runtime → Prompts tab has a presets view. It lists the prompt
  presets and shows what one would change by name: each override against the
  text in force, the overrides a restore would clear, keeper instructions,
  runtime assignments and exact-output lanes. An admin session saves the live
  state as a preset (replacing one only after confirming), restores a preset
  with a per-surface report, and deletes a preset (#55434).
