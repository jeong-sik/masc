### Removed

- **Local install**: `scripts/install-local-build.sh --refresh-guest-shim` is removed, as RFC host-and-shim-share-one-build-identity decided, and the option is now refused as unknown. It downloaded the release shim of the version the build reports, which a checkout build never accepts, and in four cases (unreadable `SHA256SUMS`, no such asset, a sidecar without an asset name, a build that reports no release version) it left the old shim in place after one WARN line and ended 0. The install without the option already rebuilds a shim of another source identity from the same checkout (#55481). To go back to a release shim, run the release installer: `scripts/install.sh --version vX.Y.Z --force --base-path <workspace>` (#55507).
