### Fixed

- The account server of a multi-account installation stops its boot on a Keeper configuration journal. The first step of the engine rolls such a change back after the boot looked in the folder of Keeper definitions, and could so write a definition the autoboot of the engine starts. A folder of definitions the boot cannot stat stops it too, where it was read as absent (#53790).

### Upgrade notes

- A multi-account installation that holds a Keeper configuration journal from a single-user boot does not boot until the journal is gone. A single-user boot rolls the change back (#53790).
