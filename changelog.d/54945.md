### Fixed

- An ACP Keeper on Mistral Vibe now starts its host with `VIBE_ENABLED_TOOLS` set from its native posture: `none` (also when no posture is declared) allows the MASC bridge tools and `todo`, `read` adds `read_file`, and `full` sets nothing. Before, Vibe ran every call its own policy allows, such as `bash` with `echo`, without asking MASC, so a `none` Keeper ran host commands (#54945).

### Upgrade notes

- Vibe Keepers at `none` or `read` lose Vibe's `cron`, scratchpad and web-search connector; MASC `WebSearch`, `WebFetch` and `Grep` cover search. A `VIBE_ENABLED_TOOLS` in the server's own environment no longer reaches the host (#54945).
