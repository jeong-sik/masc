### Internal

- `Keeper_sandbox_image_catalog` reads and writes a per-host
  `sandbox-images.toml` that maps a sandbox image name to the build promoted
  for each image store. It resolves a name to that build or to a typed
  reason it is missing, promotes a new build while keeping the previous one,
  rolls back, and saves atomically only over the bytes it read. The shipped
  `config/sandbox-images.toml` names `base` and `ocaml` with no builds.
  Nothing reads the catalog yet (#38745).
