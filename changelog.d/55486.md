### Added

- **Discord**: a Keeper can attach stored files to a Discord post. `keeper_surface_post` takes `attachment_ids` (canonical `att_<64 hex>` ids, in order, at most 10, Discord only), such as the `attachment_id` `keeper_generate_image` returns. Discord shows images inline and plays audio in place; MIDI, PDF and other files appear as downloads. Before approval each file must be one the posting Keeper may read and becomes durable, so it cannot be evicted while the post waits; after approval the bytes go up with the last text chunk. A file that is missing then fails before anything is sent. The bot needs the Attach Files permission (#55486).
