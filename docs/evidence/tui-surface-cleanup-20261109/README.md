# TUI 화면·팔레트 정리의 확인 범위

기준 소스는 `918c3c685dba668418711b9003a76a9e6a1066cc`다.
화면 지도와 팔레트 변경을 소스에서 확인한 기록이며 실제 화면 캡처가 아니다.

## 확인한 것

- `surface` 23종, Keeper 모드 6개·상세 탭 11개, 설정 탭 7개·Tools 탭 5개를
  실제 타입·화면 선택·키 처리와 대조했다.
- 독립 에이전트가 화면 지도를 검토했다. Automation·Channels를 전체 화면 진입점으로
  잘못 센 부분과 빠진 음악 작업대를 수정했다.
- 팔레트의 빈 검색은 최상위 목적지로 제한하고, 검색은 전체 typed action을 사용한다.
  Goal 지급을 열지 않던 전용 action은 인터페이스·실행기·기존 검사에서 함께 제거했다.
- 독립 에이전트가 팔레트 diff의 기능·권한·별칭·행 예산을 검토했고 P0/P1/P2를 찾지 못했다.
  개수 안내와 목록 순서를 잘못 설명하던 주석도 제거했다. GitHub 정식 승인은 별도다.
- 변경 `.ml`·`.mli`를 `ocamlc -stop-after parsing`으로 확인했다.
- 캐시 CMI를 격리해 복사하고 변경 인터페이스와 직접 참조 인터페이스를 다시 검사했다.
  `masc_tui_palette.mli/.ml`, `masc_tui_render_overlays.mli/.ml`,
  `masc_tui.ml`, 기존 `test_tui_palette_matching.ml`의 타입 검사가 통과했다.
  소스에는 `-w +4+32+69 -warn-error +a`, 테스트에는 `test/dune`의 `-w -4`를 적용했다.
- 변경 Markdown의 상대 파일 링크와 `git diff --check`를 확인했다.
  삭제한 RFC를 가리키는 활성 문서·코드 참조를 정리했다.

## 증거의 한계

캐시 CMI에 대한 타입 검사는 전체 의존성을 소스에서 다시 빌드한 결과가 아니다.
기존 캐시의 인터페이스를 기준으로 한 소스 호환성 확인이며 실행 파일을 만들거나 설치하지 않았다.
로컬 Dune 빌드·검사 실행·CI·실제 TUI 화면 관측은 이 기록에 포함하지 않는다.
화면 문구·배치·행 순서를 고정하는 검사는 추가하지 않았다.

성공한 재검사의 파일 해시·경고 옵션·종료 코드는 [영수증](typecheck.json)에 있다.
원시 명령·종료 코드는 로컬 `artifacts/tui-surface-cleanup-20261109/final-typecheck-results.json`,
작업 로그와 CMI 사본은 같은 디렉터리에 있다.
설치된 TUI가 이 소스로 바뀌었다고 주장하지 않는다.
