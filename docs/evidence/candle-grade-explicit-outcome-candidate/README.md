# Explicit-outcome Grade candidate

This candidate is excluded from `config/prompts`. The runtime retains the
previous Grade template until the RFC's human calibration is performed.

The candidate preserves wording invariance while allowing a single capability's
inherent difficulty and explicitly promised correctness or continuity guarantees
to justify a higher grade. Counting more outcomes is not a prerequisite.

No execution or calibration is claimed for this revised template. To evaluate
it, create an isolated prompt directory containing this Grade file plus the
unchanged Relation and Weights files from the same source revision, prepare a
new probe plan with that directory, and retain its exact template hashes.
Earlier frozen prompt measurements do not apply to these bytes.
