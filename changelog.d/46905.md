### Added

- `viewport-cadence-bytes` workflow and `measure-viewport-cadence-bytes.py` measure raw PTY-master bytes for three 15-second sessions per pin, including screenshot-response windows, for the Before (`11749bf34f`, parent of the #46832 merge `eb39c50f33`) and After (default `eb39c50f33`) pins. The experiment requires the expected poll counts, ordered responses, a per-run random control title and image bytes in both control windows, and fewer constant windows with title and image bytes after. Unrelated or delayed asynchronous frames can share a window, so co-occurrence does not establish what caused the image output. Run manually through Actions → viewport-cadence-bytes → Run workflow (optionally override `before_sha` and `after_ref`). The `viewport-cadence-bytes` artifact contains `viewport-cadence-bytes.json`, `capture-*.bin`, `capture-*.fixture.json`, `binary-sha256.txt`, `harness-sha256.txt`, and both `masc_tui_*` binaries when those files have been produced.
