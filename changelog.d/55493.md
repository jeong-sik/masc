### Upgrade notes

- A Lane declaration runs a `host_process` package, reads a `snapshot_file`
  outside the workspace, holds record grants or reads an operator-only source
  only when it carries `operator_authority = true`. A Keeper_only declaration
  whose Keeper visibility comes only from an upstream Lane output needs the
  line too. A marked Keeper_only declaration still reads as its Keeper, so the
  line does not let it hold record grants or read outside the workspace.
- Add the line to each such declaration under `<config root>/lane-addons/`
  before restarting on this build. The earlier build that is still running
  reports the line as an unknown declaration field and keeps the worker it
  already runs. A declaration that still lacks the line after the restart is
  listed under `configuration.issues` in `masc_lane_inspect`, and its worker
  does not start. Remove the line before rolling back (#55493).
- `masc browser-lane-setup` writes the line only into a declaration it
  creates. For an existing `host_process` browser declaration without it, the
  command names the file and leaves it unchanged (#55493).

### Changed

- An unmarked Shared declaration now reads as an unauthenticated caller, and
  an unmarked Keeper_only one as its Keeper. Only the operator can save over or
  Detach a declaration that carries `operator_authority = true`; a Keeper's or
  an unauthenticated caller's save or Detach of that file is refused (#55493).

### Fixed

- Reconcile no longer attaches every Shared Lane declaration as operator
  configuration. A worker gets operator authority only from
  `operator_authority = true`, which only the operator can save. A manifest
  that turns to `host_process` after a Keeper's save no longer runs on the
  host. A snapshot link that later points outside the workspace is no longer
  read. An upstream Lane that later turns Keeper-only or operator-only no
  longer gives a declaration that Keeper's or the operator's authority.
  Removing the line stops what it allowed, even in a pass that cannot apply
  the declaration (#55493).
