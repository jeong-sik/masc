### Fixed

- An exception the Claude Code or Antigravity runtime did not expect, caught
  as the turn leaves it, is a masc internal error
  (`internal_unhandled_exception`, site `claude_code.runtime_boundary` or
  `antigravity.runtime_boundary`) rather than a provider parse error. It no
  longer reads "Parse error", and the lane walk no longer treats it as a
  reply no candidate could read. The dashboard client probe reports it as
  `runtime_exception` (#39792).
