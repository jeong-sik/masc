### Performance

- The verification dashboard (`/api/v1/verification/requests`, `/api/v1/verification/summary` and the proof compose) keeps each request's listing row for the version of its file, so a listing stats every request file but reads and parses only the ones that changed since the last listing. On a store of 1,938 requests (69 MB) a listing took 733 ms, most of it JSON parsing on the server's main domain, and now takes 4.5 ms after the first; the kept rows hold 7.4 MB (#39938).
