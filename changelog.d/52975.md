### Documentation

- Revise the Draft RFC that keeps Keeper row facts in memory by their
  writers: a reader fills an empty value without taking any lock and
  installs it by compare-and-set, a writer reads the value before it changes
  the file and empties it when another change came first or the file ended
  mid-line, and the Owner meta read falls back to the file when no Owner
  holds a meta. This replaces the fill under the store lock that the first
  draft described (#52975).
