### Added

- A Keeper can end a chat turn to wait for the receipt of a background `Execute` run with the new `keeper_receipt_wait` tool. The next run of the same conversation starts with that receipt, and no other run reads or deletes it while the wait is pending. A request whose run ended without leaving a receipt is settled with one `Unfinished` receipt and a `Source_lost` resolution. 가이드 없음(문서 없음) (#51429).

### Internal

- `Keeper_client_tool_outbox_wake.create` takes `~settle_lost_waits`, which `server_bootstrap_maintenance` binds to `Keeper_receipt_wait_sweep.settle_lost`. The wake module cannot call `Keeper_execute_background` directly because that module calls `notify` (#51429).
