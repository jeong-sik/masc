### Fixed

- The Clients roster no longer presents synthesized times as client session or last-seen facts: `/api/v1/dashboard/clients` sends `null` for both fields on Workspace_state and Keeper_registry rows and preserves them only on Agent_record rows. The TUI measures ages to the snapshot's `generated_at` instead of the current wall clock. The nullable timestamps and partial-read reporting use `masc.dashboard.clients.v2`; a server and TUI on different schema versions reject the snapshot with an explicit unsupported-schema error instead of misreading the old contract (#48070).
