### Changed

- A runtime binding whose model has no AGENT_CORE catalog row, under a provider the catalog has a row for, is now an exact-output slot when its model declares a `[models.X.capabilities]` table; the slot answers with the capabilities the binding's Keeper turns run on. A Tinker `tinker://` sampler checkpoint is the first such model. Without the table the slot is still left out as `Target_not_in_catalog`, also on the Anthropic wire, where the adapter fills the binding's capability override from the provider preset; the boot log names each such slot and the table to write. A binding whose provider has no catalog row is still left out (#50026).
