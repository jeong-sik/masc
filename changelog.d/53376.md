### Internal

- A product path that shrinks or changes a Keeper's head now has one function to go through, `Keeper_turn_log_reset.run`: its own checks, one save that closes the head's open messages (checks again against the closed head), the turn log's `Reset` line with an announced cause, then the change. The line names what was closed since the last unit, so what the path drops is named before it goes. After the line there is no error branch: a failed change and a kill leave the same disk, and the next unit starts at the line's `after` either way. Nothing calls it yet; history clear and the recovering purge move onto it next. The closing save the process start step makes now lives in `Keeper_turn_log_closing`, shared by both (#53376).
