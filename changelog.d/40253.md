### Added

- Model-capable Lane Add-ons resolve their installation-owned host runtime route,
  retain model requests before invocation, and preserve actual response identity
  and declared candidate failures. Unsupported official-client output controls
  fail explicitly. Thinking-only responses continue to the next declared candidate
  with their provider stop reason, and model-declared temperature stays authoritative.
  Missing or unknown host sampling routes remain configuration issues before
  worker persistence and can recover after a runtime update without a TOML edit.
  Native HTTP and preflight integration coverage is pending CI execution. (#40253)

- Integrate worker-bound sampling brokers and durable bounded request evidence from the parent; preserve capacity-wait semantics without inventing a cumulative model deadline. (#40253)

- Accept the required source-access argument in the sampling recovery fixture, preserving its preflight and recovery cases. (#40253)

### Fixed

- Treat a declared zero turn timeout as unbounded when invoking host sampling providers, preserving missing and positive liveness declarations. (#40253)

- Continue model fallback when a provider omits a usable model identity, order sampling through the shared quota/backpressure walk, and record rate/quota refusals while clearing answered candidate pressure (#40253).

- Use the runtime instance type exported by the current runtime interface for host sampling backpressure annotations (#40253).
