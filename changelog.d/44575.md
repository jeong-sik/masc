### Changed

- A Keeper request that ended on an agent-core `RateLimited` or provider `RateLimit` error now stores a typed `provider_rate_limited` cause with the provider (when known), the wait the producer reported (`null` when none) and the provider's own text, instead of one `core` sentence. The one-line summary shows the wait only when it was reported (#44575)

### Upgrade notes

- Chat rows and walk evidence that carry a `provider_rate_limited` failure are unreadable to a binary older than this change: restart a TUI that was already running before the server restarts, and do not roll the server back to a build that predates it once such rows exist (#44575)
