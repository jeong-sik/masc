### Upgrade notes

- Before restarting onto this build, delete `memory_recall`, `memory_recall_scope` and `memory_recall_keepers` from `[typesafeai]` in `runtime.toml`. `[typesafeai]` refuses unknown keys, so a file that keeps any of them is refused as invalid: the server starts in model-setup-required mode with no runtime, and Keepers do not boot until the keys are gone. The previous build reads a file without all three keys as recall off, so they can be deleted before the restart; delete the three together (#55426).

### Removed

- The `[typesafeai]` keys `memory_recall`, `memory_recall_scope` and `memory_recall_keepers` are removed; nothing has read them since the recall pipeline was removed (#55426).
