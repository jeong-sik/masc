### Fixed

- A child that prompts on the terminal no longer stops a `masc start` that runs as a background job of that terminal. The server now ignores SIGTTIN and SIGTTOU from startup, and every child inherits the ignored signals whichever way it is started, so reading the terminal fails with EIO instead of stopping the server's whole process group. Children stay in the server's process group, so killing the group still ends them. On 2026-09-24 agy opened /dev/tty for an interactive login and the server stopped with all nine official-client children for fourteen minutes. A terminal handed to any spawned child as stdin is now replaced by /dev/null, not only for children in their own process group (#38633).
