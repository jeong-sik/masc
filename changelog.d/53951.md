### Fixed

- The refusal of the account server over a Keeper configuration journal no longer promises a rollback. The boot does not read the journal; the engine would roll back only one that decodes and names this configuration root, and would not start on another. Removing the journal leaves the Keeper definition and runtime.toml as the change left them (#53951).

### Documentation

- The interface and the setup guide of the account server say that `GET /health/ready` answers 503 whenever the authorization zone cannot be trusted, after the engine is ready too, and that the home and invitation pages still answer then (#53951).
