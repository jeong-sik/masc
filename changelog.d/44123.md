### Fixed

- A Task status row with a missing or non-RFC 3339 lifecycle timestamp is rejected when it is read. `claimed_at`, `started_at`, `submitted_at`, `completed_at` and `cancelled_at` were taken as the empty string or any text; only `AwaitingVerification.started_at` was checked. Like any other corrupt required field, such a row makes the whole backlog unreadable and the error names the row, so the deployment preflight (`validate-task-backlog`) refuses it before the executable is replaced. (#44123)
