### Changed

- The startup checkpoint object sweep keeps the bundles that a Keeper's
  turn log lines past its Memory writer's reading name, so a line not yet
  read still reads the content it was written with after a purge rewrote the
  history. Each turn log is read from the `turn_log_offset` of the commit
  log's tail line when that line names the turn log's id and the offset
  starts a line, and from its first line otherwise. A turn log that cannot
  be read, or a line from there that does not decode, stops the sweep with
  nothing removed (`checkpoint object sweep skipped`). The startup log line
  gains `turn_log_bundles=` (#54033).
