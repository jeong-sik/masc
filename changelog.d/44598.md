### Fixed

- The dashboard FSM views (flowchart, keeper lanes, fleet matrix, transition history) now draw and read the runtime (KCL) states the server sends, `idle`, `routing`, `executing`, `done` and `exhausted`, instead of the never-sent `selecting` and `trying`. The runtime-lane stall judgement and two operational-summary branches that only matched the old names are removed (#44598)
- The composite flowchart's turn (KTC) area now draws the `routing` and `exhausted` turn phases the server sends, and the keeper turn lane reads both with a meaning instead of the fallback text (#44598)

### Internal

- Dashboard tests compare the KTC, KDP and KCL state names with the string results of `turn_phase_to_string`, `decision_stage_to_string` and `live_runtime_state` in `keeper_composite_observer.ml`, so a server-side change to one of these alphabets fails a dashboard test (#44598)
