### Changed

- Browser Add-on exports such as `browser_command` are no longer Keeper tools or MCP `tools/list` entries. The host browser tools (`Browser*` in a Keeper, `masc_browser_*` over MCP) are the one browser tool surface, and several browser installations may export one name without failing the public tool reading. `masc_browser_read` `mode = "screenshot"` now answers a caller without a Keeper workspace with the PNG as an image block, which `browser_command`'s `page.capture` used to give such callers. A full document source read (`page.read` with `includeHtml`) stays with the operator dashboard and the runtime's document sources; the capability table already lists `read_html` as unsupported in BrowserRead.
