### Upgrade notes

- Building from source needs `mirage-crypto`, `-ec`, `-pk` and `-rng` 2.4.1,
  `cstruct` 6.3.0, and grpc-direct at `9ec21f9`, which no longer needs
  `mirage-crypto-rng-eio`. Bring an existing opam switch up with
  `scripts/opam-pin-external-deps.sh --install` and
  `opam install ./masc.opam --deps-only --locked`; opam removes
  `mirage-crypto-rng-eio` 1.2.0 on the way. The Keeper sandbox image reports
  `sandbox_image_lock_mismatch` until it is rebuilt from the new
  `masc.opam.locked` (#55013).

### Fixed

- The HTTPS listener no longer signs with a P-256 implementation that leaks
  timing through its table lookups (OSEC-2026-17). With no certificate
  configured, the listener signs every TLS 1.3 handshake with its
  self-signed P-256 key (#55013).
- A ClientHello, or a server certificate on an outgoing TLS connection, that
  carries a short compressed NIST curve point fails the handshake with an
  error instead of an exception (OSEC-2026-15). Outgoing TLS connections
  refuse a certificate whose EC public key is the point at infinity
  (OSEC-2026-13), and a certificate whose RSA signature is 0 or 1 is
  rejected as invalid instead of raising `Invalid_argument` (OSEC-2026-14)
  (#55013).
- The locked `mirage-crypto` and `cstruct` carry the fixes for OSEC-2026-12
  (AEAD plaintext written before the tag check) and OSEC-2026-20 (wrong
  bytes from `Cstruct.filter_map`, reverse `tail` and `cuts`, and `find`).
  MASC's own code calls none of the affected functions (#55013).
