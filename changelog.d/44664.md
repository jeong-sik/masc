### Fixed
- A provider call cut off by a server stop while it was reading the response now ends as cancelled. The socket is owned by a sibling fiber that closes it when the stop cancels the request switch; a reader that was runnable at that moment reached the closed descriptor before any cancellation check and was recorded as a transport failure (`readv: file descriptor used after calling close!`). Reads and writes on the raced socket now check the caller's cancellation first. (#44664)
