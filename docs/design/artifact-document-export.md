# 아티팩트 문서 내보내기

관련 목표: #45940. HTML·Markdown 게시 버전을 Word(.docx)·PPT(.pptx)·PDF(.pdf)로
내보냅니다. 각 변환기는 현재 읽은 게시 버전을 사용합니다.

## 사용

문서 읽기 화면에서 `Word로 내보내기`를 펼치고 `Word 파일 다운로드`를
누릅니다. 지금 읽은 게시 버전을 변환하며 파일명에는 문서 ID와 버전을
넣습니다. 편집 원고를 작성 중이거나 공동 편집 중이면 내보내기 버튼은
비활성화됩니다. 원고는 게시한 뒤 그 게시 버전에서 내보냅니다.

제목, 문단, 굵게·기울임·취소선·위첨자·아래첨자, 줄바꿈, 코드,
중첩 목록, 순서 목록의 시작 번호와 항목별 번호, 인용, 표와 셀 병합,
안전한 외부 링크를 Word 요소로 옮깁니다. 표의 세로 병합은 HTML 행 그룹
안에서만 이어집니다. Word 문서는 A4 세로와 1인치 여백을 사용하며,
기본 글꼴에 한글용 글꼴을 지정합니다. 실제 글꼴과 줄바꿈은 여는 프로그램의
설치 글꼴에 따라 달라질 수 있습니다.

문서에 base64로 포함된 PNG·JPEG는 바이트를 포함하고 인쇄 영역에 맞춰
비율을 유지합니다. 외부 그림과 다른 그림 형식은 설명과 안전한 링크로
바꾸며 결과 안내에 표시합니다. 외부 그림을 가져오는 요청은 하지 않습니다.
앱·영상·SVG·수식의 실행 화면, CSS 배치, 외부 폰트와 현재 앱 입력은
변환하지 않습니다. script·style·메타 정보는 본문으로 넣지 않습니다.
Word XML에 넣을 수 없는 제어 문자는 대체 문자로 바꾸고 알립니다.

## 경계

변환은 브라우저에서 필요할 때 불러오는 docx 라이브러리로 수행합니다.
HTML은 parse5로, Markdown은 기존 GFM AST 경로로 파싱하며 원문 스크립트와
이벤트 핸들러를 실행하지 않습니다. 원래 게시 내용, blob, 개인 입력,
공동 편집 원고와 확인 기록은 쓰지 않습니다. 별도 서버 변환 API나 외부
변환 서비스로 내용을 전송하지 않습니다.

내보내기 요청은 게시 ID·버전·본문 digest·인증 시점·작업 공간으로 묶인
읽기 화면에 속합니다. 문서 변경·화면 닫기·인증 또는 작업 공간 철회가
있으면 이전 비동기 변환 결과로 다운로드를 요청하지 않습니다. 실패하면
문서를 유지하고 오류를 표시하며 자동 재시도하지 않습니다.

OOXML 압축 파일의 제목·목록·표·관계·그림 바이트 검사, 읽기 화면의
비동기 소유권 검사, 실제 게시 API→읽기 화면→Word 바이트 생성,
별도 문서 프로그램의 열기·렌더링은 서로 다른 증거입니다. 합성 DOM의
앵커 클릭과 파일 바이트 캡처는 실제 브라우저 다운로드 성공을 증명하지
않습니다. Word를 LibreOffice로 PDF 렌더링하는 검사는 Office 파일의
소비자 확인이며 실제 브라우저나 Microsoft Word 자체의 확인을 대신하지
않습니다.

## PPT

읽기 화면의 `PPT로 내보내기`에서 `PPT 파일 다운로드`를 누릅니다.
게시 버전 전체를 편집 가능한 제목·본문·표·그림으로 옮깁니다. 원문을
요약하거나 문장을 버리지 않습니다. 문서 제목과 각 제목은 구분 슬라이드,
본문은 16pt, 표는 14pt로 나눕니다. 테마 색상·글꼴, 네 가지 레이아웃,
이름 있는 제목 자리, 주제별 섹션과 출처 메모를 포함합니다.

브라우저의 Canvas.measureText로 글자 너비를 측정합니다. 단어가 한 줄보다
길면 유니코드 글자 경계로 나누며 한글도 공백에 의존하지 않습니다.
슬라이드의 실제 너비·높이에 맞춰 본문과 표 행을 나눕니다. 긴 표의 머리글은
다음 슬라이드에 본문 한 줄과 함께 들어갈 때 반복합니다. 넓은 표는 열을
나눠 표시합니다. 측정과 출력 모두 Noto Sans KR 테마를 사용합니다. 이 글꼴이 없는 환경은
대체 글꼴로 열리므로 줄바꿈을 실제 프로그램에서 확인해야 합니다.

병합 셀은 각 행·열에 값을 반복해 일반 셀로 풀어 씁니다. 세로 병합은
HTML 행 그룹 끝까지만 적용합니다. 표 안의 글자 서식은 일반 글자로
옮기며 문단·목록·코드의 줄바꿈은 유지합니다. 셀 안의 안전한 링크는
주소를 함께 표시합니다. 표 안의 그림은 설명과 링크로 바꿉니다.
이 차이는 다운로드 화면과 결과 안내에 표시합니다.

HTML·Markdown 파싱, 외부 자원 요청 금지, 원본과 입력 보존, 비동기
다운로드의 인증·문서 소유권 검사는 Word와 같은 경계를 따릅니다.
PPT XML 검사, 실제 Reader에서의 바이트 생성, LibreOffice 렌더링,
실제 브라우저 다운로드와 Microsoft PowerPoint 실행은 별도로 검증합니다.

## PDF

읽기 화면의 `PDF로 내보내기`에서 `PDF 파일 다운로드`를 누릅니다.
A4 세로, 0.75인치 여백으로 제목·문단·목록·표·안전한 링크·포함된
PNG·JPEG를 배치합니다. 긴 본문과 표는 페이지에 이어집니다. PDF에
한글 일반/굵은 글꼴과 단색 이모지 글꼴의 사용한 글자를 포함하므로
다른 기기의 설치 글꼴에 의존하지 않습니다. 글꼴에 없는 문자는
유니코드 번호로 보존하고 안내합니다. 기울임은 일반 글꼴로 옮깁니다.

표의 가로·세로 병합과 셀 안의 문단·목록·제목·중첩 표를 옮깁니다.
넓은 표는 실제 글자 크기·목록 들여쓰기·중첩 표의 여백에 필요한
최소 너비에 맞춰 열을 나눕니다. 경계를 지나는 가로 병합 값은 각 표에
반복해 표시하며 결과에 안내합니다. 세로 병합은 원본 HTML 행 그룹
안에서만 이어집니다.

머리글은 본문 페이지에 반복합니다. 반복할 머리글과 본문 한 줄이 같은
페이지에 들어가는지는 실제 PDF 배치 결과로 확인합니다. 들어가지 않는
머리글은 일반 행처럼 페이지에 이어서 넣고 반복하지 않습니다. 본문과
행 병합으로 이어지는 머리글도 반복하지 않습니다. 두 경우 모두 결과에
안내합니다. 긴 단어는 포함된 글꼴의 실제 너비를 측정해 유니코드 글자
묶음 사이에서 줄을 나눕니다. UTF-16 문자를 쪼개는 break-all이나 글꼴에
없는 숨은 줄바꿈 문자를 넣지 않습니다.

변환은 브라우저의 지연 로드 pdfmake로 합니다. 글꼴은 앱에 포함된
고정 파일만 같은 출처에서 인증 정보 없이 읽고 리디렉션을 허용하지
않습니다. 외부 글꼴 서비스에 요청하지 않습니다. 글꼴 원본·SHA·라이선스는
`dashboard/src/assets/pdf-fonts/README.md`와 인접한 OFL 문서에 있습니다.
PDF 본문에서는 자원 URL 접근을 차단합니다. 원본 스크립트·CSS 배치·앱의
실행 화면과 현재 입력은 실행하거나 변환하지 않습니다. 외부 그림은
설명과 안전한 링크로 바꿉니다. 원래 게시 내용과 공동 원고·개인 입력을
쓰지 않습니다. 인증·화면 소유권이 바뀌면 진행 중인 다운로드를 거둡니다.

실제 PDF 파서의 strict 열기·글자 추출·글꼴 포함 검사, PDF 소비자의
이미지 렌더링, Reader의 합성 DOM 바이트 캡처와 실제 브라우저 다운로드는
각각 별도 증거입니다. 보이는 글자가 정상이라는 이유로 복사·추출되는
문자까지 보존됐다고 간주하지 않습니다.
