### Fixed

- A broadcast or Board post no longer takes a dune alias such as `@check` inside a code span for its recipient, and a real mention written after that span is found. The regex `Mention` module is gone: `Board_addressing`, the grammar the Board and the Keeper lanes already use, now picks the recipient. A mention glued to the preceding word, as in `Keeper(@name`, no longer counts as one (#46755).
