### Upgrade notes

- After upgrading, every Keeper request carries a "Workspace wiki" paragraph: one line per wiki page, built at the start of the turn. Its size grows with the number of pages. Set `enabled = false` under `[wiki_contents]` in runtime.toml (or `MASC_KEEPER_WIKI_CONTENTS_ENABLED=false`) and restart to turn it off. Add the table to a live runtime.toml only after this version is running; earlier versions do not know it (#42961).

### Added

- Each Keeper turn carries the wiki table of contents: one line per wiki file (title, file, one-line summary), built from the pages at the start of the turn rather than read from `index.md`, followed by the request's route to `keeper_wiki_read` (direct, through `keeper_tool_search`, or unavailable). A wiki listing failure shows a fixed line without the IO error. Autonomous turns record the paragraph as the `wiki` layer of the dynamic-context receipt. `[wiki_contents] enabled` in runtime.toml (default `true`) turns it off (#42961).
