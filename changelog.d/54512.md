### Fixed

- In the TUI, an Ask on Work > Inbox is answered with `a` to `d`. `1` to `4` no longer answer it and switch workspaces like `5` and `6` do. The Inbox card hint, the Inbox empty state and the help overlay name the new keys (#54512).
- In the TUI Keepers view, the sub-tab bar follows the pane that has focus: with the Preview pane focused it shows the keeper's tabs (`Chat & Stream`, `Memory`, `Work & Candle`, `Sandbox`, `Config`), which are the tabs `[`, `]` and the arrow keys switch. The embedded Memory preview hint reads `[Enter] Read` instead of `[Enter] Dive` (#54512).
- In the TUI composer, one `Esc` on a bare `/` clears it and returns to workspace navigation. A typed command such as `/hel` still takes two (#54512).
- The TUI Lane dive breadcrumb reads `Runtime › Lane` instead of `Infra › Lane` (#54512).
- An account with a quota window that still has room (unlimited, or under 100 percent used) and a `$0` extra credit window shows `$0 Sub` instead of `$0 Exhausted`. An account whose only window is credit keeps `$0 Exhausted` (#54512).
