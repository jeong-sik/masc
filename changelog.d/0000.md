### Added

- Add `scripts/migrate-lane-addon-bindings.py`, which classifies lane add-on binding records written by v0.48.0 or earlier using the container's own rules, and can move the records that are safe to move out of the read path (#0).
  - Usage: `python3 scripts/migrate-lane-addon-bindings.py --base-path <masc base path> [--write-out <archive dir>]`. The default run is classify-only and changes nothing; it prints one line per record and the before/after counts. `--write-out DIR` additionally archives every detached legacy record byte-identically to `DIR/<name>.json.legacy` (hash-verified) and renames the store file to `<name>.json.migrated`, which the store skips because `read_bindings` reads only files ending in `.json`. Records that are not detached are never moved or rewritten: repairing one means adding top-level `visibility` and `source_access`, which is an authority decision, and the tool reports those instead.
