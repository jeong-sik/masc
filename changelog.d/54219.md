### Changed

- RFC #53746 §3.4 (L5) states how the turn context lives today — sent once at the end of a turn's first request and absent from later requests' input on every Agent Core lane — and how L5 is built: the outside-text message is kept whole in history, and each request's projection leaves out the sections and lines an earlier outside-text message in the window already carries, so the same window sends the same bytes. It adds the price `w·ΔO + c·O·(1+m)` with measured requests per turn by lane. §4.1 adds the pre-L6 measurements (recall sets of 84–251 facts and 149–304KB, of which a median 94–99% is still selected 16 turns later) and proposes folding L6 into L5 by making recall one line per fact (#54219).
