### Internal

- `approval-auto-merge` now dispatches the main build right after it confirms a
  merge. A merge committed by `github-actions[bot]` produces no `push` run, so
  `Main minimal build` did not start for that commit and the build had to be
  dispatched by hand. Measured on 2026-11-10: five such merges left no push run,
  and one merge by a Keeper account left one (#51185).
