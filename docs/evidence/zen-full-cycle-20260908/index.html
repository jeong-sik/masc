종료 단계에서 발견한 문제

첫 Keeper 종료는 Librarian 메모리 정리가 30초를 넘어 보류됐습니다. 정리 완료를 확인하고 공식 복구 경로로 기존 종료를 대체했습니다. 추가 모델 턴 없이 새 종료가 finalized에 도달했고, Keeper는 paused 상태로 남았습니다.

따라서 이번 결과는 “복구 후 완료”입니다. 첫 시도부터 모든 종료가 매끄러웠다는 의미는 아닙니다.

설치 바이너리를 고정한 별도 실행 환경과 생성한 로컬 웹앱에서 진행했습니다. 기존 로그인 탭이나 외부 서비스에는 작업하지 않았습니다. 단일 실측이며 일반적인 성능·시각 인식 벤치마크는 아닙니다.
