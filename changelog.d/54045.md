### Internal

- `Exact_lane_slots` records each walked slot in the run's slot capture,
  as the lanes that walk HTTP and CLI apart record them: the HTTP flow, the
  CLI run and the outcome of its answer, and a slot passed without a visit
  (a full HTTP slot, a held CLI slot). The walker tells the lane of each
  slot it passes, when it passes it (`on_pass`). No lane that opens a
  capture uses the walker yet (#54045).
