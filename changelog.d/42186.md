### Added

- A start of the Keeper Firefox and its BiDi host, at a server start or for a Keeper's hover or drag, whose port answers after a last host that ended on that port with its BiDi session left in Firefox, or with Firefox refusing it one, now restarts that Firefox when `.masc/browser-lane/keeper-firefox.json` shows MASC started it and it started no later than that host ended: Firefox refuses every new host while it holds that session. The profile is kept, so logins stay; open tabs close. The new Firefox is started once the stopped one's process group is empty and its port no longer answers, waited for up to 5 seconds. Any other Firefox on the port is left running, the server log says why, and a host is started for it all the same (#42186).
