### Documentation

- Added `docs/evidence/execute-waits-2026-11/`: a script, tests and a measured result that count how long `Execute` calls run, what the long ones wait for, and how often a Keeper schedules its own wake instead. Of the `sleep` time in calls of 60 s or more, 95.6 % names a GitHub Actions run or runs `gh`; calls of build or test tools are 3.9 % of `Execute` time. The tool-efficiency report now cites this measurement for the cause of the waits, and RFC-0379 section 6 records the measured demand and one proposed trigger, without deciding it (#48592).
