### Added

- `agent-compaction-threshold` in `[models.<id>]` (a fraction in (0, 1) of `max-context`): an ACP Keeper passes the point to its host when it starts it, so the host compacts its own session during a turn — `VIBE_AUTO_COMPACT_THRESHOLD` for Mistral Vibe, `AGY_CLI_AUTO_COMPACT_OVERRIDE` for Antigravity, `-c context_compaction.*` for Muse Code. Kimi Code takes no such point and refuses the key at load. Absent keeps each host's default (#54915).
