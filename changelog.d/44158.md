### Fixed

- A failed `docker run` of a Keeper container now reports `status=exit=N` (or `signal=N`) and `container_after_run=stopped|absent|running|unknown` in the `docker_container_start_failed` message, and says `<no output>` when the run printed nothing. It used to carry the exit status only for mount failures, so a run that printed just a container id left no cause. (#44158)
