### Changed

- `masc sandbox-image promote` asks the chosen image store's own CLI whether
  it holds the tag and records only a tag it holds, so promote works on the
  nerdctl_kata and microsandbox stores and `masc setup` no longer stops at
  promote on a nerdctl_kata host. The host catalog keeps one reference per
  name and store, and a store table with any other key is refused. To go
  back, promote an earlier tag the store still has (#38951).
