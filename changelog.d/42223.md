### Fixed

- A restart of the Keeper Firefox for a session the last BiDi host left keeps `.masc/browser-lane/keeper-firefox.json` until the stopped Firefox's port no longer answers, and removes it just before the new Firefox starts. A restart that gives up because the port still answers after 5 seconds now leaves the record, so the next start reads it as a Keeper Firefox that has ended instead of one MASC never started; the give-up message says that what holds the port is outside that Firefox's process group, with no window to close, and names the `lsof` command that finds it (#42223).
