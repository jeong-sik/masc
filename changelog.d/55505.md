### Added

- **Discord**: a Keeper can send a stored audio file as a Discord voice message, a playable waveform. `keeper_surface_post` takes `as_voice_message: true` with exactly one id in `attachment_ids`; the text goes first as its own message, because Discord allows no text on a voice message. `keeper_voice_speak` now also stores its clip as the Keeper's attachment and returns `attachment_id`, so a spoken reply can go to Discord as voice. MP3, WAV, Ogg, M4A and WebM are accepted; MIDI is refused before approval because it holds notes, not sound. The server needs `ffmpeg` on its `PATH`; without it the post fails before anything is sent. A Discord post's files now become durable only after every one of them passes the file check before approval, so a post refused for one of its files leaves the others as they were. A post with a voice message that fails after its text reports the text's message id, and the text goes into the Keeper's conversation, so the Keeper does not post the text twice (#55505).
