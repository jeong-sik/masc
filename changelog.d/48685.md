### Internal

- The TUI's Code answers are declared in `Masc_tui_code_results` next to the functions that apply them. Its `apply` returns what is left for the event loop, and the protocol and the loop decide by `answer_kind` instead of listing every Code answer. Code requests deliver only Code answers, and `masc_tui.ml` wraps them in `Code_msg` in one place, `deliver_code`, which stamps the workspace when the request starts (#48685, #48664).
