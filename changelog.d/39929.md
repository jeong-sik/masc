### Internal

- `Candle_ledger` reads and appends `candle-ledger.jsonl` through one family of `Fs_compat` private JSONL functions. `update` reads the ledger, lets the caller name the events to append, and appends them only if the file is still as it was read, reading again when another writer got in first. A row that does not read, or a file that ends inside a row, fails the read, and only `recover_at_start` cuts a torn tail (#39929).
