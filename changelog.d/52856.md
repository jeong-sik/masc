### Fixed

- An official client (Antigravity, Codex, Claude Code, Muse, vibe-acp) that cannot be started is no longer retried automatically when the same request fails the same way: a missing executable, an argv over the limit, a permission refusal or a child setup failure end as `spawn_refused_same_input` (Fatal), while a shortage the system releases (`EAGAIN`, `EMFILE`, `ENOMEM`, ...) or a full Antigravity spawn gate ends as `spawn_resources_busy` (Transient). An exception from a running Codex client is no longer reported as a spawn failure (#52856).

### Fresh state required

- Stored official-client recovery records that name `transient_spawn_failed` no longer parse; resolve or clear those sessions before upgrading (#52856).
