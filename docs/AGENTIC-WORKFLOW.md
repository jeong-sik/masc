# MASC 에이전틱 개발 워크플로

개발 절차의 정본은 [헌법의 `execution_protocol`](constitution.xml)이다.
MASC 저장소와 작업용 checkout/worktree에서 변경을 시작하기 전에 헌법 전체를 읽는다.
시스템·개발자·사용자의 명시적 지시는 저장소 계약보다 우선한다.

구체적인 기여 절차는 [기여 워크플로](guides/CONTRIBUTOR-WORKFLOW.md)를 따른다.
PR 리뷰와 병합 절차는 [Native GitHub Stacks 가이드](guides/NATIVE-GITHUB-STACKS.md)를 참고한다.
