### Fixed

- A Task status row with a missing or non-RFC 3339 lifecycle timestamp is rejected when it is read. `claimed_at`, `started_at`, `submitted_at`, `completed_at` and `cancelled_at` were taken as the empty string or any text; only `AwaitingVerification.started_at` was checked. A row written before this change with such a value no longer loads. (#44123)
