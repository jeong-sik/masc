### Changed

- Every agy that masc launches (Keeper turns, readiness and probes, model, context and usage reads, and the Antigravity login command) now runs with `AGY_CLI_DISABLE_AUTO_UPDATE=true`, so a Keeper turn no longer swaps the agy binary under the next turn and parallel turns no longer each start an updater. The operator updates agy with `agy update` or by running agy directly (#49998)
