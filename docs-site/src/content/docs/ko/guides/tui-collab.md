## 개요

TUI Collab 허브는 별도 Keeper 선택 없이 공유 MSX 및 DOS 화면을 관측하고, `g` 키로 MSX 카트리지 로드 메뉴를 열며, `F5` 키로 MSX 게임 제어권을 전환하고, DOS 플레이 초대 링크(`n` / `/play invite`) 발급·회수 및 관측자 공개 채팅을 한 화면에서 수행하는 협업 허브입니다.

---

## 켜는 법: 진입 키 및 조작

Collab 허브는 `masc-tui`에 내장되어 있으며 터미널에서 바로 접근합니다:

- **허브 진입**: 일반 모드에서 `&`를 누르거나, 커맨드 바에서 `:` 입력 후 `go Collab`을 실행합니다.
- **머신 화면 직접 전환 (`m` / `d`)**: `m`은 공유 MSX 머신, `d`는 공유 DOS 머신 화면을 바로 엽니다(`:go MSX` / `:go DOS`도 동일).
- **MSX 카트리지 로드 메뉴 (`g`)**: Collab에서 `g`를 누르면 `<base-path>/.masc/msx/carts/`에 있는 ROM 카트리지 목록을 먼저 보여 주고 선택한 게임을 로드해 관측·플레이합니다.
- **MSX 제어권 전환 (`F5`)**: MSX 화면에서 `F5`를 눌러 `Observation`(관측)과 `Control`(제어) 모드를 전환합니다.
- **머신 간 순환 (`F4`)**: 공유 관측 화면에서 작성 중인 채팅 임시본이나 접속 상태를 잃지 않고 `F4`로 MSX와 DOS 화면을 오갑니다.
- **공개 채팅 포커스 (`Tab`)**: Collab 관측 화면에서 `Tab`을 눌러 머신 프레임과 공개 채팅 입력창 사이에서 포커스를 이동합니다.
- **DOS 플레이 초대 (`n` / `/play invite`)**: Collab에서 `n`을 누르거나 채팅창에서 `/play invite <이름> <시간>`을 실행해 새 DOS 플레이어 초대 링크를 발급하고, `x`로 회수하며, `r`로 목록을 새로고침합니다. 초대받은 게스트나 외부 AI 에이전트는 브라우저의 `/play#<token>` 또는 MCP 엔드포인트 `/mcp/play`(안내 문서는 `/play/agent.md`)를 통해 공유 DOS 머신을 함께 보고 조작할 수 있습니다.

### 주요 코드 및 모듈 좌표
- `bin/masc_tui_collab.ml` / `bin/masc_tui_collab.mli`: Collab 허브 상태 머신 및 레이아웃 렌더링.
- `bin/masc_tui_keys.ml`: 탐색 키 바인딩(`&`, `g`, `m`, `d`, `F5`, `F4`, `Tab`).
- `bin/masc_tui_types.ml`: `Collab_focus` (`Spectator` | `Conversation` | `PlayInvites`).
- `bin/masc_tui_play_pending.ml`: 전송 전 초대 변경 의도를 영속 기록하는 저널(`.masc/tui-play-pending.jsonl`).

## 활성화 조건과 안전 차단(Fail-Closed) 동작

### 조건
- **기본 관측 모드**: Collab에 진입하거나 `g` 카트리지 선택기를 열거나 게임을 전환하면 항상 안전한 `Observation` 모드로 시작합니다. `F5`를 명시적으로 누르기 전에는 키 입력이 게임 엔진으로 전달되지 않습니다.
- **워크스페이스 권위 결속**: 초대 발급·회수(`issue`, `revoke`)와 게임 제어권 명령은 서버가 TUI의 로컬 워크스페이스(`expected_base_path` 및 `expected_masc_root`)와 일치함을 검증해야 실행됩니다.

### 실패 증상 및 복구
- **신원 미확인 시 차단 (Fail-Closed)**: 서버에서 로컬 워크스페이스 신원을 확인할 수 없으면 머신 화면이 닫히고 게임 제어권이 해제되며 초대 변경 요청이 차단됩니다.
- **미확정 결과 격리 (Unknown Outcome)**: 초대 발급·회수 요청 도중 서버 응답이 오기 전에 연결이 끊기면 결과는 `unknown`으로 남고 `.masc/tui-play-pending.jsonl`에 기록됩니다.
- **미확정 결과 잠금 해제 (`u` 키)**: `unknown` 결과가 기록되면 추가 초대 발급·회수가 잠깁니다. 오퍼레이터가 서버 로그나 프로세스 종료 여부를 확인한 뒤 Collab에서 `u`를 눌러 확인 절차를 거치면 잠금이 해제됩니다.
- **채팅 폴링 일시 중지**: 유령 접속자 표시를 막기 위해 워크스페이스 신원이 미확인된 동안에는 공개 채팅방 폴링이 멈춥니다.

## 실행 예시

### 1. MASC TUI 실행
```bash
# 워크스페이스 경로와 서버 포트를 지정해 TUI 실행
masc-tui --base-path ~/masc --port 8935
```

### 2. 대화형 탐색 순서
1. `&`를 눌러 Collab 허브를 엽니다.
2. `g`를 눌러 MSX 카트리지 로드 메뉴를 열거나, `m` / `d`를 눌러 활성 MSX·DOS 머신 화면으로 바로 전환합니다.
3. 상태 표시줄의 모드 배지(처음에는 `[Observation]`)를 확인합니다.
4. MSX 화면에서 `F5`를 눌러 입력 전달을 활성화합니다(배지가 `[Control]`로 변경됨). 이제 방향키와 액션 키로 MSX 머신을 조작합니다.
5. `F4`를 눌러 MSX와 DOS 화면을 전환합니다.
6. `Tab`으로 채팅 입력창으로 포커스를 옮겨 메시지를 입력하고 `Enter`를 누릅니다.
7. `Esc`를 눌러 Collab 개요 화면으로 돌아갑니다.
8. `n`을 눌러 플레이어 이름(예: `guest1`)과 만료 시간(예: `12`)을 입력하고 `Enter`를 누르면 1회용 QR 카드와 플레이 링크(`/play#<token>`, MCP 접속은 `/mcp/play`)가 생성됩니다.

## 끄는 법 및 되돌리는 법

- **제어권 해제**: MSX 화면에서 `F5`를 다시 누르면 즉시 `Observation` 모드로 돌아갑니다.
- **화면 나가기**: 활성 머신 화면에서 `Esc`를 누르면 Collab으로 돌아가고, Collab에서 `q` 또는 `Esc`를 누르면 기본 TUI 서피스로 돌아갑니다.
- **초대 회수**: Collab에서 초대를 선택하고 `x`를 누르거나, TUI 커맨드 바에서 `/play revoke <name>`을 실행합니다.

## 상태 및 알려진 한계

- **지원 상태**: v0.52.0 이상에서 안정 지원. 원격 게스트 접속에는 인증된 리버스 프록시와 `MASC_HTTP_BASE_URL` 설정이 필요합니다.
- **단일 제어권자**: 어느 시점에든 한 명의 플레이어 또는 Keeper만 머신 제어권을 가질 수 있습니다. 다른 참가자가 제어권을 잡은 동안 관측자는 화면 프레임을 볼 수 있지만 입력을 주입할 수는 없습니다.
- **터미널 폭 제약**: 좁은 터미널(80열 미만)에서는 게임 화면 비율을 유지하기 위해 공개 채팅 메시지가 줄어들거나 사이드바가 숨겨집니다.
- **오프라인 확인 절차 필수**: 네트워크 응답이 유실된 초대 요청은 반드시 `u` 키 확인 절차로 해소해야 하며, 단순히 TUI를 재시작한다고 해서 미해결 `.masc/tui-play-pending.jsonl` 항목이 우회되지는 않습니다.
