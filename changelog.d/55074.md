### Fresh state required

- A Keeper name with an ASCII capital letter is refused: `masc_keeper_up name=Yuna` fails with `keeper_name must be lowercase: capital letter at byte 0`, and the name is not lowered. A Keeper created by an earlier build under such a name is not read after the upgrade: its `<base-path>/.masc/config/keepers/<Name>.toml` and `<base-path>/.masc/keepers/<Name>.json` are refused as invalid names, and a `<base-path>/.masc/keepers/<Name>/` directory makes the retained Keeper listing fail with `invalid retained Keeper directory`. Nothing is converted. With the server stopped, recreate the Keeper under a lowercase name and remove the files and directory of the old name (#55074).

### Fixed

- A Keeper can no longer be named so that the Librarian owner check refuses every pass, and two Keepers whose names differ only in case can no longer share a container name, a Board actor key or, on a case-insensitive disk, a directory (#55074).
