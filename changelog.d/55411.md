### Added

- The dashboard has a Runtime → Prompts tab (`/runtime/prompts`). It lists the
  shared prompts, including the Keeper world's value system
  (`keeper.worldview`) and, behind a switch, the fragments such as the
  `keeper.world.*` frame. Each prompt shows the text in force, its source and
  a diff against the file. An admin session edits, saves and clears the
  override in a multiline editor, and clears overrides the server holds back
  (#55411).
