### Fresh state required

- Keeper metadata no longer has a `last_runtime_attempt` key, and a metadata file that still carries it is refused. Every writer stored `null` there, so no information is lost. For fresh state in an existing workspace, stop every writer and preserve the old workspace, then remove that one key from each `<base-path>/.masc/keepers/<keeper>.json` (`Keeper_types_profile.keeper_meta_path`), for example with `jq 'del(.last_runtime_attempt)'`, and run `validate-stores` again before starting the server. This change performs no installed-state removal (#52852).

### Fixed

- The operator snapshot, its persistent-agent rows and the degraded dashboard row no longer report `unknown_model` as a Keeper's `active_model`, `active_model_label` or `last_model_used`. Those keys came from Keeper metadata that never recorded a runtime attempt and are removed; the model a runtime actually used is still reported through runtime trust (#52852).
