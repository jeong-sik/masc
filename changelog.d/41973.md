### Added

- The TUI's Browser Lane picker says where the BiDi browser host stands, under its choices: whether a host runs and is attached, when and why the last one ended, whether that Firefox has to be restarted first, the results the server did not acknowledge, and the command that starts a host. It reads the `bidiHost` the server sends with the connection list, so the rows change when the list is read again, and a server that sends none draws none. A hover or drag that was not sent for want of a BiDi connection shows the first of those rows too. On a terminal too short for everything the choices keep their rows (#41973).

- Escape server-provided BiDi host text in unsent hover/drag warnings before terminal styling and clipping (#41973).
