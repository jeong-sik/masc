# Tools 화면 「1분 이상 걸린 호출」 통계 (2026-11-10)

도구 호출 한 건이 앞에서 도는 동안 그 호출을 낸 턴은 기다려요. 지금 화면은 호출 수, 실패율, 실행 시간 합계, p50/p95를 보여 주는데, 이 숫자로는 1분 넘게 걸린 호출이 시간을 얼마나 쓰는지 알 수 없어요. 최근 30일은 p95가 8.0초인데, 호출의 0.82%(6,630건)인 1분 이상 걸린 호출이 실행 시간의 56.2%(475.4h / 845.7h)를 써요. p95는 이 꼬리를 보여 주지 못해요.

## 바뀐 것

- 서버(`Tool_metrics_series`): 구간, 합계, 도구 행마다 `long_count`(60초 이상 걸린 호출 수)와 `long_total_ms`(그 호출들의 시간 합)를 더했어요. 응답 맨 위에 기준값 `long_call_ms`(60000)가 있어요. 60초는 긴 호출이고 59.999초는 짧은 호출이에요. 실패한 호출과 deferred 호출도 길면 세요. 호출이 없던 구간은 null이 아니라 0이에요.

## 이 통계가 세지 못하는 호출

저장소(시리즈가 읽는 곳)는 호출이 결과를 돌려준 시각에 행을 써요(`Tool_metrics_persist.enqueue`). 같은 기간(UTC 11-08~11-09)의 Execute 긴 호출을 장부와 맞춰 봤어요.

- 장부(`measure_execute_waits.py`): 448건 24.19h. 저장소: 440건 23.34h.
- 저장소의 440건은 모두 장부에 짝이 있어요(시각 ±60초, 길이 ±20초로 맞춤).
- 장부에만 있는 8건은 모두 `Cancelled: Posix_spawn_process_mgr.Stop_without_grace` 또는 `Cancelled: Masc.Keeper_owner_signals.Stop_active_child`이고 disposition이 없어요. 합이 3,034초(0.84h, 한 건이 2,076초)예요. 결과를 돌려주지 못한 호출이라 행이 없는 것으로 보여요. 호출 경로는 확인하지 않았어요.

배경 Execute는 영수증까지만 재요. 장부의 `run_in_background:true` Execute 69행(11-09~11-10)은 모두 completed이고, 길이는 중앙값 61ms, 최대 1.9초이며 60초 이상이 0건이에요.
