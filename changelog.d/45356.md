### Changed

- A required exact-output service now counts as available when an Addon lane whose exact output carries the service's id (for example `hitl_auto_judge_exact`) holds an admitted slot, as well as when the builtin lane does. `Standalone_lane.obligation` stays the one place that says which services are required, and publication only reports availability; which lane runs a request is decided where it is dispatched. No configuration creates such an Addon lane yet, so nothing changes until a later layer declares and dispatches one (#45356).
