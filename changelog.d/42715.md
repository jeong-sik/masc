### Fixed

- `masc_wiki_create` and `masc_wiki_update` refuse a header value that would read back as something else: a tag with a comma, a bracket, a line break or outer spaces, and a title, summary or note that is blank. A tag holding a line break and `---` used to close the page header early, so the write succeeded and the page read with different tags and a different body. A hand-written page whose `tags` line is not a list is now named with that reason (#42715).
