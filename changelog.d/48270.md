### Added

- `Authz_zone`, the writer zone that appends one record to the authorization log while masc runs. It opens the log and the external store itself, keeps their handles, and refuses a log without a `Fresh_bootstrap`. Each commit judges what an earlier entry left with the judgment that a start makes and refuses to write when the store and the log disagree; a record that `Authz_state` refuses writes nothing. Otherwise it closes the earlier intent, writes `Intent_pending`, the record and `Committed`, and publishes the state with the record. No caller uses it yet (multi-account B3b, #48270).
