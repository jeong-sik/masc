### Upgrade notes

- Deploy this release before adding `refresh-s` to a live `runtime.toml`: an older binary refuses the unknown `usage-read` key at load (#39144).

### Added

- A provider's `[providers.<id>.usage-read]` may declare `refresh-s`, a positive float of seconds. After the read at server start, the account's usage windows are read again that many seconds after each answer, so the Overview's Providers meters no longer age until the next restart. Each repeat looks the account up in the current catalogue: a config save that removes the provider or its `refresh-s` ends the repeats, and a changed period applies after the current wait. The seed `runtime.toml` declares `refresh-s = 600.0` for OpenRouter, Z.AI, Kimi Coding and Ollama Cloud (#39144).
