### Performance

- Before a keeper turn, the driver asks three times which input modalities the run needs; each ask used to drop checkpoint messages equal to an earlier one, hashing and comparing whole messages. A repeated message adds no modality, so the modalities are now read off the messages as they come. On a 75 MB checkpoint of 20,512 messages one ask took 49.47 ms on the server's main domain and now takes 0.96 ms (median of five) (#39943).
