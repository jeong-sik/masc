### Fixed

- **Local install**: `scripts/install-local-build.sh` rebuilds a workspace guest exec shim that declares another source identity than the build even when the shim has a sha256 sidecar, and removes that sidecar with the shim it described. Before, the install left such a shim alone and ended 0, and the restarted server refused it: between 2026-11-21 and 2026-11-24 three microVM Keepers ran no guest command for about 73 hours while the server was replaced fourteen or more times. A failed rebuild installs nothing, and its by-hand command now removes the sidecar too. `--refresh-guest-shim` still hands a release shim to the release step (#55481, refs #53296).
