taskSpace

Reuse or create an Agent-owned task space; a name held by a user-owned space fails with EGO_TASK_SPACE_NAME_IN_USE. A new space starts with managed Page p1, and profileId applies only when creating it. Options: profileId: Browser profile id returned by profiles(); new spaces only.

await taskSpace(nameOrId, { profileId? })

Use subtree with an iframe root ref to focus on that frame. root: Valid Page snapshot ref such as @21; required only when scope is subtree.
