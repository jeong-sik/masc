### Added

- `Keeper_cache_outcome_reading` holds the `/cache-outcome` answer and writes and reads back its JSON with one set of field names, and `Message_list_change` holds the message-list change that the projection comparison returns, with its JSON. Both live in `masc_types` beside `Turn_record`, so the TUI, which does not link `masc`, reads the same definition as the server. Every tagged object has a closed kind list, so a new shape does not compile until both the writer and the reader name it (#53963).
