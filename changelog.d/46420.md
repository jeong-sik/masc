### Fixed

- Keep a connection's input free when the SDK refuses a click, double click or
  drag target with its typed `ElementResolutionError` (no match, hidden,
  disabled, obscured or invalid selector), because no press is outstanding
  then. Any other error still leaves release unconfirmed, and so does any error
  from `press`: its keys bypass the SDK's input tracking, so a key command that
  times out reaches the same error after the key was sent (#46420).
