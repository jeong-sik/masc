### Documentation

- Rewrite the verification part of RFC "a-stalled-handoff-reaches-the-one-who-can-move-it" from a read-only recount of the operating install. Of 19 Tasks stalled in `awaiting_verification`, 17 stopped on a passing failure: the server process ended during the review (8), the reviewer's provider call failed (8), or a provider call failed after the verdict was reported (1). The RFC now proposes that a settled verdict report decides the review however the execution ended, that a review ending without a report by cancellation, failure or writer loss goes to the next attempt, and that the operator list follows the `Awaiting_verdict` item of the task-lifecycle RFC instead of reading the run registry, which keeps only the latest 64 completed rows (#51500).
