# Changelog fragment for PR (issue #40070)

fix(board): store a whitespace-only hearth as no hearth

A board post created with a hearth of only whitespace (e.g. `" "`) was
persisted as `Some ""`. The board list filter trims and lowercases before
matching, so a stored empty hearth identifies a hearth that no `hearth=`
filter value can select, and `/api/v1/board?hearth=` reads an empty value as
"no filter". Normalize the hearth at the persist boundary: trim, lowercase,
and drop the value when it becomes empty, so a whitespace-only hearth is
stored as no hearth.
