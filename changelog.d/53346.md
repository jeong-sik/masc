### Performance

- A Keeper's metrics store keeps the text of its newest 120 rows in memory in the process that writes the store. The recent tool names and the recent activity of a Keeper row, and the metrics chart of one Keeper, read those lines and open no day file. Each read 120 rows from the files on every request. The rows are kept as text, which took a quarter of the memory of the same rows parsed (336,000 B against 1,318,080 B for 120 synthetic rows of 2.8 kB). (#53346)

### Internal

- `Keeper_status_metrics.recent_metrics_row_count` is the one place the 120-row window is written; the tool audit and the metrics API each spelled it. `Dated_jsonl.last_lines` is a fact of a store's newest rows as text, and `Dated_jsonl.parse_line` decodes one of them as the strict reads do. (#53346)
