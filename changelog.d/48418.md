### Changed

- A Memory journal line, retraction plan receipt, publication receipt or source-bound memory snapshot that is refused now names the missing or unexpected fields, or the row and value that failed, instead of a fixed sentence. A retraction plan receipt must carry `revision_links` (#48418).

### Fresh state required

- A retraction plan receipt without `revision_links` is not read. Stop the server, delete `.masc/config/keepers/*.memory-retraction-plan.json`, then install (#48418).
