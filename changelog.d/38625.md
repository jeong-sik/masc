### Internal

- `scripts/review/approve-guard.sh` is the one call review lanes use to post APPROVE. It refuses unless the SLOT line names this PR and this exact head, the PR is open, non-draft and based on main, and every check-run and workflow run on that SHA is completed and successful. An empty run list is not green. It also refuses an empty review body. `--check` only evaluates and never writes. The guard skips a head it has already approved, and after posting it reads the review back. A 22-case self-test against a fake `gh` runs as `test_review_approve_guard` (#38625).
