### Fixed

- The shared Librarian worker sends a typed `refuse_body` command instead of loading a body it cannot list before allocating. An Exact body larger than any host listing (observed 12,061,259 B against a 4 MiB listing) used to be handed to the worker, whose container then died with oom (die 137) repeatedly. The host now restores the original, reads the current declaration and owner record, and sends the small canonical refusal so the existing v2 `Request_body_refused` record keeps the evidence. Pending, unknown and final records are unchanged, and the stored worker v2 format is untouched (#52504).
