### Changed

- A runtime binding whose model has no AGENT_CORE catalog row, under a provider the catalog has a row for, is now an exact-output slot when its runtime.toml states every capability an exact slot reads: the window (`max-context`), the effort ladder (`accepted-reasoning-efforts`), JSON mode (`supports-response-format-json`) and native schema (`supports-structured-output`). A provider preset never stands in for one of them. The slot answers with the capabilities the binding's Keeper turns run on. A Tinker `tinker://` sampler checkpoint is the first such model. A binding that leaves one of the four unstated is still left out as `Target_not_in_catalog` on every wire, and the boot log names the keys to write. A binding whose provider has no catalog row is still left out (#50026).
