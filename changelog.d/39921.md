### Performance

- A microVM guest boot verifies the shim without rehashing it: the binary's SHA-256 is kept per file version (device, inode, size, mtime), so a boot reads only the sidecar until an install replaces the binary. One verification took 21.59ms of the server's main domain at p50 on the installed 5.2MB shim and now takes 0.022ms (#39921).
