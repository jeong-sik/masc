같은 run의 최신 완료 named output 연결, 직접 소비자 wake, 보존 근거, 구독 참조·sequence와 명시적 read/ack는 기존 계약입니다. 아래 조립 편집기, 일반 보고서 패키지와 자동 Board/Broadcast 연계는 제안입니다. 구독 알림을 Broadcast 또는 읽음으로 간주하지 않습니다.

이 편집기는 단방향 출력 연결을 모델링합니다. 피드백·행동 적용·재관측은 별도 owner 계약이 필요하며, 순환선을 그린다고 실행되지 않습니다.
