### Changed

- The tool audit of a Keeper row (recent tools, the newest turn's tools) is read without a cache. It was served from a ten-second cache filled by a pool job, though the process that writes the metrics store answers it from memory. A row now shows a turn's tools once its metrics row is written. The row's `tool_audit_read` field says `read` or `unreadable`; `timed_out`, which only the cache's compute window produced, is gone. (#53378)

### Internal

- `Operator_control_snapshot_tool_audit.read` takes no read policy; the cache key, the cached encoding of its outcome, `Timed_out` and `Keeper_status_metrics.Tool_audit_timed_out` are removed. The row's `dt_profile` timing, which was never assigned, is removed from the sub-op log line. (#53378)
