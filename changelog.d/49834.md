### Added

- `Runtime_vibe_cli` runs Mistral Vibe once in headless mode: the prompt on stdin, the `ask` agent, `--output json` and a per-call output directory that is removed afterwards. The child environment is a fixed list of names, so the server's `MISTRAL_API_KEY` never reaches Vibe and it uses the keyring credential. `export.json`'s outcome decides the result, and an exit code that disagrees with it is an error that names both values. Nothing calls it yet (#49834).
