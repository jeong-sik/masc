### Fixed

- A Lane Add-on `browser_document` source now reads its document through the browser Add-on worker, which holds every browser connection since #44295. It used to look the browser up in the server process's empty Browser Lane tables, so it always reported no connected browser. The source reads the one browser Add-on its installation may read; with none it names the unready installation, and with more than one it says so. A consumer detached during its read no longer stops the browser Add-on, and the read no longer makes the browser Add-on observe again. (#45210)
