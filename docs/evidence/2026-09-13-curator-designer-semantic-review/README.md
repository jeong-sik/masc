# Real local curator: designer group review

This captures the completed designer group from the existing 93-source local
Qwen run. The exact request contains its 12 original source IDs and snapshot
metadata. The result contains eight claims, no conflicts and one exclusion.
The model receipt preserves generation identity and measurements. This is not
the final cross-Keeper proposal, a new runtime-lane run, or an installed test.

Six claims faithfully attribute historical recollections. That does not prove
their underlying claims or present applicability. Claim 3 adds a priority rule
between executed pixel analysis and actual image inspection that the two
records do not establish. Claim 6 copies damaged fee text without identifying
its ambiguity. The exclusion says s12 has no factual content, but its
`evidence_path` resolves to snapshot1's real change record adding the s11
constraint. `resolved-s12.json` preserves that resolution. Exclusion as redundant
could be reasonable; exclusion because evidence is absent is unsupported.

The standalone and runtime curator instructions now explain metadata references,
preserve unintelligible text as ambiguous, and prohibit inventing precedence or
retractions. Python syntax was checked with `ast.parse`. No fresh model result
has validated the prompt correction. The existing editor request remains bound
to its already captured prompt; changing source does not alter that execution.
No claim was promoted and no runtime memory or configuration was changed.

`audit.json` records every claim's assessment. The exact request, result and
model receipt are copied without transformation. SHA256SUMS covers this archive
except itself. Broader current-file verification, final synthesis, automatic
Keeper discovery and demonstrated use in later turns remain separate work.
