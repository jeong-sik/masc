### Changed

- Bare `masc` no longer sends a workspace with Keeper history back into setup because of imp's own configuration. imp's model binding (`model_connection`), declaration (`keeper_declaration`) and sandbox are now advisory onboarding checks: the server skips an imp it cannot load and boots every other Keeper, so a broken `imp.toml` or an unresolved imp runtime is reported and the workspace opens. A `runtime.toml` the server cannot load still keeps the setup journey, since the server then boots with no runtime; that failure is reported by a new `runtime_configuration` check in `masc doctor --json` and `/api/v1/setup/status` instead of `model_connection` (#38196).
