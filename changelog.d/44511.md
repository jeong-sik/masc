### Fixed

- A cancelled Muse Code turn now gives the `muse serve` host the termination grace period to exit before the switch kills it, so the host can release its session and the next resume is not refused while the lease is held (#44511)
- A Muse Code write that times out after `turn/start` was sent, such as an approval reply, reports `turn_accepted = true` instead of `false`, so a caller does not retry a turn the host may be running (#44511)
