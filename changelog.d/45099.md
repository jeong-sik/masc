### Upgrade notes

- `scripts/install-local-build.sh --with-browser-addon` is removed. The script installs `masc-native-addon-launcher`, `masc-browser-addon-worker` and `masc-browser-process-owner` with masc by default and then declares the browser Add-on for the workspace; `--no-browser-addon` leaves all of it out. A workspace that already declares the package with another copy keeps that declaration, and setup names the `manifest_path` line that switches it (#45099).

### Fixed

- A local install no longer leaves the workspace without a browser Add-on, which made every native browser host poll answer HTTP 503 (#45099).
