### Added

- `masc exact-addon-setup --base-path <base>` writes each Exact worker package this masc carries to `<base>/.masc/packages/<name>-<revision>` when that folder does not exist, and builds the Docker image its manifest names. An existing folder is never rewritten, and one that holds other files is reported by name. The image is built from the package's `Dockerfile` and the shared `exact_worker.py` and `protocol.py`, and carries their digest as the `masc.lane.carried.digest` label; an image that already has that label is not built again. A package that fails, for one when Docker is absent, does not stop the others, and the command exits 1. `scripts/install-local-build.sh` runs it after the browser Add-on step and goes on when it fails (#52847).
