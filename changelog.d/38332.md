### Fixed

- masc-tui no longer calls a 401 or 403 without an `auth_error_code` a refused operator token. The auth layer writes that code on every refusal, so one without it is a handler refusing the request itself: run-next declining another Keeper's queued message, a Board reaction that is not the caller's, a browser-lane or activity check. The TUI told the operator to run `masc login` for these, which a new token does not fix; the JSON reads, the keeper roster, the chat events journal and the chat reconciliation read now show the server's own words for them (#38332).
