### Performance

- A Keeper row reads the Keeper's newest execution receipt from a value its store keeps in memory instead of from the day files, and `Keeper_execution_receipt.append` moves that value (`Dated_jsonl.newest_parsed_row`). `Keeper_execution_receipt.latest_json` now passes over a last row that is not JSON and gives the receipt before it, as `read_latest_receipt` does, and no longer reads a `.jsonl` file whose name begins with a dot.
