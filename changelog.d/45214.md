### Changed

- A workspace curator capture stores the model input once. Batches render their prompt over the canonical input, and a restore renders it again with the captured template; the capture keeps only the SHA-256 of the prompt it sent and refuses a restore that renders a different one. The observer registration receipt names the capture by its request digest instead of holding a copy, so an original's owner record holds one copy of the request instead of six (#45214).
