### Fixed

- A child masc starts can no longer stop the server through the terminal the server was started from. Every child now starts in a session of its own, so opening /dev/tty fails instead of stopping the server's process group, and a terminal handed to any child as stdin is replaced by /dev/null. On 2026-09-24 agy opened /dev/tty for an interactive login while `masc start` ran as a background job of a terminal, and the server stopped with all nine official-client children for fourteen minutes. Ctrl+C on a foreground server now reaches the server only; the server still ends its children when it shuts down (#38633).
