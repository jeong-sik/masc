### Added

- Workspace media upload endpoint `POST /api/v1/media` with raw-bytes SHA-256 addressing, magic-byte MIME verification (PNG/JPEG/GIF/WebP), explicit SVG refusal (`415`), pure OCaml raster dimension parsing, systhread-offloaded hashing/writes, and single-user plus multi-account bridge parity (#55189).
- Immutable caching (`Cache-Control: private, max-age=31536000, immutable`), strong `ETag` with `304 Not Modified`, `X-Content-Type-Options: nosniff`, `Content-Security-Policy: default-src 'none'; sandbox`, and `Content-Disposition` on `GET /api/v1/media/<sha256>` (#55189).

### Changed

- Removed blind 24-hour / 500 MiB wall-clock cleanup (`cleanup_old_files_in_dir`) from `Keeper_chat_media_store` and retired the now-unused `MASC_KEEPER_GENERATED_MEDIA_RETENTION_SEC` and `MASC_KEEPER_GENERATED_MEDIA_DIR_MAX_BYTES` environment variables and runtime setting registry entries. Workspace media under `.masc/media/` is currently append-only with no automatic reclamation until a follow-up two-pass reference-based GC PR lands (#55189).
- Legacy `.bin` files written by the previous media store are intentionally no longer resolved by `resolve_token` and now return `404 Not Found` (#55189).
