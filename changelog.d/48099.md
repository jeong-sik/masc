### Changed

- `GET /api/v1/dashboard/keeper-costs` keeps each Keeper's metrics day files folded between reads and answers with no 60-second cache in front. The server announces `workspace_dataset_changed` with `dataset` `keeper_costs` when a metrics row other than a heartbeat is written and when a kept row or day file leaves the default 24-hour window. The TUI Usage view reads Keeper usage on that push instead of every two seconds, and its decoder and the web cost dashboard no longer have the cache's loading, stale and pending states (#48099).
