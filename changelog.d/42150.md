### Fixed

- A BiDi browser host that takes a workspace now appends the previous host's unacknowledged results to `bidi-host-unacknowledged.jsonl` before it replaces `bidi-host.json`. Starting a host again, by hand or by the server, used to erase that list, which records actions that may have taken effect without the server confirming them. When the archive cannot be written the new host does not start and the previous record stands (#42150).
