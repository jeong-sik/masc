### Fixed

The block now splits on the break first and reads each line through that same reader, so a break in the middle keeps its blank row the way the operator ask pane draws one, while a run of breaks at either end is dropped because a leading blank would take the row the label sits on. A CRLF break leaves no stray carriage return on the row (#38030).
