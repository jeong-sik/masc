### Added

- `viewport-cadence-bytes` manual workflow measures raw PTY-master bytes on the Before (`11749bf34f`, parent of #46832 merge `eb39c50f33`) and After (default `eb39c50f33`) pins in the same CI image. The harness survives source checkouts, serves the browser discovery/read contracts, opens the viewport with Ctrl-^ then Ctrl-O, and records the screenshot poll denominator for each constant/control window. Missing or unequal poll coverage invalidates a measurement. Run Actions → Viewport cadence bytes → Run workflow, with optional `before_sha` and `after_ref` overrides. Artifact `viewport-cadence-bytes` contains `viewport-cadence-bytes.json`, `binary-sha256.txt`, `harness-sha256.txt`, and both `masc_tui_*` binaries. A valid measurement may report no skip effect.
