### Changed

- The number of queued events one Keeper turn takes is now set in `runtime.toml` as `turn.admission_max_events` (default 32, range 1 to 256, applied at the next restart). The server no longer reads the environment variable `MASC_KEEPER_ADMISSION_MAX_EVENTS`, so move an exported value into the file. A value outside the range fails the configuration load at startup; the environment variable used to be clamped to the range. (#50965)
