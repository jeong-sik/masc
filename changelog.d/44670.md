### Changed

- Pinning ocaml-msx #52 makes the server serve SNSMAT `0x0141`, GTSTCK `0x00D5` and GTTRIG `0x00D8` from the plain-CALL trap and record whether a served vector's caller returned into ROM or RAM; the core this pin replaces serves none of the three. This entry states what the linked core does, not which game path reaches it: the Sangokushi II playtest that prompted the pin never showed those vectors being called, so whether its deploy and battle-direction prompts read them stays unverified. Servers built from this version link these emulator fixes; individual games are not re-verified by this change. (#44670)
