### Upgrade notes

- A microVM Keeper now refuses a mounted guest shim built before shims
  declared their relay version, which includes every release shim up to
  0.73.1. Reinstall the shim built from the same source as the server:
  `scripts/install.sh --version v<server version>` for a release, or
  `scripts/remote-ssh/build-shim.sh` for a checkout build, as
  `docs/MICROVM-REMOTE-RUNBOOK.md` describes (#52973).

### Fixed

- A microVM Keeper whose mounted `masc-exec-shim` speaks another relay version
  than the server no longer boots a guest that the host then refuses, nor
  replaces a running guest with one that mounts the same shim. The server
  reads the relay version out of the shim's bytes before it stops or boots
  any guest and reports `microvm_shim_relay_version_mismatch` with the
  reinstall command (#52973).
