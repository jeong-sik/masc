### Documentation

- `docs/spec/00-glossary.md`: the glossary now carries an **Ego Browser Companion** entry that separates the installed native `ego-browser` command, the optional `ego-browser` package and the observation Lane Add-on it publishes, and states that installing the package adds no `BrowserSession` backend, no worker tools and no native Bash for a generic Keeper `Execute` sandbox. It also fixes the contract vocabulary: six `OPERATIONS`, the success statuses `observed`/`postcondition_met`/`closed`/`retired` and the failure statuses `rejected_before_effect`/`outcome_unknown`, each bound to its operation (#44813).
