### Changed

- H2 connections on the cleartext and TLS listeners no longer advertise server push (RFC 9113 §8.4). `transport.h2_initial_window_size` and `transport.h2_max_frame_size` in `runtime.toml` set the per-stream window and the largest accepted frame; both default to the h2 library values (65535 and 16384) (#49863).
