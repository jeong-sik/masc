### Added

- `masc_keeper_delegate_targets` reads the chat queue and the live turn of up to 16 named Keepers, so a Keeper can compare delegate targets before it calls `masc_keeper_delegate`. Each row carries `queued_count`, `oldest_queued_age_s` while work waits, and `turn_age_s` while the Keeper is inside a turn. The `target_turn_age_s` in the delegate result comes from the same read. The tool is deferred, so a request carries its schema only after the model asks for it by name. 가이드 없음(문서 없음) (#50446).
