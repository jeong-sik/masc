### Changed

- The server streams its log ring at `GET /api/v1/dashboard/logs/stream`, which takes the `/api/v1/dashboard/logs` query and sends that route's answer as SSE frames with a `reset` flag: a reset frame replaces the client's list, the others carry only entries newer than the last frame. The TUI System logs view follows it while it shows the server's logs instead of reading 300 entries every two seconds (#48107).
