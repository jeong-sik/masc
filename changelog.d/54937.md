### Fixed

- A Keeper tool call's observation now records the file the tool opened: it
  resolves the call's cwd and then its path through the same function the file
  tools use, so a relative `repos/…`, `.masc/…` or `playground/…` path under a
  `cwd` is no longer attributed as if the cwd were absent, and a Docker
  container path maps onto the same host mount the tools use (#54937).
