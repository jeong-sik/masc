### Upgrade notes

- A Lane declaration runs a `host_process` package, reads a `snapshot_file`
  outside the workspace, holds record grants or reads an operator-only source
  only when it carries `operator_authority = true`. Add that line to each such
  declaration under `<config root>/lane-addons/`; until then reconcile reports
  an issue for it. An earlier build rejects the line as an unknown field, so
  remove it before rolling back (#55493).

### Fixed

- Reconcile no longer attaches every Shared Lane declaration as operator
  configuration. An unmarked declaration runs with the least authority that
  could have saved it, so a manifest, snapshot or upstream that changes after
  a Keeper's save no longer reaches a host process, a file outside the
  workspace or operator-only output. Only the operator can save
  `operator_authority = true` (#55493).
