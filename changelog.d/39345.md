### Added

- The deployment gate judges the live runtime.toml with the incoming build before installing it, through `masc-deployment-preflight-helper validate-runtime-config --base-path`: the raw save check (Keeper setting schema, `Runtime.validate_config_text`), the `[fusion]` table as Fusion runs load it, boot's runtime initialisation (refused when it would disable a runtime, leave a Keeper without its runtime or leave an exact-output slot out) and boot's exact-output registry step without publishing. A value such as `[skills] resource-read-max-bytes = 65536` after #39040 stops the deploy with the file and the key. A missing runtime.toml passes where boot's own config-root bootstrap would write it, and otherwise only with `--allow-empty-workspace`. (#39345)
- `scripts/deploy.sh` runs that check (`--runtime-config-only`) before it stops the previous prod, and again under the lease. `scripts/install-local-build.sh` runs it before it replaces any binary, and now needs the workspace to check through `--base-path` or `MASC_BASE_PATH`. (#39345)
