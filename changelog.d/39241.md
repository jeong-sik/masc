### Added

- A Keeper lane that runs one turn through `muse serve` (`Keeper_muse_runtime`).
  The Keeper's MASC tools reach the session through the loopback MCP bridge,
  the official-client session store records the Muse Code session under the
  new `muse` client kind, and `turn/completed` usage is reported as a turn
  total. No runtime selects the lane yet (#39241).
