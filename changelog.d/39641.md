### Added

- `D` on Config > runtime.toml removes a Claude Code, Codex or Antigravity
  account. The screen lists the tables it deletes, the lane and exact-output
  lane slots and vision runtimes it leaves, and the keepers that go back to
  the default, or why it refuses. Enter removes the account from the file as
  the server holds it and saves through the preview; if that file would
  change differently from what the screen showed, nothing is saved and the
  new changes are shown. The login store stays on disk (#39641).
