### Fixed

- The TUI no longer draws the `/health?full=1` fleet placeholder, which the
  server sends while its health snapshot is warming, timed out, or the fleet
  scan raised, as a fleet of zero Keepers. The Keepers header and the Metrics
  readiness line say "not measured (<status>)", with the refresh timeout and
  the server's reason when there is one (#38474).
- A fleet reading (`schema` `masc.keeper_fleet_operator.v1`) now requires every
  count and name list the TUI draws; a missing one fails to decode instead of
  reading as zero, and an unknown schema is refused (#38474).
