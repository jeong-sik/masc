- Read preserves JSON integer line coordinates and rejects malformed or unrepresentable offset/limit values before filesystem access, instead of returning the file head as a successful read. #41932
- Rejected Read values that cannot be JSON-encoded still produce a normal caller error response. #41932

### Changed

- Move pure Read argument decoding to its line-window owner and remove the runtime's private copy of filesystem-guidance constructors. #41932
