### Fixed

- The TUI runtime table no longer says a spent account twice. A runtime
  resting for its provider quota (a quota refusal or a usage read that found
  the window spent) read `한도 소진 (…)` and then `계정 한도 소진` on the same
  row; on the row the rest, which carries when it ends, now says it alone.
  The rest names one end, so a usage reading with several windows shows each
  window's reset only in the Overview providers view. A payment refusal still shows the
  account limit beside it (#53403).
