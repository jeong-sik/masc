### Documentation

- RFC `librarian-history-original-holds-what-it-read`: a completed-history Librarian original keeps the read range verbatim and points at each source prefix (checkpoint messages, official trace rows, turn boundaries) by `{count, digest}`, which the commit-time source lock recomputes from the live source. Today one pass that reads a 210 B turn allocates about 1,150 times the checkpoint size because the original holds four whole-history copies (#46390).
