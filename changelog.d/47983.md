### Added

- An agent that owns an Ego Space can release a pending native input lock itself
  with `BrowserAct action: "release_input"` (`generation` from `space_status`,
  `confirmation: "checked_and_released"`), recorded as `keeper_asserted`
  readiness. `space_status` now reports `inputLock` (state, who and when held,
  the release path, the last refused release). Experimental. Guide:
  `docs/guides/ego-native-workflow.md`, "Releasing a pending input lock as the
  owning agent" (#47983).

### Fixed

- A refused Ego input-reset confirmation now says why (a stale generation names
  both generations, a running command, a client or Space mismatch) instead of
  only "not applied" (#47983).
