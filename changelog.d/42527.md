### Fixed

- `masc_runtime_ollama_probe` no longer advertises a `think_policy` parameter. It predates the chain that ended in the #30040 TOML migration and was carried along as a dead declaration through `lib/tool_local_runtime.ml` → `lib/tool_schemas/tool_schemas_local_runtime.ml` → TOML (#20203, #30040), but no code ever read it — the handler reads only `think_mode` and `think` — so a caller passing `think_policy="enabled"` got a successful call with thinking silently left off. The dead declaration is removed; the working knobs are unchanged (#42527).
