## 화면과 남은 범위

같은 LibreOffice·글꼴 환경에서 첫 열의 과도한 줄바꿈이 줄었다.
한글용 글꼴 대체는 WenQuanYi Zen Hei였다. 원본 한글 글꼴과 같다는
판정이 아니다. 행 높이·셀 여백·글꼴·머리말·페이지 전체는 복원하지 않는다.
한글과 Microsoft Word 앱의 화면·인쇄는 이번에 직접 실행하지 않았다.
한 twip보다 좁아 반올림하면 0이 되는 양의 열은 HWPX도 출력할 수 없다.

고정 Core로 HWPX를 다시 저장하는 별도 진단에서 기존 차트 연결 손상이
재현됐다. 원본의 관계 파일이 사라지고 워크북 이름이 바뀌면서 참조가
그대로 남는다. 기존 병합 출력과 후보 4종에서 같았고 손실 보고는 0이었다.
[후속 이슈 #52637](https://github.com/jeong-sik/masc/issues/52637)에 기록했다.
현재 MASC의 직접 HWPX 어댑터는 이 Core 재저장 경로를 거치지 않는다.
표는 Core로 다시 저장해도 131개 셀 너비를 보존했다.
