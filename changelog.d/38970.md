### Upgrade notes

- Raw cost-ledger rows (`costs/`, `usage_projection: raw_observation`) now carry `usage_scope`. Raw rows written before this release have none and read as `unavailable`; they are not guessed. Their counts mix scopes by client (Antigravity rows were conversation-cumulative), so they do not add up to a spend. `masc cost` and inference metrics read resolved rows only and are unchanged (#38970).

### Fixed

- An official-client turn that fails after its client reported usage now leaves that report in the cost ledger: Codex's thread count from every `thread/tokenUsage/updated` frame, the Claude Code result frame's turn total, and the Antigravity result's conversation count, each as a raw row under its scope. A turn whose client reported nothing still gets a row saying its usage is missing (#38970).
