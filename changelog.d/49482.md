### Changed

- The TUI Tools catalog lists calls, failures and 95th-percentile latency beside each tool, read from `tool_usage.by_tool` of `GET /api/v1/dashboard/tools`. A catalog entry named by a public spelling such as `Read` takes the row of the tool that lists it in `public_names`; a tool with no row reads `0`, and an envelope with no per-tool counts reads `--`. The columns leave when the terminal is too narrow, `P95` first, so an 80-column terminal draws the catalog as before (#49482).
