### Documentation

- RFC lane-row-offers-actions §2.5: the TUI install form spreads its root over
  the alternatives of a binding schema that is a `oneOf` without `properties`,
  so such a binding is filled one alternative at a time instead of as one JSON
  field. The section states when the spread root accepts the same values; a
  binding outside that condition stays one JSON field (#52310, #52318).
