### Added

- `masc auth bootstrap` writes `<base>/.masc/config/runtime.toml` when the
  workspace has none: the file this release ships, which a single-user server
  writes at its start. A freshly activated account server no longer answers
  `GET /api/v1/auth/integrations` with 503 until the operator writes the file
  by hand, and people can connect a Claude Code subscription. A file that is
  there is kept (#52697).
