### Changed

- **Keeper model input**: on the direct HTTP lane, the tool results and verified arguments of a turn that ended now go as markers from the next turn's first request, whether the carried window stayed or moved (RFC tool-results-age-out-of-context, 2026-11-24 decision J). A window the size signal watched used to keep them whole until the window moved, so a request carried every ended turn's results up to the declared limit. A window that stays now rewrites its prompt cache once a turn, from the first result of the turn that just ended. A request whose turn boundary is unknown demotes nothing, where a window that stayed used to keep the markers it had sent (#55514).
