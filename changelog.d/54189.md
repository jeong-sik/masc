### Changed

- The World Memory Curator walks its lane's HTTP and CLI slots in one
  walk, one slot per step, as the librarian_memory ask does. A full slot
  is passed for a later slot with a free seat, whatever its kind, so a
  free CLI slot answers while every HTTP slot is full. Whether a batch is
  narrowed is read from the slots the walk passed: an answer cut at any
  slot's output budget narrows a classification batch, where before only
  the last HTTP candidate counted (#54189).
