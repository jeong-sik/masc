### Fixed

- A Muse Code, Claude Code, Codex app-server or Antigravity turn whose owner is cancelled while the host is exiting now returns instead of waiting forever on a reap that the cancelled switch can no longer finish; the four runtimes reap the host through `Eio_process_capture.reap_proc_with_clock` (#44529)
- `Eio_process_capture.reap_proc_with_clock` no longer raises when the child's exit status cannot be read after SIGKILL (a failed `waitpid`); it logs a warning and leaves the child to the switch release hook, so a finalizer that stops a host cannot replace the turn's result with that exception (#44529)
