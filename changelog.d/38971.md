### Changed

- A request that the candidate's own policy refuses before it is sent (`Retry.Attempt_rejected`) now shows route class `admission` instead of `attempt_rejected` in Keeper turn records and driver logs. Keeper's Api-error route classes now come from the same `Candidate_fault` judgment that the candidate walks use (#38958), and the route class `attempt_rejected`, which nothing produces anymore, is removed. Lanes behave the same as before: both classes already rotated to the next candidate (#38971).
