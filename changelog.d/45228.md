### Fresh state required

- Original Add-on request records are now `lane.addon.tool-request-owner.v3`. A record names its request body by digest, and the body is a file under `<base>/.masc/lane-addons/tool-request-bodies/`. Earlier records are not read, and the deploy store check refuses each one by file. With the server stopped, move aside every scope directory under `<base>/.masc/lane-addons/tool-request-owners/` (workspace-curator is `5e5665b70b1920c0c1dc7d16ab2b33c8d21773a7a0fab71bed62b03a8dd851e3/`, candle-appraisals is `730f334f72479a09ad59258948bf7ed64bbe4d707bc3c0d1e787baeebe5d7a37/`), and delete the `workspace-curator/` and `candle-appraiser/` directories in the state volumes of those installations (#45228).

### Changed

- An original Add-on request body is written once, before the record that names it. Retain and progress compare the request by its digest. A Workspace Curator successor intent names its child by request ID and request digest instead of holding the whole child capture. A record whose body is missing, changed or not canonical JSON is an error, not absence (#45228).

### Performance

- A progress event on an original Add-on request reads and rewrites only its record, whose size does not depend on the request. Before, each event read, compared and rewrote the whole request (#45228).
