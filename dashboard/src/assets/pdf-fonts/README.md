Sources and hashes verified 2026-10-26. Noto Sans KR regular/bold provide Korean and Latin; Noto Emoji provides monochrome emoji. Missing glyphs are disclosed as Unicode code-point labels. Noto Sans KR has no italic face in this bundle; italic source uses the regular face with a conversion notice. Font bytes and internal family names are unmodified.
