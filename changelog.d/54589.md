### Fixed

### Upgrade notes

- The first Librarian checkpoint written by this version stores sequenced fact changes in the cold archive. A binary rollback after that checkpoint requires an archive reader that understands those rows or conversion of the saved state (#54589).
- A checkpoint retains the latest 2,000 detailed commit sequences and older last-removal evidence per absent fact. Keeper diff reports when a request crosses the folded history or reaches its read or result limit. Retained malformed bytes and conflicting versions remain available for an operator to repair in the private archive (#54589).
