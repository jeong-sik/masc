### Fixed

- A Goal verification original that was left dispatched by an execution that ended without a verdict (its process died, its refusal write failed, or it never saw the reply) now records the run as owner-less and its next scan makes the next attempt under the current authority, instead of stopping on "no automatic replay" forever. A cancelled or retention-failed run end asks again the same way, a raised exception still waits for an explicit `request_complete`, and the Goal-side view reads both new evidence shapes while keeping every other record on its existing reviewer-refusal path (#52577).
