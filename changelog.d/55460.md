### Fixed

- **Board**: a comments, votes, reactions or sub-board source refused because another writer moved its file is read again before the next Board operation, as the posts source already was. On 2026-11-24 every comment write was refused for 123 minutes, until the restart. The first write after the other writer's is still refused once; that refusal is what shows the file moved. Reads that a refused source would refuse (comments, evidence reads, vote lookups, reaction lists, sub-board reads) start from the same check, and `create_sub_board` and `update_sub_board` now do as the other writes did. A write whose outcome is unknown still needs a restart (#55449).
