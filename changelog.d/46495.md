### Added

- Add opt-in per-artifact external sharing for published artifacts: a `POST /api/v1/published-artifact-shares` (`{"id": "artifact-<32hex>", "shared": true|false}`, `CanAdmin`) request and the dashboard `외부 공유 켜기` / `외부 공유 중` toggle turn on and revoke sharing per artifact, and pressing `P` in the TUI Resources detail pane posts the same request and refreshes the reading (#46495). Artifacts stay private by default (`shared = false`, unauthenticated `GET /api/v1/published-artifacts/artifact-<32hex>` answers `401`); when sharing is enabled the same URL serves a read-only external view (`#workspace?section=artifacts&artifact=artifact-<32hex>`) and the TUI badge shows `[외부 공유중]` / `[비공개]`.
  - Usage — 켜는 법: 대시보드 ArtifactReader 의 `외부 공유 켜기` 버튼, TUI Resources 상세에서 `P`, 또는 `POST /api/v1/published-artifact-shares` (`CanAdmin` + workspace precondition). 켜지는 조건과 실패 증상: 요청이 `CanAdmin` 권한 없이 오면 거부되고, 공유가 꺼진 artifact 의 외부 URL 은 `401` 을 돌려준다. 끄는 법: 같은 엔드포인트에 `{"shared": false}` 를 보내거나 `외부 공유 중` 버튼·TUI `P` 로 철회한다. 가이드 없음(대상 문서: docs/design/report-artifacts.md, docs/evidence/2026-10-27-published-artifact-share/README.md).
