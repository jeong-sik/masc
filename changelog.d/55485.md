### Internal

- **Discord**: `Discord_rest_client.send_files` posts one Create Message request as `multipart/form-data` (`payload_json` and one `files[n]` part per file). A file name with a quote, backslash, CR, LF, NUL or slash, a media type outside RFC 6838's restricted-name grammar, or alt text over 1024 characters is refused before any request is built; a boundary that occurs inside a part is redrawn. Nothing calls it yet; #55486 does (#55485).
