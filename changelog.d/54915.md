### Added

- `agent-compaction-threshold` in `[models.<id>]` (a fraction in (0, 1) of `max-context`): an ACP Keeper passes the point to its host when it starts it, so the host compacts its own session during a turn — `-c context_compaction.*` for Muse Code and `AGY_CLI_AUTO_COMPACT_OVERRIDE` for Antigravity. Kimi Code and Mistral Vibe take no such point for every model and refuse the key at load. Absent keeps each host's default (#54915).
