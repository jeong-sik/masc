### Changed

- The standalone lane snapshot (`/api/v1/dashboard/standalone-lanes`, and `exact_snapshot` in `/api/v1/lanes`) no longer carries `exact_run_projection_count`, `exact_run_source_total` or `exact_run_projection_truncated`. Since #51727 they always said every retained run was read. The TUI drops the "Exact run observations are windowed" notice, and the dashboard drops the run-window counts, the window warning above the lane matrix and its "No run in recent window" labels. The schema name stays `masc.standalone_llm_lanes.v2`; a TUI started before this build fails to read the Lane inventory from a server running it until that TUI restarts (#51744).
