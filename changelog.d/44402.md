### Documentation

- The glossary `Assignee` entry now carries the `holder` alias that code comments and tool rejections use for the same person, states which lifecycle statuses have a holder (`Claimed`, `InProgress`, `AwaitingVerification`) and which do not, and separates the holder-only `Release`/`Submission` refusals (`task_release_requires_current_owner`, `task_submit_requires_current_owner`, carrying `current_assignee`) from a plain invalid-transition rejection. It also keeps the machine-controller holder out of this sense (#44402).
