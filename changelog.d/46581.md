### Documentation

- RFC `librarian-durable-message-floor`: §3.8 records how the L3 layer is split into L3a to L3d with the L3e to L5 layers still to come, and what the first four layers settled (message-floor state machine, Runtime step entry, step request, step gate journal with its driver, the served slot, the starting current Memory, and how the host recognizes a step). §3.9 records how a size-refused original descends, publishes in one Memory commit and is cleaned up. The starting current Memory of a first chain is the Memory captured when the chain starts, not the `current` of the original's input. Three points stay open: what to do when Memory changed between the descent and the publication, inventory validation of the step gate journals, and the model call of an enabled gate (#46581).
