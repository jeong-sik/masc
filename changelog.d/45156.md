### Fixed

- A Lane Add-on installation that failed, or is starting, stopping or detaching, is no longer reported as absent. The export and browser readings return every visible installation that cannot serve with its reason from the same read as the usable exports, and the browser host names it ("Add-on installation browser-work (package browser) failed: ...") instead of "no browser Add-on is attached". A held tool export that ended names its own installation's state, a machine screen read reports a detaching producer that no replacement serves, and a consumer's upstream read keeps the producer's failure (#45156).
