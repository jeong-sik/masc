### Removed

- The dashboard no longer reads a `goal_notification` chat delivery key. The server neither writes nor reads that kind, so a chat row that still carries one now reads as an invalid delivery identity, like any other kind the server does not write. The Keeper questions panel, planning focus panel, planning deck and task wall, which no dashboard route mounted, are gone from the source together with the helpers only they used; the built dashboard changes only in the Keeper chat decoder and in the stylesheet, which drops the Tailwind classes only those files used (#55200).
