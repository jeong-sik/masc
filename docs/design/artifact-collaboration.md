# 아티팩트 공동 편집

관련 목표: #45940. 원고 편집·파일 가져오기는 #45957이며, 이 문서는 그다음 공동 편집 층의 계약을 다룹니다.

## 문서와 위치

게시한 HTML·Markdown 버전은 바꾸지 않습니다. 공동 편집은 별도의 공유 원고에서 합니다. 게시할 때만 공유 원고를 읽어 기존 아티팩트의 새 버전으로 저장합니다. 게시 기준 버전이 달라졌다면 기존 publication CAS가 덮어쓰기를 거절합니다.

공유 원고의 본문은 Yjs `Y.Text('content')` 하나입니다. 여러 편집자가 보낸 update는 서버에 저장되고 다른 편집자에게 전달됩니다. 서버가 원고를 처음 만들 때 게시 버전의 본문을 한 번만 넣습니다. 각 브라우저가 같은 초기 텍스트를 독립적으로 삽입하지 않습니다.

Keeper는 문서를 읽은 뒤 받은 상대 위치와 읽었던 문장을 함께 보내 수정합니다. 다른 편집자가 앞에 문장을 넣으면 상대 위치도 원래 문장을 따라갑니다. 선택한 문장 안이 달라졌다면 수정을 거절하고 새로 읽도록 응답합니다. 한글·이모지를 자르는 UTF-16 위치도 거절합니다.

## 현재 위치와 과거 기록

현재 위치는 문서·편집 세션·커서·선택 영역·읽기/편집 상태로 표시합니다. 사용자 이름과 Keeper 이름은 인증된 호출자에서 가져옵니다. CRDT update 안에 actor나 권한을 넣어 신뢰하지 않습니다.

연결이 살아 있는 편집 세션과 Keeper의 실제 실행 문맥을 현재 위치의 근거로 사용합니다. 연결 종료·문서 이탈·Keeper 실행 종료 때 해당 위치를 거둡니다. 재시작 후 과거 위치를 현재 위치로 복원하지 않습니다. 마지막으로 관측한 위치만 있을 때는 관측 시각을 붙인 과거 기록으로 표시합니다.

댓글은 문서 ID·원고 세대·상대 위치·작성 당시 인용문에 연결합니다. 댓글 작성자는 서버가 기록합니다. 텍스트가 지워져 범위가 접히면 원래 인용문을 유지하며, 비슷한 문장을 검색해 다른 위치에 붙이지 않습니다.

## 변환 프로세스

`dashboard/src/lib/artifact-shared-document.ts`가 브라우저와 변환 프로세스에서 쓰는 Yjs 로직입니다. `src/workers/artifact-document.ts`는 stdin으로 JSON 요청 하나를 받아 stdout으로 결과 하나를 반환합니다. 변환 프로세스에는 파일 경로·네트워크 주소·인증 정보·작성자 권한을 주지 않습니다. OCaml 호출자가 작업 공간·인증·문서 잠금·저장·전달을 담당합니다.

`scripts/install-artifact-document.sh`로 self-contained transformer를 설치합니다. Node와 Dashboard의 고정 의존성이 필요합니다. 생성한 bundle은 커밋하지 않습니다. 설치본은 bundle 해시별 디렉터리에 보관하고 launcher를 교체합니다. 이 설치는 서버 바이너리를 갱신하지 않습니다. OCaml 호출자는 변환 프로세스에 30초의 실행 상한을 두고, 상한을 넘은 호출은 문서 오류가 아니라 Unavailable로 되돌려 클라이언트가 재시도할 수 있게 합니다.

## 현재 구현 범위

공유 텍스트 병합, 상대 선택 영역, Keeper의 선택 영역 교체, JSON 변환 프로세스와 focused 검사가 구현되어 있습니다. `masc.artifact_document_engine`은 OCaml 호출자에게 snapshot·상대 선택 영역·오류를 타입으로 돌려줍니다. 변환 프로세스에는 PATH만 전달하며 공급자 인증 정보나 Node 옵션을 넘기지 않습니다. stdout 전체를 별도 파일에서 읽으므로 일반 도구 출력의 미리보기 제한으로 원고가 잘리지 않습니다. 위치는 UTF-8 바이트 수가 아닌 UTF-16 단위로 검사합니다.

독립 경계 검사는 `scripts/dune-local.sh build test/artifact_document_engine/test_artifact_document_engine.exe`로 컴파일합니다. 설치된 실제 변환 프로세스를 포함하려면 실행 파일에 `--transformer /path/to/masc-artifact-document`를 넘깁니다. 인자를 생략하면 요청·응답 경계 검사만 실행합니다.

### 공유 원고 저장과 API

`Artifact_draft_store`는 `<effective MASC root>/artifact_drafts/<artifact-id>.json`에 Yjs 상태를 저장합니다. 본문은 이 상태에서 읽으며 별도 권위로 중복 저장하지 않습니다. 게시 기준 버전·본문 digest·원고 세대·변경 순번·인증된 수정자는 manifest에 남습니다. 원고가 이미 있으면 `open`은 그 원고를 돌려주며 최신 게시물로 덮어쓰지 않습니다.

기존 owned-path·stable-lock·cursor 조건부 rewrite로 저장합니다. 다른 작성자가 먼저 저장한 것이 확인되면 새 상태에 수정을 다시 계산합니다. 선택한 문장이 달라졌으면 교체를 거절합니다. 저장 여부가 불확실한 경우에는 이 재시도를 하지 않고 원고 세대와 시도한 순번을 반환합니다. 메타데이터 손상이나 안전하지 않은 파일 경로는 새 원고 생성으로 숨기지 않습니다.

`GET /api/v1/artifact-drafts/<artifact-id>`는 저장된 공유 원고를 읽습니다. `POST /api/v1/artifact-drafts`는 닫힌 action 계약으로 `open`·`merge`·`select`·`edit` 등을 받습니다. 이 경로와 checkpoint·presence·실시간 이벤트는 HTTP/1과 h2c 게이트웨이에 등록됩니다. 읽기에는 `CanReadState`, 수정·presence에는 `CanBroadcast` 인증이 필요하며 작업 공간 precondition도 검사합니다. 클라이언트가 작성자 이름을 지정하는 필드는 없습니다.

h2c 응답은 리스너 전체 응답 용량을 공유합니다. 인코딩된 문서와 전송 중인 조각을 예약할 공간이 없으면 일반 응답은 빈 503을 반환하고 실시간 이벤트 연결은 끊습니다. POST의 503이나 연결 끊김은 저장 후에 발생할 수도 있으므로 적용 여부를 다시 읽어 확인해야 합니다. 실시간 연결을 다시 열면 전체 상태 전송을 다시 시도합니다. 단일 스냅샷이 설정된 용량보다 크면 용량을 조정하기 전에는 재연결해도 전송되지 않습니다.

정확한 공유 원고를 게시한 후 `POST /api/v1/artifact-draft-checkpoints`에 원고 target, 관측한 sequence, 게시 revision을 전달하면 원고의 기준을 갱신합니다. 본문·형식·순번이 게시본과 다르거나 그 사이 게시본이 바뀌면 갱신을 거절합니다. `already_current`는 현재 원고 기준의 관측이며 이 호출의 저장 영수증은 아닙니다.

`select`는 문서 ID·원고 세대·상대 위치가 묶인 selection을 반환합니다. `edit`는 이 selection과 읽었던 문장을 받아 그 문서에 적용합니다. Yjs의 원고 끝 위치는 다른 문서에서도 해석될 수 있으므로 원시 상대 위치만으로 문서를 선택하지 않습니다. Dashboard API 호출부도 응답의 문서·세대·selection 대상이 일치하는지 검사합니다.

실제 transformer와 영속 저장을 포함한 검사는 `scripts/dune-local.sh build test/test_artifact_drafts.exe` 후 `_build/default/test/test_artifact_drafts.exe --transformer /path/to/masc-artifact-document`로 실행합니다. 인자가 없으면 schema 검사만 실행합니다.

### 공동 편집 화면과 댓글

Dashboard의 공동 편집 화면은 원본 편집과 HTML·Markdown 문장 편집을 지원합니다. 실시간 연결에서 확인한 편집자와 Keeper의 상대 위치를 원고에 표시하며, 문서 이탈·연결 종료·Keeper 실행 종료 후에는 현재 위치로 표시하지 않습니다. `keeper_artifact_draft`로 Keeper도 같은 공유 원고를 읽고 수정하며 댓글과 제안을 남깁니다.

Keeper는 같은 워크스페이스의 게시 문서를 `keeper_artifact_draft`의 `find`로 찾을 수 있습니다. 검색은 제목·요약·각 버전 작성자·Task·Goal의 후보를 돌려주며 문서의 동일성을 결정하지 않습니다. 페이지 커서는 질의와 일치한 게시 목록 및 읽기 오류에 묶입니다. 일치 결과나 읽기 오류가 바뀌면 검색을 다시 시작하고, 무관한 문서의 게시에는 이어서 읽습니다. 목록은 항목별로 읽으므로 검색 도중 다른 게시가 있으면 오류가 없어도 빈 결과가 원자적인 부재 증명은 아닙니다. 두 작성자가 동시에 새 문서를 게시하면 각각 생성될 수 있습니다. `published`는 기존 문서의 최신 게시 원문과 이력을 읽고, `open`은 남아 있는 공유 원고에 들어갑니다. 원고의 기준 버전과 최신 게시 버전이 다를 수 있으므로 게시 전에 둘을 확인합니다. 워크스페이스 내 공유와 로그인 없는 외부 공개는 별도입니다.

문서 형식은 공유 원고를 시작한 게시 버전에서 가져옵니다. 최신 게시물의 형식이 달라졌어도 기존 원고를 그 형식으로 해석하지 않습니다. 기준 버전이 현재 열린 게시물과 다르면 해당 버전을 작업 공간에 묶어 읽고, 원고에 기록한 본문 digest와 일치하는지 확인합니다.

Markdown 미리보기에서 글을 누르면 선택한 부분의 원문 문법을 고칠 수 있습니다. 표·목록·굵은 글씨·링크·각주의 위치는 GFM 파서의 원문 위치에서 가져옵니다. 입력한 Markdown은 그대로 반영하며 선택 범위 밖은 다시 직렬화하지 않습니다. 같은 글이 반복되어도 문자열 검색으로 편집 위치를 정하지 않습니다. HTML 문장 편집에서는 입력한 글을 HTML 텍스트로 이스케이프합니다. 두 형식의 미리보기는 같은 격리 정책과 해당 미리보기에만 유효한 선택 표식을 사용합니다. 원본의 스크립트·이동·전송 기능은 실행하지 않습니다.

문장을 선택한 뒤 **선택한 원문에 댓글**로 댓글이나 변경 제안을 작성합니다. 편집창을 떠나도 댓글을 붙일 선택 영역은 유지하지만, 이를 현재 편집 위치로 계속 알리지는 않습니다. HTML 문장 편집에서 제안한 글은 HTML 텍스트로 이스케이프합니다. Markdown 문장 편집과 원본 편집에서 제안한 글은 원문 그대로 보냅니다. 제안 반영은 댓글과 본문을 한 번에 저장하며, 선택한 원문이 달라졌으면 반영을 거절합니다. 반영·거절 시 대화는 해결 상태가 되며 다시 열 수 있습니다. 게시된 버전은 별도로 **새 버전으로 게시**할 때만 갱신합니다.

댓글 입력은 브라우저에 복구본으로 보관합니다. 전송 시에는 요청 ID와 내용을 고정합니다. 응답을 놓치면 **전송 결과 확인**으로 저장 기록을 읽거나 **같은 요청 다시 보내기**를 직접 선택합니다. 같은 문서·원고 세대·작성자·요청 내용이 확인된 기록에 한해서만 복구본을 지웁니다. 화면을 다시 열었다는 이유로 요청을 자동 전송하지 않습니다.

입력을 복구할 때는 선택 시점의 미전송 원고를 합치고, 내용을 확인한 뒤 댓글을 보냅니다. 다른 작업 공간의 복구본은 섞지 않으며, 다른 원고 세대의 입력은 다운로드만 허용합니다. 문장 입력은 HTML·Markdown 형식도 함께 보관하며, 현재 형식과 다르면 다운로드만 허용합니다. 브라우저 저장 공간이 부족하면 현재 탭의 메모리와 이전에 저장한 사본을 유지하고 다운로드를 안내합니다. 각 입력 버전은 별도의 저장 키를 사용하므로 다른 탭의 이전 응답이 새 사본을 지우지 않습니다.

이 구현과 focused 검사 성공은 실제 브라우저 공동 편집 검증이나 운영 설치 증명이 아닙니다.

설계 근거: [Yjs document updates](https://docs.yjs.dev/api/document-updates), [relative positions](https://docs.yjs.dev/api/relative-positions). 공식 문서에서 update의 순서 독립성과 상대 위치 동작을 2026-10-25에 확인했습니다.

Markdown 위치와 렌더링은 [mdast-util-from-markdown](https://github.com/syntax-tree/mdast-util-from-markdown), [GFM 확장](https://github.com/syntax-tree/mdast-util-gfm), [mdast-util-to-hast](https://github.com/syntax-tree/mdast-util-to-hast)의 공식 문서와 고정 설치본을 2026-10-26에 확인했습니다. 원문 위치는 원래 입력에서 계산하고 HTML 변환·격리는 표시용 사본에만 적용합니다.
