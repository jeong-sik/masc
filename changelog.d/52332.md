### Documentation

- Operator quiz guide, RFC operator-quiz-follows-lesson §3.8 and the package README: `since` is
  where a session that follows a lesson reads a record source from until a session that asked
  has left a cursor on that source. A `records` item added later under a new `source_id` is
  read from `since` too, and so is one whose read from `since` found no record, unless the
  host passed over commits no pull request merged (`github_pulls`) and so gave a cursor. A
  `source_id` taken out and put back is read from the cursor it had. A quiz that had asked
  before a lesson was bound reads on from its cursors, and a record the lesson cites from
  before them is not read. The operator lesson guide says the same of a lesson, and its
  macOS `date` command now gives midnight: given a date alone, `date -j -f` fills in the
  current time of day. The guide's
  install snippet lists `sources = []` last: replaced in place by a lesson source, as the guide
  says to, the old order made `language` and `timezone` keys of the source item and the host
  refused the declaration. The guide lists, in the order the host checks, the sentences a
  refused declaration gets: the TOML parser's, the one for a date or time value, one per
  mistake in a source item, and a single one for every binding the package schema refuses
  (#52319). `test_lane_addon_config` pins each quoted sentence. The RFC says the trial's
  256 MiB was the trial copies' limit, not the manifests' 128 MiB (#52332).
