### Changed

- Admit independently settled Memory candidates in one supported disposition while retaining deferred inputs, preserving sparse receipts and avoiding immediate retries of evaluated leftovers. (#42020)

### Fresh state required

- The explicit Memory admission queue file `<keepers dir>/<keeper>.memory-admission.json` now records `last_sequence`, and a queue file written by an earlier development build does not decode. Until it is removed, explicit Memory writes for that Keeper fail and its admission worker reports unavailable on every pass. `install-local-build.sh` checks only `runtime.toml`, so find these files with `masc-deployment-preflight-helper validate-stores --base-path <base>`. With every server stopped, confirm each file's `pending` list is empty, move the file out of the keepers directory, then start this build. Any input still in `pending` is lost by this step. (#42020)
