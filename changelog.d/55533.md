### Changed

- **Keeper addressing**: a workspace broadcast mention now reaches the Keeper a
  Board post to the same name reaches. A Keeper whose `mention_targets` leave
  its own name out no longer receives a broadcast by that name; another Keeper
  that lists the name receives it, and when none does the mention is rejected as
  `Target_not_configured`. The broadcast path, the chat lanes and the Board
  router now read one rule, `Keeper_lane_mentions.effective_target_ids`, so the
  delivered row's mentions are that Keeper's addresses instead of its name plus
  its list (#55533, #46853).
