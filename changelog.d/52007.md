### Changed

- Command lines now find the workspace's server through the kernel before they send a bearer: `masc restart`, `masc setup-server` and `setup-stop`, the first authorization, `masc runtime-resume` and `masc config set` send the operator bearer only to the process the kernel names both as the holder of the workspace lease and as the announcer of the port (#51807). From the port they read the version only; the workspace path is no longer read from `/health`. A server that announces no port (a binary older than #51807, or one bound on another address) is not taken for the workspace's server: the command says which of the causes may apply and sends nothing. Use the command line of the same build as the server, and restart the server once after installing (#51075, #52007).
