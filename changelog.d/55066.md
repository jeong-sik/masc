### Fixed

- An ACP Keeper on Kimi Code now sees a compaction the host made during a turn even when the turn then grew past the previous turn's count: Kimi Code sends one `usage_update` per prompt, after the response, so the Keeper also counts the `context.apply_compaction` records the prompt added to the host's session record (`agents/main/wire.jsonl` under `KIMI_CODE_HOME` or `~/.kimi-code`, protocol version 1.5). Before, the settlement kept the held context and the next turn sent only what had changed to a session that held a summary (#55066).

### Changed

- A turn whose compaction record could not be read (the Kimi Code session record or the Muse journal) now settles like a compacted turn: the next turn sends the whole World State again, and the Keeper logs why. Before, an unreadable Muse journal counted as no compaction (#55066).
