### Fresh state required

- Keeper metadata no longer carries `trace_history` or `last_handoff_ts`; both were always empty or zero. Earlier versions wrote both keys into every Keeper meta file, so every existing `<base-path>/.masc/keepers/<name>.json` is rejected as not current with `runtime reset required`. Stop the server and confirm it has exited, remove the two keys from each file (for example `jq 'del(.trace_history, .last_handoff_ts)'`), then start it again; the other fields, including turn, token and cost totals, are kept. Skill activation owners report only `current_meta` or `runtime_manifest` (#39025).
