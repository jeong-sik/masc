### Fixed

- `scripts/install-local-build.sh` brings a workspace's release guest exec
  shim to the release the built server names, checked against that release's
  `SHA256SUMS`. Only `scripts/install.sh` placed the shim, so a workspace
  deployed from local builds kept the shim of its last release install. A
  hand-built shim (no sidecar) is left alone, an unreadable release leaves the
  shim and continues with one WARN, and an asset that fails its checksum
  installs nothing (#42733).
- `scripts/install-local-build.sh --help` prints the whole usage block
  (#42733).
