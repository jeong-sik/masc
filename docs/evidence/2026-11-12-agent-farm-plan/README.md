## 가린 것

- 이 묶음은 원본의 파생본이다. 원본은 이 저장소에 없다. 파생본 바이트가 원본과 같다고 주장하지 않는다. 원본의 sha256 은 아래와 같다.

  | 원본 | sha256 |
  | --- | --- |
  | `audit-final.json` (감사 Workflow 결과) | `0af90f96bbdbfee601fac89ebff412b51d7d26b3f6bb872faaf3de3ba64c6135` |
  | `research-final.json` (조사 Workflow 결과) | `ef9035db6ec91cd6de04d8c3f7ba8e5139655919ad63954c50b31c69d070a61b` |

- 경로는 일반화했다. 세션 임시 폴더는 `<scratchpad>`, 저장소는 `<repo>`, 런타임 루트는 `<base-path>`, 홈은 `<home>` 이다. 이 묶음에 없는 감사 원문을 가리키던 좌표는 `감사 원문(영역)` 으로 바꿨다.
- 접근 경계 영역 둘(`dashboard-authz`, `sandbox-remote`)은 빈틈 세부, 검증 agent 가 더한 항목, 지울 후보의 근거를 싣지 않았다. 다른 영역의 보안 항목 셋(`external-tools-multimodal-01`, `-07`, `tools-paradigm-05`), 지울 후보 하나도 같다. 결정은 영역과 무관하게 접근 경계에 닿는 열하나를 가렸다. 가린 것은 빈틈 26건, 더한 항목 9건, 지울 후보 12건, 결정 11건이다. 수리가 `main` 에 들어간 뒤 세부를 싣는다.
- Candle 영역(`candle-economy`)도 빈틈 세부, 더한 항목, 지울 후보의 근거, 결정의 정석 쪽 답과 대가를 싣지 않았다. Keeper 는 Candle 지급 규칙을 모른다(운영자 결정 10). 이 저장소의 PR 은 Keeper 가 읽는다. 가린 것은 빈틈 12건, 더한 항목 5건, 지울 후보 2건, 결정 8건이다. 이 세부는 나중에도 싣지 않는다. 지급 경로는 사용자와 독립 리뷰어가 따로 다룬다.
- 가린 행에는 한 줄 제목과 `withheld` 칸만 있다. 지울 후보는 제목 대신 대상 이름이나 종류가, 더한 항목은 번호가 있다. `withheld` 칸의 글이 두 이유 가운데 어느 쪽인지 적는다. `counts.py` 는 영역으로 둘을 갈라 센다.
- 다른 영역의 문장이 가린 내용을 되풀이한 곳은 종류만 남기고 고쳐 썼다. 접근 경계 12곳, Candle 지급 경로 8곳이다. 운영자 설치나 조사 세션의 사정을 적은 문장 8곳은 그 부분을 뺐다. 다른 영역의 더한 항목 4건과 지울 후보 1건은 아직 고치지 않은 문제의 좌표와 닿는 조건을 빼고 종류만 남겼다. 운영자 설치의 상태, 비공개 기록의 내용, Candle 코드와 설정의 위치를 적은 곳 25곳도 그 부분을 뺐다. 운영자의 비공개 기록을 가리키던 인용 14곳은 `운영자 비공개 기록` 으로 바꿨다. `domains.json` 의 세 영역(`dashboard-authz`, `sandbox-remote`, `candle-economy`) 요약도 같은 이유로 다시 썼다. 고쳐 쓴 수는 이 묶음을 만든 스크립트가 센 값이고, 이 묶음만으로는 다시 셀 수 없다.
