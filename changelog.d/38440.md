### Internal

- `scripts/ci/changelog-section.py` can refuse a release body GitHub would cut. GitHub keeps the first 125,000 characters of a release body and drops the rest without an error. The v0.37.0 page stopped mid-word: the section was 127,523 characters and the appended generated notes 44,716 more. `--max-chars` exits 1 and writes nothing when the body is too long. `--append` places the generated notes after the section and counts them, so the limit is measured on the body GitHub stores. Without the flags the output is unchanged. Wiring the flags into `release.yml` is a workflow change the operator applies (#38440).
