### Changed

- A commit made in a Keeper sandbox (Docker, Micro_vm, Remote_ssh) carries the
  Keeper's name as git author and committer: the runtime sets
  `GIT_AUTHOR_NAME` and `GIT_COMMITTER_NAME` next to `GH_CONFIG_DIR`, and the
  exec shim refuses both names in an endpoint `env_file`. Emails are unchanged.
  A running keeper-lifetime Docker container picks the names up once it is
  recreated; a Remote_ssh endpoint needs this release's shim (#38253).
