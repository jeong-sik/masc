## (3-c-3) 결정적 사실 — 제품과 시험이 같은 커밋에서 함께 생겼다

```
$ git log --format="%H %s" --diff-filter=A -- lib/play/play_invite.ml
1e5740024c6cd84b6e75cfe40b21fd91b2fa0cdc fix(keeper): ride turn-entry admission on the tail carrier (#47781)

$ git show --numstat --format="" 1e5740024c -- lib/play/play_invite.ml
347	0	lib/play/play_invite.ml
```

`lib/play/play_invite.ml`(제품 347줄)과 `test/test_play_invite.ml`(시험 262줄)이 **같은 커밋 `1e5740024c` 에서 처음 생겼다.**

## 이게 (b) 판정에 주는 것

- 제가 앞서 쓴 "제품이 나중에 바뀌어 유효 케이스를 거부하게 됐다"는 **성립하지 않는다** — 둘이 같은 커밋에서 태어났으므로 "나중에 바뀐" 시점이 없다.
