### Documentation

- The Tools efficiency evidence folder splits Execute overhead by sandbox,
  replays the remote SSH preflight cache for a pair of lifetimes, sizes the
  queue wait that overlaps long Execute calls, and counts the Execute calls
  that ran the same command again and got the same answer or only read the
  clock. The last count goes per Keeper and per UTC hour, next to the model
  requests and input tokens of the same Keeper, and says how many of the
  repeats ran in the same turn as the run before. Tests and the results of the
  2026-11-06 to 2026-11-08 windows come with it (#50021).
