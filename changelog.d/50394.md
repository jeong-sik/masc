### Changed

- The Keepers memory and age views draw cells of their own on the axis row. The memory view draws the turn pulse, how the librarian's last pass ended, then the unread turns as a bar against the Keeper furthest behind, the time since the last digest and the gap. The age view draws the facts by age in the server's four bins, the time since the memory last changed, then the unread-turn bar, the invalidated sources and the fact count. A value the server did not measure draws `?`, and a Keeper without a readable memory row draws `mem ?`, `mem !` or `—` instead of a value (RFC-0515 V6, #50394).
