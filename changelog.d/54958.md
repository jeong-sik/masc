### Removed

- Keeper runtime-trace screens no longer show the manifest row count as a total. The number counted rows inside the server's last 1000-6000 lines of the manifest, not the file, so a long trace read as `500/6000` looked like a 6000-row file. The dashboard runtime lens drops its `manifest rows` N/M row, the turn flow shows only the returned row count, the runtime summary drops `manifest M`, and the TUI keeper dive and Flow tab show `Manifest: N` and `Runtime trace events (N)`. The runtime-trace response drops `manifest_total_rows` at the top level and in `runtime_lens.turn_clock`; `manifest_total_rows_exact` stays for the turn-flow intake check (#54958).
