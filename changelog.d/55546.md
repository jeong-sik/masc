### Fixed

- A refused Board source (posts, comments, votes, reactions, sub-boards) is now also read again once the lock file beside its file is repaired, and once at the next Board call when a write refused it rather than a read. A cause that lasts (a lock file with the wrong mode, a changed workspace directory) is met by one read instead of one at every Board call. While a Board deletion waits for a fresh store, such a source is neither read nor logged (#55546).
