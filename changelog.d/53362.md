### Fixed

- The JSONL files a Keeper keeps beside its dated stores (decisions, feedback, the TLA trace, runtime manifests) have one writer, and that writer now makes the file's directory inside the write. Each caller made it first, or did not: the TLA trace writer made none. A feedback row whose directory cannot be made comes back as an I/O error; it left as an exception. (#53362)

### Performance

- Writing a decision row, a feedback row or a runtime manifest no longer looks, on the caller's fiber, whether the keepers directory is there. That look was an Eio `stat` for every row written. (#53362)
