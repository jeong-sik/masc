What the audit found

P1

Native calls vanish

Native tool calls do not cross the MASC dynamic-tool callback. Claude drops tool_use, Codex drops command/file deltas, Antigravity keeps only anonymous counters.

P1

Cumulative usage looks live

Antigravity conversation totals are divided by a per-request context window. Live analyst rose from 795.7% to 831.1% across eight completed turns.

P1

Tools is global, not effective

The actor reaches the cache key but is discarded by inventory generation. Keeper groups, native posture and composition skills are absent.

P2

Configuration ownership is hidden

Keeper config cannot patch tools.native/groups; Antigravity is hidden from structured runtime protocol metadata.

P2

Flat Goals advertise hierarchy

The Goal record has no parent and every TUI depth is zero, but masc_goal_upsert still promises parent linkage.

P2

Skill references are hopeful

Task creation trims skill names but does not prove the directory, frontmatter agreement or effective Read capability.

Completion triggers

Native evidence

Claude, Codex and Antigravity fixtures persist a typed native tool event distinct from MASC tools. Full posture never claims MASC approval.

Context evidence

The historical 831.1% row remains untouched; new exact-revision turns either show a valid per-request ratio or an explicit cumulative/unavailable reason.

Surface parity

Two Keepers with different group/native/skill declarations produce different tool rows and digests, both equal to their real runtime bundles.

Release evidence

Exact source, binary digest, focused tests, required CI, new raw trace/TurnRecord and TUI captures exist in one evidence bundle.

Non-goals

  • Rewriting historical TurnRecords
