### Fixed

- `masc_runtime_ollama_probe` no longer advertises a `think_policy` parameter. The tool migration in #30040 introduced it as a third thinking knob beside `think` and `think_mode`, but no code ever read it, so a caller passing `think_policy="enabled"` got a successful call with thinking silently left off. The dead declaration is removed; the working knobs are unchanged (#42527).
