### Added

- **Discord**: a Keeper can send a stored audio file as a Discord voice message, a playable waveform. `keeper_surface_post` takes `as_voice_message: true` with exactly one id in `attachment_ids`; the text goes first as its own message, because Discord allows no text on a voice message. `keeper_voice_speak` now also stores its clip as the Keeper's attachment and returns `attachment_id`, so a spoken reply can go to Discord as voice. MP3, WAV, Ogg, M4A and WebM are accepted; MIDI is refused before approval because it holds notes, not sound. The server needs `ffmpeg` on its `PATH`; without it the post fails before anything is sent. A Discord post's files now become durable only when the whole post passes the check before approval, so a refused post leaves them as they were (#55505).
