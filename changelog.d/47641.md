### Fixed

- Live Board loads no longer require `board_posts.initialized.jsonl`. A workspace without that file, including a new one, can post, comment, vote and react again without an offline `masc workspace-upgrade board-posts` step. A posts file that disappears while the server runs is still refused. A server that starts without a posts file starts an empty Board, and queued Keeper Board events that point at posts from the missing file are consumed instead of held. (#47641)
