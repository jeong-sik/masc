### Fixed

- Server shutdown no longer waits 2 seconds for each child process of a Keeper turn it stops. The official-client CLI or Execute command of that turn now gets SIGKILL at once, because nothing waits on the stopped turn. Every other cancellation still sends SIGTERM and waits the 2-second grace first. A stopped child gets no TERM handler, so git may leave `.git/index.lock` behind (#49684, #49923)
