### Performance

- A successful call to a worker tool that lists MCP `annotations.readOnlyHint: true` no longer schedules a fresh Add-on observation, and does not mark the cached observation refreshing while it runs. The DOS worker lists the hint from `Machine_controller_contract.call_effect`, so a guest seat polling `masc_dos_screen` no longer copies and retains a frame per poll; error replies and tools without a hint still refresh (#46305).
