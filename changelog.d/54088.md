### Upgrade notes

- Rebuild the dashboard bundle together with the server. The dashboard keeps a closed list of builtin lane ids and rejects a lane snapshot that names one it does not know, so a bundle built before this change shows no lane inventory (#54088).
- A workspace that declared `librarian_memory` to run the World Memory curator declares `[runtime.exact_output_lanes.workspace_memory_curator]` to keep it running (#54088).

### Fixed

- Declaring `[runtime.exact_output_lanes.librarian_memory]` no longer starts the World Memory curator on the Librarian's slots. The curator asks through its own builtin lane, `[runtime.exact_output_lanes.workspace_memory_curator]`, and asks no model without that table (#54088, #53982).

### Added

- Builtin exact lane `workspace_memory_curator` (Optional, Background, no run records). The TUI and the dashboard lane inventory show its row (#54088).

### Removed

- The `Workspace_curator` constructor of `Standalone_lane.caller_lane`: the curator is the standalone lane `Workspace_memory_curator` (#54088).
