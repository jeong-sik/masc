### Fixed
- `keeper_image_read`, `keeper_analyze_image` and peer-artifact reads now report a sandbox path that does not exist or is not a regular file as a refusal (`path_not_found` / `path_not_a_file`, `workflow_rejection`) instead of a runtime failure; real transport or capture faults stay `runtime_failure`. Exception: on profiles that capture through the Turn_runtime binary capture (which accepts only exit 0), the missing-path sentinel still surfaces as `Read_failed`. (#44089)
