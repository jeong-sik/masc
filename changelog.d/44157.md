### Changed

- A saved prompt preset whose `exact_output_lanes` key names no exact-output lane is refused when it loads. Before, restoring it wrote a `[runtime.exact_output_lanes.<key>]` table that the next runtime load refused. The runtime TOML parser already refused such a table; only the preset reader is new. (#44157)

### Internal

- An exact-output lane declaration carries a typed owner instead of a free `id` string; the registry key, the `[runtime.exact_output_lanes.<id>]` table name and preset keys are derived from it in one place, and `Blank_lane_id` is removed because nothing can produce it. Wire strings are unchanged. (#44157)
