### Documentation
- RFC `keeper-guest-survives-restart`: a server restart keeps each Apple keeper guest instead of deleting and booting it again. The startup sweep held the lifecycle lock for 591–757 s while it deleted every guest of the previous process, and each fresh boot's helper exit then stalled the container API server. A guest carries a boot-plan label that start compares with `container inspect`; the GitHub credential copy lives with the guest; the sweep removes only guests no declared keeper produces. RFC `keeper-boot-runs-no-one-shot-container` is corrected where it attributed the restart stall to the helper alone. (#44677)
