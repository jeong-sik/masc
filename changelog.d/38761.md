### Added

- `masc sandbox-image promote <name> <reference> [--runtime R]` records a
  built image as the current build of a catalog name for that image store,
  reading its digest from the store and keeping the build it replaces;
  `masc sandbox-image rollback <name>` returns to that previous build. The
  catalog lives in `<base-path>/.masc/config/sandbox-images.toml`. Keepers
  do not read it yet (#38761).
