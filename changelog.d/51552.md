### Fixed

- The approval auto-merge worker closes a linked issue once per merge. An
  issue that was closed after the merge and reopened stays open when the
  worker meets the merged pull request again: on a recheck, or when a stack
  whose lower layers landed earlier lands the rest. A recheck of a merged
  pull request sends only the closes that are still missing, and every pull
  request and issue the worker could not decide gets its own record (#51552).
