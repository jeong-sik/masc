### Added

- The glossary gains a Board Attachment entry: a typed reference a Board post carries, with `kind` (image|video|youtube|external_link) and exactly one source — an absolute HTTPS `url` or an existing artifact `sha256`. The post handler is the only writer, the Keeper tool and HTTP paths share the input, and the retired raw `meta.attachments` slot is named as a boundary (#38957, closes #38833).
