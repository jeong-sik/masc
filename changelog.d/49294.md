### Changed

- The daily tool blob scan also reads the Librarian working context
  (`<keeper>.working-context.json`) and its recall index
  (`<keeper>.working-context-recall.json`) in the config `keepers/`
  directory, each through the decoder of the module that writes it. A blob
  either file names is no longer a sweep candidate, and the two files leave
  the `unclassified` list. A file of either kind that does not decode ends
  that day's scan with an error and no candidate record. Nothing is deleted
  (RFC-0499 scope layer). 가이드 없음(docs/rfc/RFC-0499-tool-blobs-are-swept-inside-the-server.md) (#49294).
