### Removed

- The 1Password add-on no longer offers Browser login. It exports only
  `onepassword_status` and keeps the operator connection controls. Its
  `connection-config.json` accepts only `client_id`, `client_secret_file`,
  `redirect_uri` and `store_directory`; a config that still has
  `browser_extension` reads as invalid until that key is removed (#48690).
- Lane Add-on workers can no longer negotiate a `lane_companion` grant, and
  the Lane call context has no `companion` field. The browser worker's private
  `extension` command and reply are gone (#48690).
- Operator control views open only HTTPS links (#48690).
