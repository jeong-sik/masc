### Added

- `agent-compaction-threshold` in `[models.<id>]` (a fraction in (0, 1) of `max-context`): an ACP Keeper on Muse Code passes the point to its host when it starts it (`-c context_compaction.*`), so the host compacts its own session during a turn. Antigravity, Kimi Code and Mistral Vibe take no such point from MASC and refuse the key at load; Antigravity's `AGY_CLI_AUTO_COMPACT_OVERRIDE` reaches its interactive client but not `agy acp`. Absent keeps each host's default (#54915).
