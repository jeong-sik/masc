# Original Ask follow-up comparison reader source boundary

| Boundary | As-Is | To-Be in this source |
|---|---|---|
| Client JSONL | Retained original structured facts, no consumer | Offline exact-discriminator reader and JSON/Markdown report |
| Denominator | No machine cohort model | Independent declared roster unioned with all selected observed reads; absent records retained |
| Outcomes | Original typed producer/UI facts | Distinct complete/failed/cancelled/withdrawn/not-started/unfinished/unobserved/invalid counts |
| Timing | Original admission/worker/producer/release/UI clocks | Same-process original-read intervals, missing-stage facts and observed/all coverage |
| Comparison | Manual inspection | Declared-condition matching and exact descriptive deltas; execution verification always false |
| Artifact failures | No Ask report | Errors plus preserved known case/arm/attempt denominator; no success-only filtering |

The producer, Main startup, authority, result publication, cancellation,
projection, decoder and persistence sources are unchanged. This consumer reads
actual integer Int64 JSON clocks and explicit details.event, not console text or
the separate startup string-clock contract. It keeps source snapshots opaque
and never labels read completion as original Task useful progress.

The independent packet roster cannot prove its own completeness. Wholly
unrecorded undeclared attempts remain unknown. Missing stage rows remain missing
facts; producer/UI outcomes can differ. Initialization spans remain separate,
without PID-based instance attribution or fabricated cold-start totals. All
outcomes remain in denominators even when only some have durations. Hash-verified
bytes and equal declarations are not execution/install identity or a speed verdict.

The parser rejects ambiguous selected transport facts and unsafe/mutated supplied
artifacts; this is offline evidence handling, not a Keeper runtime gate. It adds
no runtime configuration, timeout, retries, counters, execution budget or UI flow.
Existing inputs are not overwritten. Reader costs include reading/hash checking,
JSON validation/indexing, retained raw rows and report serialization; no memory or
runtime speed measurements are claimed.

One actual protocol/resource case was authored using two private real workspaces,
canonical Ask/answer/Task/wake/frame/decoder/result producers, the production store
and emitter, copied actual JSONL artifacts, and the public reader CLI. A real
missing-switch read and an independently admitted undispatched read must remain
not-started and unobserved, while another instance's actual complete read remains
complete. Unknown comparison conditions must not become matching/execution
proof. Mutating an actual copied artifact must invalidate evidence while keeping
known attempts and canonical resources. These are protocol/resource assertions,
not logger/helper invocation counts or synthetic log-row tests. The case invokes
only the offline Python reader when later executed. It has not been executed.

Validation is Python AST parsing only, OCaml parsing only for the scenario, source
inspection and diff whitespace. No report, tests, typecheck/build, CI, native/
model/controller/audio/PTY run, install/restart, live write, approval or merge.
No real Before/After packet or rendered report has been generated by this unit.
The guide defines the packet contract and manual command. All six original axes
and actual measured comparison/visible UI requirements remain open.
