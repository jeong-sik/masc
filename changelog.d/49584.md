### Upgrade notes

- The macOS arm64 release binary is now built on the `macos-15` runner, because GitHub retired `macos-14` on 2026-11-02 and jobs on that label are cancelled before a runner is assigned. No workflow sets a deployment target, so the arm64 binary is expected to need macOS 15 or later from this release on, as the x64 binary already does (v0.68.0 arm64 minos 14.0, x64 minos 15.0) (#49584).
