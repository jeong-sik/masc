### Changed

- ACP Keepers show a context gauge from the context the host reports its session holding (`usage_update.used`). Each driver profile declares what that number is: the newest request's counted input plus output (Antigravity, Kimi Code, Mistral Vibe, recorded as `agent_held_context`) or the host's own prompt estimate (Muse, recorded as `context_estimate`). Muse's journal-counted last request input rides in its own field and is recorded as `measured_request` (#54872).

### Fixed

- The ACP rollover no longer reads a turn's summed `inputTokens` as the session's size when the host sends no `usage_update.used`; with no count it does not roll over (#54872).
