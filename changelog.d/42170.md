### Added

- The MASC server records the Keeper Firefox it starts in `.masc/browser-lane/keeper-firefox.json` right after starting it, before waiting for its port: the process group, when its first process started, the profile and the port. A Firefox it cannot record is stopped. A server whose `runtime.toml` has no `[browser.live.bidi]`, or has `[browser.live] enabled = false`, stops that Firefox, and no other process, when the process its group is numbered after still runs with the recorded start in that group; otherwise it leaves it running and logs why. A server starts no Keeper Firefox over a record whose group may still run, or over one it cannot read. A server that loaded no runtime configuration stops nothing. Before each signal a group stop checks that the group's number still names the group it meant, and a stop that reaches SIGKILL waits up to a second for the group to empty; a group whose processes this account may not signal is never taken for gone (#42170).
