### Documentation

- The glossary now defines the three terms the MIDI source editor uses: `MIDI source asset` (the imported SMF/RMID document kept as original bytes plus source-event edits, not a reduction into the Phrase schema), `Source port` (the 0–127 routing identity the source file carries, bound to a destination only by an explicit `:midi-port` or `:midi-output` session selection) and `Source audition` (ordered playback of the source wire stream, which refuses clip looping and, on stop, releases only the keys and hold pedals it owns) (#44378).
- The `Source port` entry also separates the recording option's `SOURCE_ID`, which names a CoreMIDI input source, from the source port it looks like (#44378).
