### Changed

- A runtime binding whose model has no AGENT_CORE catalog row, under a provider the catalog has a row for, is now an exact-output slot when its model declares a `[models.X.capabilities]` table; the slot answers with the capabilities the binding's Keeper turns run on. A Tinker `tinker://` sampler checkpoint is the first such model. Without the table the slot is still left out as `Target_not_in_catalog`, and a binding whose provider has no catalog row is still left out (#50026).
