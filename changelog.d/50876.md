### Added

- `prompt_compare.py` decides whether a keeper-librarian prompt draft goes in, and `prompt_lines.json` fixes its comparison before any draft runs, as RFC-0517 §2.3 asks: the two Inkling baseline runs of the current prompt, the runs per side and the noise widths (worse below -2.5σ, better above +2σ). A draft goes in when no metric of Inkling or GLM gets worse and the memory state, stale drops or merges improve on Inkling. It refuses runs of different drafts on different models, and a run listed twice or copied from another run (#50876)
