### Changed

- Pinning ocaml-msx #52 makes the server serve SNSMAT `0x0141`, GTSTCK `0x00D5` and GTTRIG `0x00D8` from the plain-CALL trap and record whether a served vector's caller returned into ROM or RAM. Sangokushi II's second-unit deploy and battle-direction prompts read those vectors, so a build on the previous pin could not report arrow keys at all. Servers built from this version link these emulator fixes; individual games are not re-verified by this change. (#44670)
