### Added

- A BiDi browser host given `--firefox-profile PATH` keeps a session only with a Firefox that reports running that profile (`moz:profile` in the session's capabilities, both paths resolved), and otherwise ends the session and stops with the profile it found in its record. The MASC server passes the configured `[browser.live.bidi]` profile to the host it starts, so a port answered by the everyday Firefox does not give a Keeper that profile (#42151).
