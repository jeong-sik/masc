### Documentation

- Keeper Firefox RFC: `docs/rfc/RFC-browser-keeper-firefox.md` proposes that the MASC server start the dedicated-profile Firefox and its BiDi host when `runtime.toml` has a `[browser.live.bidi]` table: at boot it starts only what is missing and leaves both running across server restarts, and a Keeper's hover or drag starts them again when no BiDi connection is listed; no code changes (#42108).
