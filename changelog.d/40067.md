### Performance

- The provider-scoped model catalog lookup (`Model_catalog.lookup_for_provider_result`, behind every capability read for a runtime that names its provider) reads an index built with the catalog instead of scanning every row: 2.18 µs -> 0.11 µs per lookup over the repository catalog. `/api/v1/runtime/resolved` makes about 60 of these lookups per request.
