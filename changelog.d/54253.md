### Added

- A server route now has to be named by the account gate's inventory before it can answer, and the inventory is read from the router's own route table (`Server_account_route`) rather than from registration sites, so a route reached through a helper or a prefix cannot fall outside it. A path no entry covers is refused (`Server_account_gate.decide`), and a boot check reconciles the inventory: empty, no keeper prefix, or one path with two accesses stops it (`Server_account_gate.reconcile`). Keeper sub-routes are covered by their prefix. No route's access changes in this layer (#54253).
