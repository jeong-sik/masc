### Changed

- A `masc_board_post_get` result whose text equals an earlier result of the same turn now
  goes to the provider as one line, `[masc:same-result first_tool_use_id="..." bytes=N
  sha256=...]`, on lanes whose requests MASC assembles; the first result stays whole and
  the tool's description says what the line means. The rule (RFC-0510) has been in the
  request assembly since #52335 with no tool declaring it. Over 2026-11-21..27 the stored
  last requests of 9,825 turns carried 9,824 same-turn repeats of 2,048 B or more, and
  7,932 of them (57.9 MB of 65.3 MB) were this tool's. The ledger, the stored history and
  the other tools are unchanged; removing `same_turn_result_stub = true` from the tool
  file turns it off (#55390).
