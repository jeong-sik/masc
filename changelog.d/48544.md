### Added

- `GET /api/v1/dashboard/keeper-memory-health?keeper=<k>` answers one Keeper's memory health row, the element the fleet answer carries for it; an unlisted Keeper is a 404 and an empty name a 400. The fleet totals and alert summary are counted by one module that the server answer and the TUI decoder's check both use, and an alert keeps the severity it was made with instead of reading it back from its JSON (RFC-0487 L1, #48544).
