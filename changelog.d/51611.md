### Internal

- The keeper-librarian prompt comparison reads its baseline as numbers. `prompt_lines.json` (schema v2) holds each model's baseline as hits over chances for the seven metrics, each run's E-real record and the sha256 of the rows they came from, so `prompt_compare.py compare` no longer reads the baseline's run folders or its judges' decisions; `prompt_compare.py baseline` prints the baseline that runs of the pinned template counted. A baseline names the provider and the model it was counted for and the pass lines, the template and the `prompt_counts.py` it was counted under, and a file that names another of them is refused. A draft run that holds the rows a pinned baseline was counted from is refused. `prompt_lines.json` is read as written: a key the comparison does not read, a key written twice in one object or a value of another shape is refused. A v1 `prompt_lines.json` is refused, and `runs.json` lists one list of runs per model (#51611)

### Fixed

- `prompt_compare.py` classes a difference of exactly a noise width as the same. It compared floats, and a rounding error called 18 of the 75 such pairs of equal chances up to 260 worse or better (#51611)
