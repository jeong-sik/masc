### Upgrade notes

- Connector state moved from `<base>/.gate/runtime/<kind>/` to
  `<base>/.masc/connectors/<kind>/`, and the old location is no longer read.
  Before restarting on this version, stop the server and move each
  `<base>/.gate/runtime/{discord,imessage,slack,telegram}` directory to
  `<base>/.masc/connectors/`. A connector whose directory is not moved starts
  with no bindings, so its channel messages reach no Keeper. Move the whole
  directory: an iMessage binding moved without its `cursor.json` re-reads
  Messages.app from ROWID 0 and delivers the bound conversation's history
  again. Paths set through `MASC_*_BINDING_STORE_PATH`,
  `MASC_*_BINDING_AUDIT_PATH`, `TELEGRAM_BINDING_*_PATH` or
  `MASC_IMESSAGE_CURSOR_PATH` are unchanged (#55239).

### Fixed

- Discord, iMessage, Slack and Telegram bindings, binding audits and poll
  cursors default to `<base>/.masc/connectors/<kind>/`. The workspace tree and
  file routes no longer list or serve them, and a container that keeps only
  `.masc` on a volume keeps them across a recreate (#55239).
