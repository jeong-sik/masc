### Fixed

- **Board**: a comments, votes, reactions or sub-board source refused because another writer moved its file is read again before the next Board operation, as the posts source already was. On 2026-11-24 every comment write was refused for 123 minutes, until the restart. The first write after the other writer's is still refused once; that refusal is what shows the file moved. The read happens where a caller takes the store (`Board_dispatch.backend`), so every Board operation starts from it, including the comment read of a Keeper's world observation. One predicate, `Board_posts_source.fresh_read_can_clear`, says which refusals are read again: a cursor or content mismatch, a path that changed during the operation, and a lock another writer held. A refusal for a torn tail or a second hard link is not read again, for posts as well: the next read would meet the same file. A write whose outcome is unknown and a pending deletion still need a restart (#55460, refs #55449).
