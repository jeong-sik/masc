### Fixed

- The outermost catch-all of a Claude Code or Antigravity turn re-raises
  `Out_of_memory`, `Stack_overflow` and `Sys.Break` instead of typing them as
  `internal_unhandled_exception`. It logs the backtrace of any other exception
  it types, because the typed error keeps only the exception text. Callbacks
  and stream reads inside the turn still type these three (#39824).
