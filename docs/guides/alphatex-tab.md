# alphaTex 악보와 재생 (TUI)

> **상태: 실험 기능** — 하위 호환 약속이 없습니다. 문법·화면·동작은 v0.56.0
> 이후에도 바뀔 수 있습니다.

TUI 어디에서든 ```alphatex 또는 ```atex 코드 펜스가 들어간 텍스트(Board 글·댓글, Keeper
직접 채팅)를 만나면 ASCII 타브라튜어(tablature)로 그립니다. 기타를 치는
사람이 Board에서 코드 리프나 릭(riff)을 주고받을 때, 텍스트로는 읽을 수
없는 운지를 화면에서 바로 보려는 기능입니다.

## 전체 악보 열기와 재생

Keeper 채팅에서 `/score`를 입력하면 현재 불러온 대화의 가장 최근 완결된
`alphatex` 또는 `atex` 블록을 같은 터미널의 전체 악보 화면으로 엽니다.
`/score 2`는 그 앞의 악보입니다. 원문을 고정한 뒤 열며, 종료하면 대화로 돌아옵니다.

이 화면은 공식 **alphaTab 1.8.4 + alphaSkia 3.5.147**을 사용합니다. 다중 트랙·보표·성부,
오선보·타브·숫자보·슬래시·타악기·연주 효과를 자체 부분 문법으로 축소하지 않습니다.
지원 범위와 잘못된 문법의 판정은 고정된 공식 엔진 버전을 따릅니다. 단순 검사 통과를
모든 가능한 악보의 정확성으로 보장하지는 않습니다.

Node.js 22 이상과 pnpm이 있는 환경에서 `scripts/install-alphatex.sh`로 보조 프로그램을
설치합니다. 설치 경로를 바꾸려면 `--prefix /path/to/bin`을 지정합니다. TUI를 실행한
환경의 PATH에 `masc-alphatex`가 있어야 합니다. Ghostty·Kitty·WezTerm처럼 Kitty 그래픽을
지원하고 셀 픽셀 크기를 응답하는 터미널이 필요합니다.

| 키 | 동작 |
|---|---|
| ↑/↓ 또는 j/k | 현재 시스템 스크롤 |
| PageUp/PageDown, [ / ] | 뷰포트 이동과 다음/이전 시스템 |
| Home/End | 전체 악보 처음/끝 |
| + / - | 기보 크기 조절 |
| t | 전체 트랙과 개별 트랙 순환 |
| ←/→ | 대화에 저장된 이전/다음 악보 |
| Space | 선택 트랙 재생·일시정지·재개 |
| s | 재생 중지 |
| v | 원문과 공식 오류 진단 읽기 |
| q 또는 Esc | 대화로 돌아가기 |

공식 AlphaSynth가 반복·길이·음색·연주 효과를 PCM WAV로 합성하며, 로컬 afplay·ffplay·aplay·SoX
중 가능한 플레이어로 재생합니다. 기존 `[tui] midi_soundfont`가 있으면 사용하고, 없으면
공식 패키지의 Sonivox SoundFont를 씁니다. 닫을 때 재생과 worker를 끝내고 임시 파일을
지웁니다. 재생 위치를 따라 움직이는 커서는 아직 없습니다.

베이스는 예를 들어 다음처럼 씁니다. `tabs`는 복수형이며 `tab`은 공식 문법에서도 오류입니다.
alphaTex 1.8에서는 메타데이터 뒤의 별도 `.` 구분자를 생략할 수 있습니다.

```alphatex
\title "반음 연결 연습"
\instrument 34
\tuning (G2 D2 A1 E1)
\staff {score tabs}
\clef bass
\tempo 80
\ts 4 4
:4 5.3 7.2 7.2 :8 3.2 4.2 |
:2 5.2 {d} :4 r
```

이음줄(tie) `{t}` 같은 노트 효과는 프렛·줄 바로 뒤, 길이 점 앞에 둡니다.
`7.4{t}.8`은 앞 음과 이은 8분음표이고, `7.4.8{t}`처럼 길이 뒤에 쓰면 공식
엔진이 `AT205 Unrecognized property 't'` 오류로 거부합니다.

프렛 자리에 `-`를 쓴 `-.4.8`도 이음줄이고, 쉼표가 아닙니다. 공식 엔진은 같은 줄의
앞 음을 다시 치지 않고 이어서 끌어 줍니다. 쉼표는 `r`, `r.8`로 씁니다.

## 채팅 안의 ASCII 미리보기

악보 펜스 안에서 지원하는 기본 문법은 다음 지시자와 노트 토큰입니다
(masc_tui_alphatex_score.ml `directive_of_word` 직독):

| 지시자 | 인자 | 화면 효과 |
|---|---|---|
| `\title "…"` | 따옴표 문자열 | 헤더에 제목(`"Riff"`) |
| `\subtitle "…"` | 따옴표 문자열 | 헤더에 제목 뒤 부제(`"Warm-up"`) |
| `\tempo 96` | 숫자(BPM) | 헤더에 `♩=96` |
| `\ts 4 4` | 숫자 둘 | 헤더에 `4/4` |
| `\tuning (G2 D2 A1 E1)` | 고음 줄부터 음이름 목록, 괄호 생략 가능 | 베이스 4줄 등 지정한 튜닝 표기 |
| `\instrument 34` | 기타·베이스 GM 프로그램 24–39 또는 표준 악기명 | 명시한 `\tuning`을 유지해 본문 TAB을 그림. 음색은 재생에만 사용 |
| `\ro` | 없음 | 도돌이표 시작 `|:` |
| `\rc 2` | 반복 횟수 | 도돌이표 끝 `:|x2|` |
| `\ae (1 2)` | 괄호 숫자 목록 | 대체 엔딩 브래킷 `1,2|` |

`\subtitle "…"`는 제목 뒤 헤더에 부제로 그립니다. 제목처럼 마지막에 말한
`\subtitle`이 이깁니다. `\artist "…"`, `\ks C#minor`, `\clef bass`,
`\section "…"`도 읽습니다. 이 메타데이터는
프렛·줄·길이를 바꾸지 않으며 ASCII 탭에는 따로 표시하지 않습니다.
`\clef`는 `treble` `bass` `alto` `tenor` `neutral`(또는 `g2` `f4` `c3` `c4` `n`)만 받고,
오선보 기호일 뿐 TAB 줄에는 영향이 없습니다.
`\ks`, `\clef`, `\section`은 첫 음표 앞이나 명시적인 마디선 `|` 다음에 적습니다.
음표 앞의 단일 `\track "Bass" { instrument "Electric Bass Finger" }`와
`\staff { tabs }`도 읽습니다. 악기를 지정하면 `\tuning`을 명시해야 합니다.
두 번째 트랙·보표, 음표 뒤의 트랙·보표 선언, 지원하지 않는 속성은 원문과 이유를
보여 줍니다. 여러 악기의 독립적인 마디를 하나로 이어 그리지 않습니다.

노트는 `프렛.줄` 한 쌍입니다. 기본 기타 튜닝의 줄 번호는 **1 = 고음 e 줄, 6 = 저음 E 줄**이고
표준 alphaTex와 같습니다. `:4 0.1 3.2 5.3 0.4`는 "4분음표 4개: e줄 0프렛,
B줄 3프렛, G줄 5프렛, D줄 0프렛"입니다. 띄어쓰기로 여러 노트를 이어 쓰고
`|`로 마디를 나눕니다.

프렛 대신 `-`를 쓴 `-.4`는 이음줄입니다. 같은 줄에서 가장 최근에 나온 음을 찾아 그 프렛을
괄호에 넣어 `(7)`처럼 그립니다. 사이에 쉼표나 다른 줄의 음이 있어도 건너뛰고 찾습니다.
찾는 범위는 공식 엔진(alphaTab 1.8.4)과 같이 그 마디와 앞의 세 마디입니다. 그 안에 이을 음이
없으면 미리보기는 그리지 않고 이유를 보여 줍니다. 공식 엔진은 이 경우를 오류로 보지 않고
개방현(0프렛)으로 연주합니다. 쉼표는 `r` 또는 `r.8`처럼 씁니다.

악보 상단에는 지시자가 말한 것을 한 줄로 적습니다 — `\tempo` BPM, `\ts` 박자,
`\title` 제목, `\subtitle` 부제 순서로 ` · `로 이어
`♩=96 · 4/4 · "Riff" · "Warm-up"`처럼 그리고, 넷 다
없으면 헤더 줄 자체가 없습니다. 그리고 각 줄 묶음(시스템)의 맨 위에는 물리
마디 번호가 1부터 올라갑니다. 시스템이 여러 개여도 번호는 이어집니다.

## 켜는 법과 켜지는 조건

별도 설정이 없습니다. 펜스 태그 줄의 첫 단어가 `alphatex` 또는 `atex`이면 켜집니다
(`bin/masc_tui_markdown.ml` `is_alphatex_tag` 직독):

- 첫 단어가 `alphatex` 또는 `atex` — 펜스 태그 줄에서 앞뒤 공백을 떼고 소문자로
  비교합니다. ```AlphaTex 나 들여쓰기된 태그도 인정됩니다.
- 선택 옵션 `rhythm` — 태그 줄에서 `alphatex` 뒤에 `rhythm` 단어를 함께 적으면
  (예: ```alphatex rhythm) 리듬 줄을 더 그리고 상단 머리글을
  `alphaTex 악보 (리듬)`으로 바꿉니다(`alphatex_rhythm_word`).

지원 문법 밖의 지시자(`\album` 등)를 만나면 렌더링을
중단하지 않고, 지시자 원문과 함께 이유를 적은 fallback 상자로 보여 줍니다:

```
┌─ alphaTex 악보 ──────────────────────────────
│ ASCII preview: the \album directive is not in the subset
│ \album "nope"
└──────────────────────────────────────────────
```

## 실행 예시 (개발판 main, 2026-10-14 실측)

### 예시 1 — 최소 펜스

```
```alphatex
\tempo 96 :4 0.1 3.2 5.3 0.4
```
```

Board 본문과 채팅 양쪽에서 실제로 그려진 화면(렌더러 출력 실측, 2026-10-14,
60칸 창 — 펜스 상자 머리글과 코드 색은 생략하고 그려진 행만):

```
♩=96
  1
e|0---------------|
B|----3-----------|
G|--------5-------|
D|------------0---|
A|----------------|
E|----------------|
```

헤더(`♩=96`)와 첫 마디 번호(`1`)가 올라간 것을 볼 수 있습니다.

### 예시 2 — 도돌이표와 대체 엔딩

```
```alphatex
\title "Riff" \tempo 92 :4 0.6 3.6 5.6 3.6 | \ro :4 5.6 3.6 0.6 3.6 | \ae (1 2) :4 7.6 5.6 3.6 0.6 | :4 8.6 7.6 5.6 3.6 \rc 2
```
```

같은 세션에서 실측한 화면:

```
♩=92 · "Riff"
  1                 2                    3
e|----------------|:----------------|1,2|----------------|
B|----------------|:----------------|1,2|----------------|
G|----------------|:----------------|1,2|----------------|
D|----------------|:----------------|1,2|----------------|
A|----------------|:----------------|1,2|----------------|
E|0---3---5---3---|:5---3---0---3---|1,2|7---5---3---0---|

  4
e|----------------:|x2|
B|----------------:|x2|
G|----------------:|x2|
D|----------------:|x2|
A|----------------:|x2|
E|8---7---5---3---:|x2|
```

두 번째 줄 묶음의 마디 번호가 `4`로 이어지는 것이 포인트입니다.

## 어디서 볼 수 있는가

- **Board 글·댓글**: Board 탭(Tab 링 5번째)에서 글을 열어 본문을 스크롤
  (`j` 키)하면 펜스 위치에서 그려집니다.
- **Keeper 직접 채팅**: 메시지 본문의 펜스가 그려집니다. `[tui]` 설정의
  `opening = "keeper"` + `opening_keeper = "이름"`을 쓰면 시작하자마자 그
  Keeper의 채팅이 열려 확인이 빠릅니다.

## 실패 증상과 뜻

| 화면 문구 | 뜻과 처방 |
|---|---|
| `ASCII preview: the \<지시자\> directive is not in the subset` | ASCII 미리보기 범위 밖입니다. `/score`로 공식 엔진의 전체 악보와 재생을 엽니다. 이 문구만으로 공식 문법이 틀렸다는 뜻은 아닙니다. |
| `ASCII preview: one measure needs N cells and this pane has M` | ASCII 미리보기 폭이 부족합니다. `/score`에서 확대·스크롤해 읽습니다. 표시를 위해 원래 마디를 바꿀 필요는 없습니다. |
| 펜스가 그냥 텍스트로 보임 | 태그 첫 단어가 `alphatex` 또는 `atex`가 아닙니다(예: `alpha`, `tab`). 첫 단어를 고치세요. |

## 끄는 법

스위치가 없습니다. 태그를 지우거나 `text`로 바꾸면 해당 펜스는 평범한 코드 펜스로 돌아갑니다.
렌더링은 읽기 전용 동작이라 화면 표시 외에 아무 상태도 바꾸지 않습니다.
