### Changed

- The librarian_memory ask walks its HTTP and CLI slots in one walk, one
  slot per step. A full slot is passed for a later slot with a free seat,
  whatever its kind, so a free CLI slot answers while every HTTP slot is
  full. Before, CLI slots ran only after every HTTP slot had failed. Two
  CLI slot outcomes are new: a slot passed because a later slot gave a seat
  first is `Silent Not_called`, and a slot that cannot take the question or
  whose account published no seats is `Silent Unavailable` (#54024).
