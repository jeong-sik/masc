### Fixed

- A Gecko browser that leaves its automation worker, for example by
  relaunching itself to apply a staged update, no longer blocks the browser
  Add-on. On each configuration pass the host removes the free profiles of
  ended instances under their lock, sends SIGTERM to the process that holds
  one, and SIGKILL on the next pass if the same process still holds it. The
  allocation is released without a worker-written receipt (#45411).

### Fresh state required

- The `automation-closed.json` receipt and the allocation `profiles/`
  directory are gone. An allocation left by an earlier build is refused once;
  retain it through `POST /api/v1/lane-addons/retain` after the upgrade
  (#45411).
