### Added

- `Authz_zone`, the writer zone that appends one record to the authorization log while masc runs. Each commit first closes the intent that an earlier entry left, with the judgment that a start makes, and refuses to write when the external store and the log disagree. It then refuses a record that `Authz_state` refuses, writes `Intent_pending`, the record and `Committed` for a mode event, and publishes the state with the record. No caller uses it yet (multi-account B3b, #48270).
