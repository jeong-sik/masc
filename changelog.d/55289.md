### Fixed

- Pausing, resuming or seeking an imported MIDI performance on an external MIDI output no longer re-sends the current Program Change under a bank that playback sent after it. When that Program Change was selected before the source set a bank register, and playback has since sent that register, reconstruction reports an error before sending anything instead of guessing the device's initial bank. Entering a MIDI arrangement region and repeating a rendered VST region refuse the same way when that Program Change comes before the region's start (#55289).
