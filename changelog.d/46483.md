### Changed

- A job submitted through `Executor_pool_ref` without a weight takes 0.2 on the HTTP read pool instead of 1.0. Reads were measured to use about 0.18 of a core while they run, and Eio's executor stops admitting work once its jobs' weights reach 1.0, so two reads waiting on I/O used to fill the read pool while its domains were idle. A read pool worker now holds five such reads. The shared pool's default and any weight a caller passes are unchanged (RFC-0474 L4a, #46483).
