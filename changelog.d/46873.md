### Added

- `masc config set KEY=VALUE ... --base-path P` writes keys of `runtime.toml`. KEY is a dotted key the settings registry names, such as `autonomous.enabled`; a key it does not name is refused. VALUE is read as the key's kind (boolean, integer, float or text) and refused when it is not. A workspace with no `runtime.toml` is seeded the way server start seeds it. Several assignments are written in one commit or not at all, and comments and other tables are kept. What a value means is not checked here: the server refuses a blank wake prompt or an unusable DNS address when it starts. 가이드 없음(docs/ENV-CONTRACT.md) (#46873).
