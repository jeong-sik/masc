### Changed

- The Keeper log, Connectors, saved preparation record and composer row views no longer draw a "refreshing" or "rechecking" sentence while a read runs over a value they already hold. Local reads (Keepers roster, Work tasks, chat live context) now count in the reading slot, and the Keepers and Work headers no longer draw a stage row for a slow local read. The slot draws only reads started on the open screen, so a slow local read started on another screen is drawn nowhere once the Keepers or Work screen shows a held list (#54221).
