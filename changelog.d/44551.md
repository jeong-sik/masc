### Fixed

- The Codex runtime no longer records a `commentary` agent message as the turn's answer. A message's phase now decides its role: `final_answer` is the answer, `commentary` is narration that reaches the stream but not `text`, and `partial_answer`, a missing phase and an unrecognized phase (logged with its string) stay answer candidates. A turn that ends with narration only returns an empty `text`, which Keeper acceptance rejects like any blank reply. (#44551)
- Streaming deltas of a Codex agent message are kept per unfinished item instead of being appended to one shared fallback. When an item completes, an answer candidate keeps its text and commentary drops it, and an item that only the `turn/completed` items list names as commentary is dropped too. (#44551)
