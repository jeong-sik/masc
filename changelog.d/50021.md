### Documentation

- The Tools efficiency evidence folder splits Execute overhead by sandbox,
  replays the remote SSH preflight cache for a pair of lifetimes, sizes the
  queue wait that overlaps long Execute calls, and counts Execute calls that ran
  the same command again and got the same answer, per Keeper and per UTC hour,
  next to the model requests and input tokens of the same Keeper. It comes with
  tests and the results of the 2026-11-06 to 2026-11-08 windows (#50021).
