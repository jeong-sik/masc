### Exempt

- Docs only: adds an RFC that keeps a finished message's size once per Keeper and message encoder. Stage 1 (#55268, #55397) keeps one table per Keeper name and encoder for the life of the process, bounded by 64 MiB of measured encoding length per table, and accepts that memory grows with the number of Keepers and encoders; owner release, a process-wide heap bound and key identity follow in later stages (task-4169, task-4167, task-4168). No user-facing behavior change (#55240).
