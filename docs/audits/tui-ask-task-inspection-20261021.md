cursor. `o`, `h/H`, `v`, `r`, `b` and Esc use the shared inspector. The Ask origin
section records its association, not original question text unavailable in the
submission receipt. It is not a Task creation receipt or Task/Goal completion
proof. Binary submissions retain metadata/preview captions; pixels are not drawn
by this diagnostic reader.

link and can request a fresh independent read. Unlinked/missing answer identity
cannot open the inspector. Global Task rows and current composer Keeper selection
do not supply a replacement. Creation-history navigation remains creation-only.
The same Ask reuses observations across health refreshes by canonical workspace
paths, not by incidental whole health-record equality.

## Source preservation checks

- Original Task, history page/cursor and verification ids remain exact query
  inputs; producer and strict decoder are unchanged.
- Submission evidence retains operator access and original Task/submission
  validation; observation does not authorize mutations.
- Original answer owner is the existing submission request token. Canonical
  answer/stimulus and Task link are checked before opening/current admission.
- A request must still be the pending object for its original owner, current
  viewer, workspace authority/read scope and current source ticket.
- Ask and creation bindings cannot cross. Ask lookup never manufactures a
  creation ticket; creation lookup still requires a ready single receipt.
- Main cancellation uses the captured pending job; new answer dispatch retires
  an Ask-owned reader before replacing the submission. Physical cleanup is not
  inferred from model retirement.
- Failure retains last source observations. Task absence is not deletion; Task
  status and verification evidence are not Goal completion.
- Actual answer writers, wake delivery, Task lifecycle, history and proof
  producers are unchanged. No live/runtime mutation was performed.
- The old creation-only reader module/library was renamed with all direct
  consumers and Dune dependencies; no compatibility alias remains.
