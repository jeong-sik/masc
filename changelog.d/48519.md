### Performance

- `masc_dos_*` results return `screen_text` without the spaces after each row's
  last glyph and without the empty rows after the last glyph. The machine pads
  its text page to 25 rows of 80 columns, and a program that draws in a graphics
  mode leaves that page blank, so every result carried about 2 KB of spaces. In
  the stored requests of 2026-10-29 to 11-04 all 4,764 pages were blank, and
  the trim would have removed 265.6 MB, 2.30% of the request bodies (#48519).
