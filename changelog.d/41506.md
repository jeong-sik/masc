### Changed

- Board attention ledgers no longer grow with consumed work for a keeper's whole life. A drain now rewrites the candidate ledger without the Consumed rows whose Board signal the keeper's Board cursor has already passed — the same token the replay gate compares, so a removed row can never be re-minted by replay — and the same drain, like process-start recovery, drops settled partition receipts whose candidate is terminal on the candidate ledger. An unreadable candidate ledger, or one with rows the decoder refused, keeps every receipt (#41422, #41506).
