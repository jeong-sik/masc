### Added

- A TUI Overview Team row shows the pull requests on its Keeper's checkout branch, by number and a checks glyph (`#38078✓`: ✓ passing, ✗ failing, ◐ running, · none; more than one adds `+N`), ahead of the row's cause or Task so a narrow row keeps them. Only pull requests the server joined to that Keeper by exact head branch are attached; a pull request the server has not joined (`keepers: null`) is attached to no Keeper (RFC-0465, #38168).
