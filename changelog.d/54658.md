### Fixed

- A `muse_code` session no longer fails at `session/new` when the operator's muse settings or a `.mcp.json` the host loads define an MCP server named `masc`. The host refuses a session server that has the name of one it already has (-32030), and MASC named its bridge `masc`. The bridge is now `masc_keeper` for `muse_code`, so the model sees MASC's tools there as `mcp__masc_keeper__<tool>`; the other drivers keep `masc` (#54658).
