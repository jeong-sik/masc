### Added

- Sixteen OpenRouter free (`:free`) models that support tools now have AGENT_CORE catalog rows and `runtime.toml` bindings (`openrouter-free-*`), so the operator can add them to the end of a lane as a fallback. No lane uses them until live config places them, so existing lanes behave as before. Window and output ceiling come from OpenRouter's model list read on 2026-09-25, and both prices are 0 (#39150).
