6. 구현 규칙

기능 우선

실제 canary 실패를 먼저 재현한다. 관측 인프라가 없다는 이유로 정상 기능을 막는 전역 gate를 만들지 않는다.

Typed boundary

Raw → Resolved → Decision → Command. 문자열/substring/regex가 도메인 상태를 대신하지 않는다.

Effect outside

pure transition에서 command를 만들고 filesystem/network/process effect는 바깥 owner가 실행한다.

Current only

producer/reader/writer/caller를 함께 바꾸고 old reader, dual write, fallback facade, 죽은 테스트를 남기지 않는다.

설정 진실

경로는 <base-path>에서 resolve한다. env를 추가하기 전에 TOML과 기존 runtime params를 확인한다.

Heuristic gate 금지

임의 숫자·substring·regex·timeout·budget으로 정상 흐름을 차단하지 않는다. 정말 필요한 제한은 측정된 자원 경계와 typed outcome으로 설명하고, 희귀 실패는 우선 관측 가능하게 만든다.

Reuse before abstraction

표준 라이브러리와 기존 typed module을 먼저 찾는다. 새 facade·환경변수·hard-coded path·중복 store를 만들기 전에 현재 owner와 API를 확장하고, 깊은 공통화보다 읽히는 국소 중복을 택한다.

Monadic 흐름

파싱에 성공한 값만 Option/Result 바인딩으로 흘리고 실패는 typed error로 조기 반환한다. 의미를 드러내지 않는 리터럴 숫자는 이름 있는 상수로 추출한다.

작업 프로세스

빌드 검증은 로컬이 아니라 CI로 한다. 한 PR은 20k token 안쪽으로 자르고 연속 작업은 Stacked PR로 잇는다. 병렬로 적대 리뷰를 붙이고 리뷰 대응도 병렬로 처리한다.

증거 분리

Source, CI, merged, deployed, live, screenshot은 서로 대체하지 않는다. 동일 canary identity로 연결한다.

7. 외부 구현에서 가져올 것

Anthropic advanced tool use

tool definition을 전부 prompt에 넣지 않고 필요한 tool을 찾으며, 반복·분기·변환은 programmatic calling으로 실행한다. MASC에는 on-demand catalog와 composition node를 흡수하되, code sandbox의 반환을 완료 authority로 쓰지 않고 node별 typed input/output receipt를 남긴다.

OpenAI Agents SDK

agent handoff와 trace를 별도 primitive로 둔다. MASC composition도 agent 변경을 문자열 설명이 아니라 typed handoff edge로 기록하고, 한 turn의 tool group·parallel batch·handoff를 같은 trace에서 Dashboard가 펼쳐 보여야 한다.

LangGraph

checkpoint 뒤 replay할 때 완료 task result를 복원하고 effect를 재실행하지 않는 durable execution 원칙을 참고한다. MASC의 Shell IR/composition도 JSON 직렬화 가능한 node result와 execution receipt를 checkpoint 경계에 묶고, restart 시 미완료 node만 재개한다.

UltraHorizon

장기성은 시간만 오래 흐른 것이 아니라 부분 관측 환경에서 계획·memory·tool management를 계속 성공시킨 궤적이다. 1h→24h 셀에 wall-clock과 함께 새 정보 발견, 계획 수정, 도구 결과 소비, 비반복 진척을 채점한다.

Hermes Agent

항상 주입되는 작은 user/profile memory와 on-demand session search/procedural skills를 분리한다. MASC도 사람·관계 핵심 snapshot과 상세 사건 검색을 같은 저장소로 뭉개지 않는 편이 맞다.

OpenClaw

agent별 workspace·identity·user·memory·session store 분리와 runtime/provider 경계를 참고한다. bootstrap file은 context이지 실행 권한이 아니다.

Orca

CLI agent를 worktree 단위로 격리하고 diff comment·snapshot·automation을 같은 operator surface에서 다루는 점을 가져온다. 다만 IDE가 execution truth를 소유하게 하거나 UI click을 durable task completion으로 간주하는 것은 거부한다.

Claude Code

subagent별 독립 context·tool/permission·persistent memory scope와 worktree isolation을 참고한다. 반면 hook의 stop decision을 제품 전체의 보편적 hard gate로 복제하지 않고, Keeper lifecycle authority는 runtime owner에 둔다.

Codex

여러 thread의 worktree 격리, 중간 steering, diff·screenshot·log를 agent가 직접 읽는 검증 루프를 가져온다. app/session UI를 durable Goal·Task·receipt의 SSOT로 만들지는 않는다.

Generative Agents

observation·reflection·planning의 분리가 장기 행동 품질에 기여한다. 관계 기억도 단순 사실 저장이 아니라 다음 계획에서 실제 사용됐는지를 평가해야 한다.

MemGPT

bounded active context와 external memory tier 사이 이동, interrupt 기반 control flow를 참고한다. 저장량보다 올바른 recall/reinjection과 실패 가시성이 핵심이다.
