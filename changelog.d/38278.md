### Fixed

- The repository pull reader joins a pull request to a Keeper by the author of
  the most recent commit with one parent, not the head commit. A merge commit
  at the head — GitHub's "Update branch", pr-updater's update-branch, a local
  `git merge origin/main` — carries the author of whoever brought the base in,
  so the pull request was attached to the wrong Keeper or to none. The CI state
  is still read from the head commit (#38278).
