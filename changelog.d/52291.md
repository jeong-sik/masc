### Documentation

- RFC operator-quiz-follows-lesson §3.8: an `operator-quiz` installation bound
  to an `operator-lesson` output takes a required `binding.since`, and before
  any session has asked, a session that follows the lesson reads from it
  instead of from the quiz's first session. The first quiz session of a trial
  installation ended with `no_material` because every record the lesson cited
  was older than that session (#52289, #52291).
