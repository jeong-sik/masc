### Internal

- The authorization zone reads its clock inside its locks for the time of each record, so a caller can no longer bring a time read before it waited for the lock. The authorization state keeps the latest time it has read and refuses an admission before it (`Admission_behind_log`), so a clock set back cannot spend an invitation that had expired when a later record was written. Other kinds are not held to that time. A draft no longer carries a time, and `Authz_bootstrap` takes the clock in its request (#48770).
