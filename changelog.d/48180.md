TUI Lane inventory now follows the served projection when notifying changes, with scoped Inspect reads, retries, and reconnect revalidation. Memory health is refreshed per Keeper after durable writes, and Skill activation usage is cached per session and reference instead of being reloaded and recomputed on every request. Browser and machine spectators now use scoped SSE changes, with single-flight trailing reads and pointer/draft ownership preserved. The shared periodic refresh option is removed. Browser observations are sampled by the server while subscribed and announced only when their revision changes.
