### Upgrade notes

- The Pele helper protocol is now version 2. After installing this masc-tui, run `sh scripts/install-pele.sh` from the same checkout (`scripts/install-local-build.sh` already does when its prefix holds `masc-pele`). Until then the TUI's graph and chart previews fail with the reinstall hint (#55551).

### Fixed

- A Pele helper installed before #55344 no longer passes the TUI's protocol check and then fails with `format must be mermaid, svg, or graph`. The TUI asks for protocol 2, the old helper refuses it without a receipt, and the TUI tells the operator to run `scripts/install-pele.sh` (#55551).
