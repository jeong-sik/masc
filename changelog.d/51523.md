### Fixed

- The approval auto-merge worker closes the open issues that each pull request
  it sees merged links with `Closes #N`, because GitHub leaves them open when
  the merge is made with the Actions token. A layer of a native stack counts
  once its merge commit is on the default branch. The workflow's token gains
  `issues: write`, and the pull request template says to use `Relates #N`
  when work remains in the issue (#51523).
