### Fixed
- A Muse Keeper session resumes against the completed-turn count the host last reported instead of a count MASC guessed from its own claim ordinal. A turn whose ending MASC did not see (an owner stop, a server restart after dispatch, a host stop) admits either host outcome, so resuming no longer fails with `retained session completed-turn count changed` and no longer throws the retained session away. (#44265)

### Changed
- Settled Muse official-client session bindings written before this change no longer decode. The deploy preflight and boot list them as undecodable, `--accept-store-quarantine` moves them aside, and the next claim starts a fresh Muse session. (#44265)
