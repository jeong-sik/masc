### Internal

- `Keeper_librarian_floor_publish.publish` commits the program of a finished message-floor chain to Memory as one commit over the range the refused original read, with the messages the chain could not read in the receipt and the external cursor prepared for that receipt. A Memory that changed since the chain began supersedes the program and nothing is written. The receipt check, the cursor acknowledgement and the move of the read positions stay with the consumer's own tail. `Commit.receipt_state` no longer counts unread messages in the range identity, so a range published with holes reads as published. Nothing calls the publication yet, so no behavior changes for a pass that does not descend (#46677).
