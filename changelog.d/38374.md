### Added

- `masc_dos_load` takes `boot` to name the program inside a game directory
  that holds several, such as 삼국지3's `KOEI.COM` loader (#38374).

### Changed

- The ocaml-dos pin moves to `1c75fbc`: a guest that reads the BIOS keyboard
  ring itself counts as asking for a key, so such games settle (#38374).
