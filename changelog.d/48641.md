### Documentation

- The shares of Keeper turn time in `docs/evidence/execute-waits-2026-11/`, the tool-efficiency report and RFC-0379 section 6 now count only the part of a call that lies inside a recorded turn interval. 22.3 % of `Execute` time lies outside every interval, so dividing all of it by the turn time overstated the share. The measurement script gains a `turn_time` block that reads the intervals with the same code as `docs/evidence/lane-time-2026-11/`, its tests grow from 104 to 122, and RFC-0379 section 6 states which tokens can read a run and that a finished attempt may carry no conclusion (#48641).
