### Added

- `POST /api/v1/tui/preferences` writes one parsed change to the `[tui]` table of runtime.toml (chat visit, theme, language, Board sort, candle, audio input device, retired help hint) through the config commit, so it announces `runtime_config_changed`; a change outside the closed shape is refused with 400 (RFC-0482 L1, #48133).

### Documentation

- RFC-0482 names the TUI preference route and its body, and leaves the Keeper list preference out because it writes `tui-keepers.toml` (#48133).
