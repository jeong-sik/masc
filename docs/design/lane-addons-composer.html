할 수 있는 일

패널의 독립 검토를 모아 Judge가 판단합니다. 패널 수와 연결을 바꿔 검토 층위를 조립합니다.

활용할 결과

종합 보고서에 원천 자료와 각 모델의 요청·응답 근거를 함께 보존합니다.

전달과 사용

보고서를 보존한 뒤 명시적으로 공유합니다. Broadcast 영수증과 에이전트의 읽기·활용은 따로 확인합니다.

조립 방법

블록 선택 → ‘출력 연결’ → 받을 블록 선택. 여러 입력을 한 블록에 모으거나, 같은 출력을 여러 블록에 연결할 수 있습니다.

연결에 따라 층위를 자동 정렬합니다. 입력 없이 놓인 블록은 첫 층위에 남습니다.

설치 선언에 사용할 공통 설정

서버의 자료·패키지 경로와 선언된 모델 경로를 입력하세요. 이 편집기는 파일을 설치하거나 서버를 호출하지 않습니다.

설치 TOML 미리보기

명시한 경로·입력 연결에서 생성한 선언입니다. 이미지와 자료 파일이 준비됐는지 확인하고 TUI의 Installation 편집기로 옮겨 검토하세요. Broadcast·에이전트 블록은 설치나 자동 전달을 생성하지 않습니다.

받은 보고서 읽기

fusion-report의 출력 JSON 또는 MCP 응답 파일을 읽습니다. 파일의 기록을 표시하며 서버 조회·근거 검증·전달을 실행하지 않습니다.

아직 보고서 파일을 열지 않았습니다.

공유 영수증 읽기

Evidence 응답의 보존·전달 기록을 읽습니다. 보고서와 선택 좌표가 일치해도 내용 해시·서버 상태·Keeper 열람은 검증하지 않습니다.

원천·분석·보고서·Broadcast·에이전트는 조립 역할 예시입니다. 실제 패키지와 연결하려면 각각의 manifest·출력·행동 계약을 확인해야 합니다. 포트 종류는 이 시안의 조립 규칙입니다.

현재 기능과 제안의 경계

같은 run의 최신 완료 named output 연결, 직접 소비자 wake, 보존 근거, 구독 참조·sequence와 명시적 read/ack는 기존 계약입니다. fusion-compute의 격리 패널/Judge, fusion-report, 명시적인 Evidence 공유 경로는 코드에 구현돼 있습니다. 이 조립 편집기는 설계 시안이며 설치·실행하지 않습니다. 네이티브·컨테이너 검증은 미완료이고, 자동 Board/Broadcast 연계는 제안입니다. 구독 알림을 Broadcast 또는 읽음으로 간주하지 않습니다.

이 편집기는 단방향 출력 연결을 모델링합니다. 피드백·행동 적용·재관측은 별도 owner 계약이 필요하며, 순환선을 그린다고 실행되지 않습니다.
