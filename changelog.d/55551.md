### Upgrade notes

- The Pele helper protocol is now version 2. After installing this masc-tui, run `sh scripts/install-pele.sh` from the same checkout (`scripts/install-local-build.sh` already does when its prefix holds `masc-pele`). Until then every Pele preview fails: Mermaid, SVG, graph and chart. Memory Explorer shows the reinstall hint; diagram fences in chat and Markdown show only their code block (#55551).

### Fixed

- A Pele helper installed before #55344 no longer passes the TUI's protocol check and then fails with `format must be mermaid, svg, or graph`. The TUI asks for protocol 2 and the old helper refuses it without a receipt, so the render error names `scripts/install-pele.sh`. Memory Explorer shows that error; chat and Markdown previews still drop it and show only the code block (#55551).
