### Fixed

- A browser allocation that still holds files the browser left for the Keeper (downloads, their snapshots, uploads) no longer stops its source until an operator retains it. Once the worker has settled and the allocation is the one it acquired, the host moves those folders by rename into `<lane-addon store>/kept-files/<instance id>` and releases the allocation, so the declaration starts the next instance; the release names the folder in the server log. The host never removes the moved files. A link or multiply linked file there, a destination that already holds them, or a `kept-files` on another file system still leaves the release unconfirmed. (#46454)
