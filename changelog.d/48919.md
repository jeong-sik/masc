### Added

- The server installs one provider connection cache at startup. A Keeper's
  provider requests on the server's main domain take an idle connection to
  the same origin from it instead of opening a new TCP and TLS connection.
  An idle connection closes after 20 seconds. A request on another domain
  opens and closes its own connection as before (#48919).
- The runtime health response gains `provider_connection_cache`: idle
  connections per origin, reuses, new connections, and closes by reason,
  or `null` when no cache is installed (#48919).
