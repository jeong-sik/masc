### Fixed

- Releasing the DOS controller no longer reports success while the DOS Add-on installation is failed, starting, stopping or detaching. Its state may still hold the controller, so Keeper removal, seat departure and invite revocation now record a failed release that names the installation and why; "nothing to release" is left for when no installation declares the controller. Shared machine calls name such an installation too, and the play controller lookup keeps the call's own error (#45157).
