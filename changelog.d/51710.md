### Fixed

- A new official-client session seed turns a finished-turn tool result into a
  marker only inside the part of the raw seed that was checked against the
  request. A seed with an open tool call before the turn boundary keeps the
  results after that call verbatim instead of sending them as markers by an
  unchecked index (#51710).

### Documentation

- The official-client start projection contract now states when a
  finished-turn tool result leaves as a marker and that an unbound seed keeps
  arguments and results verbatim. RFC tool-results-age-out-of-context
  records the operator decision for #51657 (#51710).
