### Added

- **Music**: `keeper_music_render` turns a score written in alphaTex into files a Keeper can send: a PNG of the score (staff and tab), a Standard MIDI File and, when asked, WAV audio. Each is stored as the Keeper's attachment and returned as an `attachment_id`, ready for `keeper_surface_post` on Discord. alphaTex that does not parse is refused with alphaTab's diagnostics. A render whose files pass the attachment store's limits, 20 MiB a file and 20 MiB of the Keeper's temporary attachments together, is refused with nothing stored; the sizes are read from disk before any file is loaded. The tool runs the server host's `masc-alphatex`, which gains `--export-midi` and exits 65 for a source that does not parse; operators rerun `scripts/install-alphatex.sh` after this release, or the tool fails on the old viewer's unknown option (#55506).
