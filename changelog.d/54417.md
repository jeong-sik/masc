### Added

- `masc_dos_screen` `include_ints` returns the DOS lane's recent INT-entry trail (last 64, oldest first, with the entry registers), giving the lane the view dosboot's `--int-trace` already has (#54417).

### Changed

- The ocaml-dos pin moves `238d2c9b` → `7cdb64b7`, which is 37 commits of ocaml-dos main — not only the `on_int` observer this feature uses: A20 gate and 16 MB RAM (#238), 386 system registers (#239), protected-mode segments and fault delivery, XMS changes, and snapshot format 42 → 45 (#54417).

### Fresh state required

- DOS lane snapshots saved before this change (autosave, autosave-prev, named checkpoints) are refused after it — the snapshot format version decides readability and 45 does not read 42. A load after the upgrade asks the usual discard consent for a previous autosave it cannot read; boot the game again from its inventory copy. Game save files under `dos/saves/` are not snapshots and survive (#54417).
