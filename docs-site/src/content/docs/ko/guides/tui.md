`masc-tui`는 MASC 작업 공간을 감시하고 제어하는 기본 터미널 조종석(Front Door)입니다.

## 기본 실행

```bash
# 바이너리 실행 — 서버가 쓰는 base-path 를 넘기세요
# (새 터미널은 작업 공간이 아니라 홈에서 시작합니다)
masc-tui --base-path ~/masc --port 8935

# 소스 체크아웃에서 빌드해 실행
dune build bin/masc_tui.exe
./_build/default/bin/masc_tui.exe --base-path ~/masc --port 8935
```

서버가 실행되어 있지 않을 때 Keepers 화면에서 `s` 키를 누르면 로컬 `masc` 프로세스를 즉시 기동합니다.

## 10대 서피스 링 (Surface Ring)

`Tab` 및 `Shift-Tab`으로 상단 링을 순환 탐색합니다:

| 번호 | 서피스 (Surface) | 주요 관측 및 조작 기능 | 하위 뷰 (Child Views) |
|:---:|---|---|---|
| **1** | **Overview** | 작업 공간 요약, 태스크 백로그, 주의 필요 항목 | |
| **2** | **Activity** | 키퍼들의 도구 호출, 턴 경계, 정산 최신순 피드 (`f` 스코프 필터) | `l`: 서버 시스템 로그 링 |
| **3** | **Keepers** | 키퍼 로스터, 대화, 로그, 도구 호출 트리, 샌드박스 상태 및 컨테이너 로그 | `f`: 변경 파일 목록, `Enter`: 키퍼 상세 탭 |
| **4** | **Memory** | 키퍼별 Memory OS 상태 및 인과 팩트 조회 | `Enter`: 팩트 브라우저, `c`: 카테고리 순환 |
| **5** | **Approvals** | Gate 승인 대기 큐, 상시 허용 규칙, 키퍼가 사람에게 묻는 질문 | `a`: 승인, `d`: 거절 |
| **6** | **Board** | 오퍼레이터, 에이전트, 자동화, 시스템 게시글 피드 | `c`: 새 글/댓글 작성 |
| **7** | **Planning** | 목표(Goals) 및 계획(Plans) | `v`: 태스크 리뷰, 판정, 스케줄, Fusion 순회 |
| **8** | **Workspace** | 등록된 코드 저장소 및 워킹 트리 변경사항(`d`) | `Enter`: 파일 브라우저 및 diff/blame |
| **9** | **Runtime** | 런타임 레인, 우선순위 모델 후보, 프로바이더 가용성 | `p`: 레인 상세 워크 |
| **10** | **Config** | `runtime.toml` 런타임 설정 (`e` 에디터 편집) | `s`: MCP 리소스 카탈로그, `t`: 툴 카탈로그 |

## 전역 조작 키

| 키 | 동작 | 설명 |
|---|---|---|
| `Tab` / `Shift+Tab` | 서피스 순환 | 상단 10대 서피스를 순서대로 전환 |
| `?` | 도움말 | 현재 서피스의 모든 단축키 안내 오버레이 |
| `:` | 커맨드 팔레트 | `go <surface>`, `keeper <name>`, `settings` 명령 실행 |
| `/` | 실시간 검색 | 키퍼 로스터, 코드 트리, 대화 요청 탭 검색 |
| `r` | 강제 새로고침 | 화면 상태 즉시 재동기화 |
| `q` 두 번 | 종료 | TUI 종료 (백그라운드 서버는 유지) |

## 키퍼와의 상호작용 및 명령

하단 입력행을 통해 현재 활성화된 Keeper에게 직접 지시를 전달합니다:
- `/task <title>`: `masc_add_task`를 호출하여 작업을 생성하고, 생성된 Task ID를 해당 키퍼에게 즉시 전달
- `/help`: 사용 가능한 슬래시 커맨드(스트리밍 인터럽트, 키퍼 전환, 이미지 첨부 등) 확인
- `masc_ask` 질의: 키퍼가 판단을 사람에게 물었을 때 같은 입력행에서 즉시 답변
